# 06_核心数据字典摘要.md
> 仅关键字段摘要，可后续扩展完整数据库表设计
>
> ⚠️ **边界澄清（D-5）**：这是**核心对象摘要**，**不是全表清单**。当前库实际 **39 张表**（含 `financial_reports` / `valuation_daily` / `money_flow_daily` / `plugin_audit` / `plugin_backtests` / `candidate_*` / `predictions` / `verifications` / `paper_*` / `experiments_*` …），**全量以 `stocklab/store/schema.sql` 为准**。把它当开发输入会漏表。
>
> ⚠️ **必须补的两个字段（D-6）**：00 §5/§6 的两条硬约束目前**没有承载字段**，不补就无法执行：
> - 「策略评估记录」加 **`连续优化失败次数`**（≥3 → 强制归档，不再迭代）
> - 「策略评估记录」加 **`冻结到期时间`**（冻结 ≤90 天，到期强制重评）

## 候选池快照单条记录
标的代码，标的名称，所属池[short/mid/long]，入池时间，原始得分，修正后得分，入池理由，风险清单，状态，快照版本id

## 插桩脚本版本记录
桩ID，版本号，脚本文本，创建时间，回测报告ID，状态：草稿/沙盒回测中/等待审核/线上/归档，备注

## 预测记录表（不可修改）
标的代码，预测生成时间，预测窗口周期，预期收益区间，涨跌概率，到期时间；到期后回填：真实涨跌幅，预测偏差值

## 策略评估记录
策略脚本版本ID，评估开始时间，评估结束时间，单轮周期设置，轮次，每轮绩效结果，评估结论：冻结/待优化/归档，备注
