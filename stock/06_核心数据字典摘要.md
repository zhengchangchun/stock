# 06_核心数据字典摘要.md
> 仅关键字段摘要，可后续扩展完整数据库表设计
>
> ⚠️ **边界澄清（D-5）**：这是**核心对象摘要**，**不是全表清单**。当前库实际 **58 张表**（2026-09-29 真库 `sqlite_master` 实测；含 `announcements` / `northbound_holdings` / `candidate_status_events` / `plugin_resource_events` / `paper_agent_reviews` / `paper_capital_events` / `paper_agent_evals` 等新表），**全量以 `stocklab/store/schema.sql` 为准**。把它当开发输入会漏表。
>
> ✅ **D-6 两条硬约束已落地（2026-09-29 订正）**：不再需要新增列——两条都做成**派生读数**（P87 / ADR-037），数据从 **append-only 台账** fold 出来，**不加列、不写新状态**：
> - **`连续优化失败次数`**：`m2 lifecycle show|due` 从 `m2_judgements` 尾部连续 `branch='optimize'` 派生（`insufficient` 穿透、`freeze`/`tune` 归零）；≥3 只在 `evidence.lifecycle.force_archive` **提示**，**绝不自动归档**。
> - **`冻结到期时间`**：取最新 `branch='freeze'` 的 `asof_date + evidence.freeze_days`，由同两条只读命令给出。
> 理由见 `docs/decisions/2026-09-27-ADR-037-*.md`：`validation_cycles` / `validation_rounds` / `m2_judgements` 全 append-only ⇒ 派生而非加列。

## 候选池快照单条记录
标的代码，标的名称，所属池[short/mid/long]，入池时间，原始得分，修正后得分，入池理由，风险清单，状态，快照版本id

## 插桩脚本版本记录
桩ID，版本号，脚本文本，创建时间，回测报告ID，状态：草稿/沙盒回测中/等待审核/线上/归档，备注

## 预测记录表（不可修改）
标的代码，预测生成时间，预测窗口周期，预期收益区间，涨跌概率，到期时间；到期后回填：真实涨跌幅，预测偏差值

## 策略评估记录
策略脚本版本ID，评估开始时间，评估结束时间，单轮周期设置，轮次，每轮绩效结果，评估结论：冻结/待优化/归档，备注
> **落地映射（2026-09-29）**：本对象＝`validation_cycles`（周期）＋ `validation_rounds`（轮次）＋ `m2_judgements`（判定）三张 append-only 表；「连续优化失败次数 / 冻结到期时间」由 `m2 lifecycle` **派生**（见上 D-6 订正），不是独立列。
