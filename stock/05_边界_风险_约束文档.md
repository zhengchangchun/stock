# 05_边界_风险_约束文档.md
## 业务边界
1. 全部为研究仿真系统，**不输出投资建议，不自动下单**。
2. 模拟回测表现 ≠ 未来实盘表现；报告固定位置输出风险提示。
3. AI可以迭代插桩脚本，但主干流程、硬约束不能被修改。
4. 人工审核是最终闸门，AI没有上线策略权限。

## 已知风险清单
1. 数据源质量问题会造成回测幻觉；依赖【03_P0公共基础组件】脏数据校验规避。
2. AI优化脚本极易出现历史过拟合；依赖 **沙盒 70/30 切分 + `overfit_flag` 标记 + 人工复查** 兜底。
   > ⚠️ **澄清（D-2）**：原文写「依赖过拟合检测模块**拦截**」——系统里**没有拦截器**，`overfit_flag` 只**打标记**、不阻断流程（口径同 03 §4.1）。两处已统一，不得再写成「拦截」。
3. 短期策略对滑点高度敏感；交易成本仿真模块降低偏差。
4. 黑天鹅事件不在历史样本中，任何模型无法完全覆盖。

## 运维约束
1. 所有脚本版本全量归档，支持一键回滚旧版本。
2. 预测记录、交易日志、快照数据禁止删除，只能标记归档。
