# 00_系统总概.md
## 项目目标
构建一套【主流程固定不可修改 + 插桩脚本AI可动态迭代】的股票分析仿真系统。
1. 模块1：候选池筛选系统：通过财务、行业经济学公式、多因子，产出短期/中期/长期观察候选池；全部策略因子封装为可动态修改插桩脚本，主流程主干逻辑固化。
2. 模块2：AI模拟选股 + 人工实盘镜像对照闭环；AI模拟账户目标：模拟收益跑赢人工镜像账户；具备预测‑验证‑测试闭环。
3. AI可以迭代插桩脚本，但是主干流程、硬约束边界不可修改；脚本上线前必须沙盒回测 + 人工审核。
4. 策略自评估：AI自主选择验证周期，硬性约束：最少2‑3个完整调仓周期，整体评估时长不超过30天；持续正收益冻结策略，持续负收益触发优化。

## 重要免责
> 本系统全部输出仅作为研究观察使用，不构成任何投资建议；模拟回测结果不能等价于未来实盘收益。

## 整体数据流
模块1【候选池筛选系统】 → 模块2【模拟&人工交易闭环系统】
模块2输出错判案例、预测偏差 → 回流输入模块1AI优化任务，完成闭环。

## 全局硬性约束（主干，AI不可修改）
1. AI仅允许修改沙盒插桩脚本，**不能修改主流程流转、不能修改全局硬约束、不能修改统计口径**。
2. 所有新版插桩脚本，必须沙盒回测，人工审核确认后，才允许投入模拟运行；禁止AI自动上线策略。
3. AI模拟选股，只能从模块1输出候选池内部选择标的，不能跳出候选池选股。
4. 策略验证约束：单策略评估至少2‑3个完整调仓周期，整套评估时间不超过30自然日。
5. 策略即使持续正收益，冻结最长有效期90天，到期强制重新评估。
6. 同一策略版本连续3次优化验证失败，强制归档，不再迭代。
7. 所有预测记录落库后不可篡改，保证验证客观。
8. 系统不对接券商实盘下单接口，全部交易为模拟仿真，实盘操作人工录入。

## 术语与现状口径（2026-09-21 澄清）

1. **「AI」的所指**：本系统的「AI」＝**外部编码 agent（如 Claude Code）+ 人工复核**，不是系统内部自动调用模型。系统内**不实现**「自动生成插桩脚本」——脚本文本一律经 `plugin` 的 `submit → 沙盒回测 → 人工 approve` 才能上线。（澄清依据：现实里新脚本由外部 agent 产出；见澄清录 D-1）
2. **模块完成度**：模块1 主干**已完成**；模块2（AI 模拟选股通路、提前熔断、策略自评估）**尚未开工**。逐条对账见 `docs/plans/2026-09-21-整体需求评审.md` §4。
3. **文档体例**：本文件及 01/02/04/05/06/07 是**需求体**（要什么）；`03_P0` 是**现状体**（已经是什么），会随代码演进订正。两者不要混读。

## 调度总配置
1. 轻量巡检：每30分钟
    - 更新候选池内标的行情、北向、公告、模拟/镜像账户市值、刷新预测
2. 每日收盘任务
    - 执行预测验证校验，统计预测偏差指标
3. 每周完整任务
    - 全量候选池扫描；策略绩效对比；AI优化任务触发判断
4. 季度深度复盘
    - 财报重算；全部候选池重打分；冻结策略强制复核触发判断
