## 0. 问题

`real_trades` 表在 P1 就建好了，**全仓库零写入入口**（实测 `select count(*) from real_trades` = 0）。
没有本金/现金表。于是「实盘现在什么状态、纪律有没有破」这个问题在系统里**无法回答**，
更没有东西能跟模拟盘对比。本轮补上这条链。

## 1. 背景事实（用户实盘，原样入库，不许改数）

| 项 | 值 |
|---|---|
| 本金 | 20,000 元，2026-09-14 到账 |
| 成交 | 2026-09-14 买入 000333 100 股 @ 86.80，费用 5.09 元 |
| 用户口述「成本 8,680」 | = **不含费**口径（86.80 × 100） |

## 2. 口径决策（→ ADR-006）

| 项 | 决策 | 理由 |
|---|---|---|
| 持仓成本 | **默认含费**；同时输出不含费 | 实盘账户里付出的钱才是真成本；扣费口径与《准确率优先·扣成本》一致 |
| 现金 | `Σ 现金流 − Σ 买入(价×量+费) + Σ 卖出(价×量−费)` | 唯一能对上券商流水的算法 |
| 总资产 | `现金 + Σ 有现价的持仓市值` | **无现价的标的排除在外并显式报警**，不用成本价冒充 |
| 累计净投入 | `Σ deposit − Σ |withdraw|` | 分红/费用不计入净投入（它们不是本金） |
| 累计收益 | `总资产 − 累计净投入`（含费） | |
| 保证金 | **无**（A 股现货全额） | 不需要维持担保比等字段 |
| 改错 | **只能冲正**（写反向记录 + note），不许 UPDATE | append-only 与 `predictions`/`features_daily` 同一纪律 |

## 3. 数据模型（前滚迁移，全部 `CREATE TABLE IF NOT EXISTS`）

```sql
-- 本金 / 现金流（append-only）
CREATE TABLE IF NOT EXISTS cash_flows (
    flow_id    INTEGER PRIMARY KEY AUTOINCREMENT,
    date       TEXT NOT NULL,
    kind       TEXT NOT NULL CHECK (kind IN
                 ('deposit','withdraw','dividend','fee','tax','other')),
    amount     REAL NOT NULL,   -- **有符号**：正=流入组合，负=流出组合
    note       TEXT,
    created_at TEXT NOT NULL
);

-- 幂等键台账（append-only）：把「重试」与「真重复成交」分开
CREATE TABLE IF NOT EXISTS ledger_idem (
    idem_key   TEXT PRIMARY KEY,
    scope      TEXT NOT NULL CHECK (scope IN ('trade','cash')),
    row_id     INTEGER NOT NULL,
    created_at TEXT NOT NULL
);
```

`real_trades` **不加列**：它已存在，加列需要 `ALTER TABLE` 而本项目的迁移是
纯 `CREATE ... IF NOT EXISTS` 幂等脚本（无 `IF NOT EXISTS` 的 ADD COLUMN）。

`real_trades` / `cash_flows` / `ledger_idem` **补 append-only 触发器**
（UPDATE + DELETE 皆 ABORT）—— 实测 `grep TRIGGER schema.sql` 里
`real_trades` 一条都没有，本轮补上。

## 4. 重复录入：为什么**不用唯一约束**

真实成交**可能同价同量同费**：同一天分两笔各买 100 股 @86.80、佣金都是 5.09，
是完全正常的真单。对 `(date, code, side, price, qty, fee)` 加 UNIQUE
= 系统**吃掉真单**，而且吞的时候没有任何声音。

所以用**两层**机制：

1. `--idempotency-key KEY`（推荐）：键存在 `ledger_idem` 表里。
   同一个 key 第二次进来 → **幂等命中**（`state=identical`，不写第二行，退出码 0）。
   这层解决的是「命令重试 / 补跑」。
2. **无 key 时**：若库中已存在**完全相同**的 `(date,code,side,price,qty,fee)` 元组
   → **拒绝**并退出 2，提示「要么给 `--idempotency-key`，要么给 `--allow-duplicate`
   确认这是另一笔真单」。这层解决的是「手滑敲两遍」。

两层都不阻止真单：真单只要显式确认一次就进得去。

## 5. 校验（写入口硬拒，不静默降级）

| 规则 | 判据 |
|---|---|
| `qty > 0` | 买入必须 `qty % 100 == 0`（整手）；卖出允许零股残量 |
| `price > 0` / `fee >= 0` | |
| `code` 已登记 | `instruments` 里存在 |
| `date` 合法 | 在 `trading_calendar` 内**且** ≤ 最近已收盘交易日（**禁录未来成交**） |
| 卖出不超持仓 | 按 `(date, trade_id)` 逐笔回放，任一时点 `qty_sold ≤ qty_held` |
| 现金流符号 | `deposit`/`dividend` 必须 > 0；`withdraw`/`fee`/`tax` 必须 < 0 |

**最近已收盘交易日**：`today` 是交易日且本地时刻 ≥ 15:00 → `today`；否则 `prev_trading_day(today)`。
（`trading_calendar` 只到 2026-09-14，`prev_trading_day('2026-09-15')` = `2026-09-14`，
所以 9-15 当天能补录 9-14 的成交。）

## 6. 持仓推导（纯函数，`stocklab/portfolio/positions.py`）

加权平均成本法，**部分卖出按均价结转，剩余持仓成本不变**：

```
买入: qty += q;  cost_incl += p*q + fee;  cost_excl += p*q
卖出: a_incl = cost_incl/qty;  a_excl = cost_excl/qty
      realized_incl += (p*q − fee) − a_incl*q      # 卖出净额 − 结转成本(含费)
      realized_excl +=  p*q         − a_excl*q      # 卖出总额 − 结转成本(不含费)
      cost_incl −= a_incl*q;  cost_excl −= a_excl*q;  qty −= q
```

输出字段名**必须带口径后缀**（`avg_cost_incl_fee` / `avg_cost_excl_fee`），
防止下游拿错口径还不知道（ERROR_DIARY「口径不匹配就该取不到数据」同型）。

清仓（qty == 0）：`avg_cost_* = 0`，`cost_basis_* = 0`（不留浮点残渣），
已实现盈亏保留；再建仓从零重新累计。

## 7. 现价口径（`stocklab/portfolio/prices.py`）

```
同日 quote_snapshots（WHERE code=? AND trade_date=asof ORDER BY ts DESC LIMIT 1）
  → source="snapshot", price_asof=trade_date
否则 bars_daily 最新收盘（date ≤ asof AND adj_mode='none' ORDER BY date DESC LIMIT 1）
  → source="bars", price_asof=该日期
否则 → 返回 None → 该标的 status="missing_price"
```

- 必须显式标注 `price_source` 与 `price_asof`。
- `missing_price` 的标的**排除出市值合计**并进 `missing_price_codes` 报警。
- **不许**用成本价冒充现价，**不许**插值。
- `bars_daily` 按 `adj_mode='none'`（不复权）取 —— 复权价不是「今天这只票值多少钱」。

## 8. 纪律检查（`stocklab/portfolio/discipline.py`）

状态语义：`PASS` 满足 / `WARN` 偏离目标带 / `FAIL` 破硬约束 /
`UNDETERMINED` **数据不足，不猜**（不是 PASS）。

| check | 判据 | 状态 |
|---|---|---|
| `single_position_max_40pct` | `max(市值/总资产) ≤ 0.40` | 超 → **FAIL** |
| `cash_band_45_60pct` | `0.45 ≤ 现金/总资产 ≤ 0.60` | 带外 → WARN |
| `stop_loss_close_85` | 收盘价 ≥ 85.00 | 破 → FAIL |
| `stop_loss_weekly_83_25` | 周线（本周 ≤asof 最后收盘）≥ 83.25 | 破 → FAIL；无 bars → UNDETERMINED |
| `no_add_above_87` | 现价 < 87.00 才允许补仓 | ≥ 87 → WARN（禁补仓） |
| `cash_per_trade_max_5pct` | 单次动用现金 ≤ 总资产 5% | 给出额度数字；无总资产 → UNDETERMINED |

减仓比例（单次 10% / 破位 20%）作为 `advisory` 回显各规则的**具体股数**，不判状态。
