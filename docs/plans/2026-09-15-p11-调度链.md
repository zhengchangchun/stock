## 1. 要回答的三个设计问题

### Q1 快照的幂等键取什么？（承 ADR-005「取语义不取呈现」）

取 **(code, trade_date, ts)** —— `ts` 是**源站自己报的时刻**，也就是「这份截面描述的是
哪一刻的市场」。它不是我们抓取的时刻（`fetched_at`），因为「同一刻的市场状态」才是这份
数据的身份；抓取时刻只是呈现。

由此得到一条免费的强性质：**非交易日重复抓取 = 天然幂等**（源站返回的仍是上一交易日的
最后一条 tick，键相同 → `identical`，一行不增）。这条性质让我们不必去猜「今天是不是交易日」
—— 猜错也不会造出假行。

### Q2 `amount`/`turnover` 怎么进 `bars_daily`，又怎么保证历史 NULL 不被填？

- 只在**该交易日已收盘**时回填：`trade_date < today` 或（`trade_date == today` 且本地时间 ≥ 15:00）；
- 只用该 `trade_date` **最晚一条**快照（当日累计量 → 收盘后的最后一条 = 全天值）；
- SQL 用 `COALESCE(amount, :amount)`：**只在原值为 NULL 时写入**，已有值一行不动；
- 作用域锁死 `WHERE code=? AND date=?`：**永远够不到别的日期**；
- 写入前对该 `(code, date)` 做 `adj_mode != 'none'` 硬拒绝（与 `insert_bars` 同一把闸，不绕过）；
- 该日期没有 bar 行 → **显式计入 `skipped_missing_bar`** 并 `system_events` 留痕，不静默跳过。

**顺带修一个真实缺陷**：`repo.insert_bars` 的 `ON CONFLICT DO UPDATE` 原本写
`amount=excluded.amount`，而腾讯日K 响应里**没有** amount 字段（`excluded.amount` 恒 NULL）
→ 每天重跑 `ingest bars` 会把前一天回填好的 `amount` **抹回 NULL**。
改为 `COALESCE(excluded.amount, bars_daily.amount)`：**源站没给 ≠ 源站说要清空**。
不这么做，「从今天起积累」根本积累不起来（第二天就被自己擦掉）。

### Q3 报告里的准确率是「历史回放」还是「实盘累计」？—— 必须结构可判

现状：`verifications` 表**没有**任何来源标记，6055 行全部来自 `verify backfill` 的 PIT 回放，
但表里看不出来。加列要改 append-only 表的历史，属于改写历史，不做。

**判据（结构性、可复核、不含主观约定）**：

> 一条预测是**实盘**的 ⟺ 它的 `created_at` 日期 == 它的 `asof_date`。

即「这个预测是在它预测的那个交易日当天产生的」。回放/补跑必然 `created_at` 远晚于 `asof_date`。
实测：现有 6055 行中 `created_at` 日期 == `asof_date` 的有 **0 行** → 全部是回放。
报告据此把两部分**分开列**，并各自标注口径；当前 LIVE 桶为空时报告直接写
「实盘累计：0 行」，而不是把回放的 38.14%/0.6581 说成实盘表现。

判据的**边界**也写进报告：`created_at` 是**入库时刻**不是**决策时刻**，
当天补跑一次历史 `asof` 会被记成实盘。这条限制明写，不藏。

## 3. 四态幂等（照抄 `verify/store.py` 的纪律，不另造一套）

| 态 | 条件 | 行为 |
|----|------|------|
| `inserted` | 该 `(code, trade_date, ts)` 无行 | 写入 |
| `identical` | 已有行，`_canonical()` 后内容 hash 相等 | 不写，成功返回 |
| `conflict` | 同键不同内容 | **不覆盖**、不改写；计入异常 + `system_events` error + 退出码 1 |

`_canonical()` 必须把数值列归一（`float()` / `int()`）：否则内存里的 `87`（int）与
SQLite REAL 列读回的 `87.0`（float）会被 hash 判成不同 → 同一份数据「第二次跑就冲突」
（ERROR_DIARY #10 的同一类坑）。

## 4. `session tick` 的判定链

```
now ──► 读日历 ──► 抓快照（不入 raw_cache：要的是新鲜数据）──► 四态落库
                                              │
                                              ├─► 对每个「已收盘」的 trade_date：回填 amount/turnover
                                              │
                                              └─► 验证到期预测（cutoff = 最近一个已收盘交易日）
                                                       └─► 滚动准确率（按日聚类 + CI + 口径）
```

**到期判据（tick 不误打未到期预测）**：
`cutoff = max{ d ∈ 日历交易日 : d < today 或 (d == today 且 now ≥ 15:00) }`。
盘中跑 tick 时 `cutoff` = 上一交易日 → `target_date == 今天` 的预测**一根都不碰**。
验证范围 = `target_date <= cutoff` 的最近 `--window`（默认 10）个到期日；
更早的未验证日计入 `backlog_skipped`，**显式报出**，不静默丢。

日历为空 / 不覆盖 `cutoff` → 显式 `reason`，不猜。

## 5. `review daily` 报告内容（每项都标口径）

1. 数据健康度（复用 `doctor`，把 CLI 里的逻辑抽成可调用函数，输出逐字节不变）；
2. 数据新鲜度：各表 `MAX(date)`、`bars_daily` 覆盖标的数、当日快照次数/标的/缺口；
3. 当日预测与验证：`target_date == date` 的预测数、验证态分布、不可评分原因；
4. 滚动准确率：按日聚类 + CI，`LIVE` / `REPLAY` **分列**，各带 `sample_gate`
   （< 120 交易日 → 「样本不足，仅供观察」）；baselines（always_up/flat/down、index_300）同表并列；
5. 实验台账：`experiment_decisions` 行数 + 各变体最新 gate（不改、不写）；
6. 数据缺口清单：`amount`/`turnover` 何时开始有值（当前：从来没有）+ 未验证的到期日区间。

## 6. 测试钉住的不变量（每条都对应一个可能悄悄出错的地方）

| 不变量 | 测试 |
|--------|------|
| 历史 `amount/turnover` NULL 不被填 | 回填只作用于指定 `date`，别的日期逐行不变 |
| 重复 tick 不重复写 | 同 `ts` 两次 → `identical`，行数不变 |
| 同键不同内容不被覆盖 | → `conflict` + 退出码 1，库里行不变 |
| tick 不误打未到期预测 | 盘中 tick：`target_date == today` 的预测无验证行 |
| 收盘后才回填 | 盘中 tick 不触发回填；`--now` ≥ 15:00 才触发 |
| 接口失败显式报错 | fetch 抛错 → `errors` 非空 + `system_events` 有 error + 退出码 1，且**不写任何行** |
| `adj_mode != 'none'` 硬拒绝 | 该 `(code,date)` 非 none → `ValueError`，不写 |
| 重采不抹回填值 | `insert_bars` 二次写 amount=None → 原值保留 |
| 口径标注不许写成实盘 | 报告里 LIVE 桶空时，`provenance` 必须写回放；断言关键子串 |
| 报告幂等 | 同输入两次 → md/json 逐字节一致 |
| 不做滚动清理 | 断言代码里没有 DELETE FROM `quote_snapshots` / `bars_daily` 的清理路径 |

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 日历不覆盖今天（`ingest index` 未跑） | 不猜：抓取照做（键幂等，猜错也不造假），摘要里报 `calendar_covers_today` 与 `captured_trade_dates` |
| 快照接口在盘后/非交易日返回陈旧数据 | 键含源站 `ts` → 陈旧数据落成上一次的键 → `identical` |
| 盘中误写当日半截 bar | tick **不**跑 `ingest bars`；当日 bar 缺失 → `skipped_missing_bar` 显式留痕 |
| 报告把回放说成实盘 | 口径分列 + 测试断言关键子串（ERROR_DIARY #16 同型） |
| 回填抹掉源站修订 | 反向也堵住：`COALESCE` 只补 NULL，两向都不互相覆盖 |
