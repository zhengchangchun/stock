### 2.1 第一层：`paper show` 同参数对拍（旧码 `cf82859` vs 新码 `bc91bb1`）

## 3. 台账 append-only / 幂等 / 退出码（收尾第 4 步，手工程序）

全部在**库副本** `B.db` 上跑（真库 `paper_agent_decisions` 仍 0 行）：

| # | 命令 | 实测 |
|---|---|---|
| 1 | `paper spec set --arm arm-agent --asof 2026-09-22 --spec '{"cash_floor_pct":50}'` | **exit 0**，`status: 已写入`，`spec_sha256 81be50261cbf…` |
| 2 | 同 `(arm, asof)` **同**内容重放 | **exit 0**，`status: 已存在且一致（未写入）`，台账仍 **1** 行 |
| 3 | 同 `(arm, asof)` **不同**内容（`55`） | **exit 1**，`error: arm-agent 在 2026-09-22 已有一版 spec —— append-only，本命令不改写历史`，原行逐字节未变 |
| 4 | 放宽 `cash_floor_pct=30`（越界） | **exit 2**，`SpecViolation: cash_floor_pct=30 —— 低于下界：45 ~ 60，且只许收紧（放宽即拒）` |
| 5 | 未知字段 `{"leverage":2}` | **exit 2**，`SpecViolation: … 未知字段（变更空间只有 5 个）` |
| 6 | `paper spec show --arm arm-agent` | 与库同源：`history` 1 条含 `spec_before / spec_after / context_sha256 / prompt_sha256 / n_trials / rejected`；`reproducibility` 明写「**无法判定**」 |

触发器（`PRAGMA recursive_triggers=ON`，与 `paper/store.py` 同口径）：

```
rows before: 1
  blocked: update -> paper_agent_decisions is append-only (改错请再审一版)
  blocked: delete -> paper_agent_decisions is append-only
  blocked: insert -> paper_agent_decisions is append-only      # INSERT OR REPLACE 的隐式 DELETE 也被拦
rows after : 1
  blocked: duplicate -> UNIQUE constraint failed: paper_agent_decisions.decision_id
```

⚠️ 同一张表用**默认连接**（`recursive_triggers` 关闭）跑 `INSERT OR REPLACE` 时**不会被拦**
（行数仍是 1，因为替换成了同内容）—— 这正是 `paper/store.py` 必须显式 `PRAGMA recursive_triggers=ON`
的原因（P6 老坑），本记录顺带复现了一次。

1. **T3 的判据「`diff` 为空」不可能成立** —— 设计 §4.6 要求 `paper show` 新增 `agent` 块。
   实际判据＝**5 条静态臂逐字段一致 ＋ 顶层只多 `agent` 一个键**（§2.1/§2.2 实测）。
   任务书原文保留不改，本条是**判据的落地解释**。
2. **T6 扩范围（良性）**：`arm-agent-random` 的空账户**阶段 1 就建**（任务书初稿写阶段 3）。
   理由＝`delta_vs_random` / `SPEC_ARMS` 需要一个落点，否则「还没有对照臂」与「账户不存在」长得一样；
   交易仍到阶段 3 才接线（现在 `has_rules=False`，只 mark-to-market，`delta_vs_random` 恒 `null`）。
   已在任务书 T6 段落补拍板记录（P43 §S6）。
3. **`-10` 与 `-15` 两臂净值/成交完全相同**（19568.54 / 各 1 笔 510300）——
   不是缺陷：ETF 目标占比 10% vs 15% 在「单次动用现金 ≤5% 总资产、整手」约束下，
   2026-09-22 这一天买出的手数一样（200 股），差异要等后续再平衡日才分叉。**当作读数如实记录。**
