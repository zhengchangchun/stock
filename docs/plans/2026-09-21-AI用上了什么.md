## 1. 先把问题如实回答

| 追问 | 事实 | 证据 |
|---|---|---|
| AI 的准确率是多少？ | 模型 `pit-rw-v1.0.2`，窗口 `2026-08-04~2026-09-21`（30 个交易日）**REPLAY 510 行**：方向命中（按日聚类）**0.3333**（CI95 0.2750–0.3917）、Brier **0.6789**（随机 0.667）；「永远猜跌」基线 0.3608 —— **比猜跌还差** | `session.review.rolling_accuracy` |
| 有实盘样本吗？ | **LIVE 0 行**。窗口内一条实盘预测都没有 ⇒ 上面全是历史回放，不是实盘表现 | 同上（`live is None`） |
| 自己编排的功能用上了么？ | 插桩脚本 7 版（active 6）、插件回测 3 条（verdict 全 `INCONCLUSIVE`）、候选池 2 快照 / 38 席位 —— **候选池在用**（short 池 = plugin 1 的 active 版本 script 7 v1.1.0）；**模拟盘一条都没用**：5 个账户 11 笔成交的 `rule_citation` 全部落在 2 条写死条文内，`params_json` 键里没有 `plugin`/`script_id`/`model` 之一 ⇒ 引用模型预测 0 条、引用插桩脚本 0 条 | 库计数 + 条文对表（见 §2） |

**「没用上」是设计，不是漏接**：生产模型方向能力 ≈ 0，所以模拟盘只做纪律与分散。
但这句话此前**没有任何测试在执行**（§4），必须先补上再谈下一步。

## 2. 取数（`paper_data.ai_evidence(conn, asof)`）

三段，每段都有明确来源，**不产生新口径**：

| 段 | 来源 | 说明 |
|---|---|---|
| `accuracy` | `session.review.rolling_accuracy` | 与「数据」页、`review` 报告**同源**；页面不重算命中率 |
| `scripts` / `by_state` / `backtests` / `candidate` | `plugin_scripts` + `plugin_audit` 折叠 + `plugin_backtests` + `candidate_snapshots/members` | 逐个 `COUNT` |
| `routing` | `candidate.score.POOL_PLUGIN` **反查** + `plugin.lifecycle.active_script_id` | 池 → plugin 的映射不抄第二份（抄的那份会与打分内核漂移） |
| `consumption` | `paper_trades.rule_citation` 对表 `paper.config.RULE_CITATIONS` + `paper_accounts.params_json` | **实测**：表外条文逐条列出；空 ⇒ 没有任何成交由模型/插桩触发 |

`consumption` 是这段的关键设计：它不是「现在没用上」的一句文案，而是一个**钩子** ——
将来真加了模型臂（新条文或新参数键），这里会自己从空变成非空，页面第一屏就会变脸。

## 4. 顺带修掉的两个真缺陷

### 4.1 `test_paper_never_imports_model_or_kelly` 根本不存在

`paper/config.py`、`paper/rules.py`、`labweb/paper_data.py` 三处文档字符串都写着
「用源码扫描钉住这条纪律」，`tests/` 下**零命中**。补成
`tests/test_paper_discipline_guard.py`：

- **AST 扫描**（不是子串）：只看 import 边、`Name`/`Attribute`/`keyword`/函数类名，
  字符串与 docstring 不参与 —— 否则文档里那句「不许碰 kelly」会把它自己判红。
- 禁 import `stocklab.{predict,verify,risk,plugin,candidate,experiments}`，
  禁凯利标识符，禁 `MODEL_VERSION`。
- **反向自检**：把一段违规样本（`from stocklab.predict.model import MODEL_VERSION` +
  `kelly_fraction(MODEL_VERSION)`）喂给扫描函数，必须判红 —— 否则「扫了零个文件」也全绿。

### 4.2 页面把 HTML 当文本显示

`rich()` **先转义再替换**，所以 `<a href>` / `<span class="s-warn">` 喂进
`glance` / `rich` 会原样显示成文本。页面上真的出现了
`<a href=/trades>成交流水</a>页`（`_overlap_note`，两支重合时必然出现）。

- 新增 `render.glance_html()`：行里**已经是 HTML** 的并行入口，调用方自己 `esc()`。
- `_overlap_note` 改成直接拼 HTML（链接恢复可点）、`_why` 改为返回 HTML 行。
- 护栏：渲染结果里不得出现 `&lt;a href` / `&lt;span` / `&lt;b&gt;` / `&lt;code&gt;`；
  两支重合时 `href="/lab/trades"` 必须在。
