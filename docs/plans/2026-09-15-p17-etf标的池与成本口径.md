# P17 ETF 标的池纳入采集 + ETF 成本/定价口径 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 `superpowers:executing-plans` 逐任务执行。
> 步骤用 `- [ ]` 复选框跟踪。

**Goal:** 让 `instruments` 能登记场内 ETF、采集其不复权日线、按 ETF 口径计价成本、并在 CLI/Web/看板显示其现价 —— 且**绝不**把未复权价冒充复权价。

**Architecture:**
ETF 与股票在**收益计算链**（复权因子 → 回测 → 特征 → 预测/验证）上口径不同：场内 ETF 的
除权除息事件**不在腾讯 `fqkline` 通道里**（见 §0 探针证据），因此 ETF 的 PIT 因子链
**无法被证明完整**。据 ADR-001/ADR-004 的「宁可拒绝服务，也不返回非 NULL 的错误值」，
本计划让 ETF：① **进采集**（不复权日线 + 快照，口径与现有通道完全一致）；
② **进展示**（估值用 `adj_mode='none'`，本来就是正确的估值口径）；
③ **不进任何依赖复权收益的计算链**，且在 `adjust` 读取层**结构性硬拒绝** ——
任何试图为 ETF 构建/读取复权链的调用都会拿到显式异常，而不是一条 factor=1.0 的假链。

**Tech Stack:** Python 3.12（`.venv/bin/python`）、stdlib + `requests`、SQLite、pytest。

## §0 探针证据（本计划的设计前提，2026-09-15 实测）

命令（联网，白名单域名）：

```bash
# ① 快照：ETF 走同一通道，字段布局与个股一致（88 字段）
curl -s "https://qt.gtimg.cn/q=sh510300,sh510880,sh512890,sh518880"
#  → v_sh510300="1~沪深300ETF华泰柏瑞~510300~4.523~4.552~4.541~6973418~..."
#     字段 1=名称 2=代码 3=现价 4=昨收 5=今开 30=时间戳 33/34=高/低 36=量(手) 37=额(万元) 38=换手
#  → ETF 名称里带「ETF」后缀，无 pe/pb（实测 39='' 46='0.00'），但不影响本计划用到的字段

# ② 日K：不复权通道可用，行格式与个股一致，且单页 2000 根
#    param=sh510300,day,,,2000,  → 2000 行，2018-06-22 ~ 2026-09-15

# ③ 除权事件：**四只 ETF 全部 0 条事件行**（2000 根 K 线内无第 7 个元素）
#    510300 / 510880 / 512890 / 518880 → n_event_rows = 0

# ④ 但 qfq 与不复权**确实不同** → 证明分红除息真实存在，只是事件不可见：
#    510300: 2023-06-01 day=3.810 vs qfq=3.530（差 7.4%），639/799 个交易日不同
#    510880: 2023-06-01 day=2.985 vs qfq=2.569（差 16.2%），641/799 个交易日不同
#    512890 / 518880: 与 qfq 完全相同（该窗口内无分红）
```

**结论（决定 T2 的取舍）**：ETF 的除权除息**真实发生**（③ 与 ④ 合起来就是证据：
价差存在，事件却为空），但**当前唯一合法数据源不暴露事件**。因此：
- 无法枚举 `cqr` → 连 `adj_factor_blackout`（需要 `cqr`）都填不出来；
- 于是**不能**生成 `adj_factors` 行。写 `factor=1.0` 就是「静默用未复权价冒充复权价」，
  正是任务书明令禁止的；
- 唯一诚实的落点是**读取层硬拒绝**（任务书给的第二个选项）。

`board` 的取舍：`instruments.board` 的语义是「**决定涨跌停幅度**」（见 `backtest/portfolio.py`
的 `LIMIT_BY_BOARD`，未知板别抛 `BoardUnknown`）。四只 ETF 的涨跌停都是 ±10%，与 `main` 一致
→ 登记为 `board='main'`，**不动 schema 的 CHECK 约束**（改 CHECK 要重建表 = 改写历史，
且新老库会分叉）。ETF 身份放在 `type` 列（`'etf'`，schema 里 `type` 无 CHECK，天然可扩展）。
