## 二、发现与处置

### F1（一般）预注册 §5 的复现命令不可执行
- 事实：`experiment run --variant …` 的 `--from/--to` 是必填项，文档里没有，照抄即退出码 2。
- 影响：后来者按文档复现会先撞一次失败，且「跑的是哪个区间」在文档里没有权威出处 —— 这正是 F3 的成因。
- 处置建议（不本轮做）：预注册模板加一栏 **「复现命令（逐字可执行，含区间与标的池）」**，并要求 CI 能逐字跑通；
  本轮请在 §5 补一行「区间与标的池见 §6.x 实测段」的指路。

### F2（一般）`+120 天` 的 PIT 边界与库内真实公告日冲突
- 事实：T1 明说「只此一句 PIT 边界」，实现只做「公告日 ≤ asof」；若按 §2 字面再加 `+120 天`，
  会误剔 41 行「法定回退公告日 = report_date + 121 天」的**合法**年报行。
- 影响：口径若改，样本会变（V1 覆盖 80.8% 还要再掉一截），本轮数字不可直接比。
- 处置建议：这一条应当写进财报数据层评审 §E 的最小改动清单（`notice_date_source` 列落地后再谈窗口），
  而不是在因子层夹一个天数。

### F3（重要，但不阻断）区间未预注册 + 检验力弱
- 事实：区间取自同构先例 P29 V1，**跑前未写死**；独立观测量级仅 ≈ 9 个季度。
- 影响：`LOSE` 只能读成「**未检出**」，**不能读成「已证否」**。这与「财报质量先验无效」是两句话。
- 处置建议：① 结论段已按「弱检验力」登记（CC 在 §7 写了），保持；② 下一轮预注册模板把
  **区间 / 标的池 / 独立观测量级估算**列为必填，**在跑之前**填；③ 若他拍板换区间，按 `LOSE` 判据
  重开一轮并保留本轮报告，不改数字。
