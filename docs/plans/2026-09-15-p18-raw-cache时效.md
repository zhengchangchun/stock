# P18 计划：raw_cache 当日时效缺陷修复（数据链完整性，最高优先）

日期：2026-09-15 ｜ 技能：systematic-debugging（先立反证失败测试）+ verification-before-completion
前置：ADR-009 ｜ 任务记录：`docs/tasks/2026-09-15-p18-raw-cache时效.md`

## 问题（已实测复现，证据见 ADR-009）

同一 `params_key = kline:sz000333:2026-09-15:2000:`（key 只带锚点 `end`，**不含 start**）
两次抓取，`RawCache` 保留首写：

| 文件 | `fetched_at` | 最新一根 |
|------|--------------|----------|
| `/tmp/poisoned-cache/…5cc21daad809.bin` | `2026-09-15T00:21:33+08:00` | 2026-09-14 收 86.8 |
| `data/raw_cache/tencent/…5cc21daad809.bin` | `2026-09-15T15:40:20+08:00` | 2026-09-15 收 87.23 |

→ 15:30 收盘链命中 00:21 那份 → **当日 K 线当日不落库**（09-15 真实发生，人工挪走 6 个文件才补上）。
→ 若抓取在**盘中**，未完成的盘中价会被当收盘价写进 `bars_daily`（静默污染，毁掉次日验证）。

**根因三条同时成立**：① key 不含 start；② 首写保留（B3 有意设计）；③ 缓存无时效概念。

## 范围（不许放宽，也不许扩大）

| # | 要做 | 不做 |
|---|------|------|
| 1 | 读侧：同日收盘前的条目 → 返回 None + `conflicts` 留痕 | 不改 SHA 校验 / 损坏仍抛 `CacheCorrupt` |
| 2 | 写侧：同样条件不落正式缓存 | 不改「首写保留」语义（当日规则除外） |
| 3 | 历史锚点行为**一字不变** | 不引入 TTL / max-age 通用过期机制 |
| 4 | 时钟可注入（判定只读 `fetched_at`） | 不读裸 `datetime.now()` |
| — | 只针对「同日盘中/收盘前抓到的响应被冻结」这一条路径 | **不改变收盘链现有行为**；盘中 tick 本就不联网，调度侧零改动 |

## 判据（唯一一条路径变化）

```
fetched_at 本地日 == params_key 第 3 段（锚点 end 日）
  且 (hour, minute) < (CLOSE_HOUR, CLOSE_MINUTE)      → 盘中快照
```
复用 `stocklab.session.close.CLOSE_HOUR/CLOSE_MINUTE`，比较方式同 `session/tick.py::_closed_at`。
解析不出锚点日/抓取时刻 → **判不了就不猜**，维持旧行为。
