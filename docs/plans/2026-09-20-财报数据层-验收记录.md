**PIT 验证（C5）**：

000333 在 2026-06-15 的可见报告期：

```python
from stocklab.candidate.score import load_financials
fins = load_financials(conn, "000333", asof="2026-06-15")
# → 78 期（最新期 2026-03-31，一季报，notice_date=2026-04-30）
```

- 2026H1（report_date=2026-06-30，notice_date=2026-08-29）**在 2026-06-15 不可见** ✓
- 系统使用 2026Q1 作为「本期」，中期/长期池 reason 字段均写 `"本期 2026Q1；可用因子 5/5"`

与 asof=2026-09-18 的因子差异（000333）：

| 分析期 | 2026Q1 | 2026Q2 |

**结论**：系统正确地在 2026-06-15 使用 2026Q1 数据（中报尚未公告），没有泄露未来数据。

## 已知限制（本轮明确记录）

1. **沙盒 verdict 全为 `INCONCLUSIVE`**：回放是 fail-closed 空实现，本轮演示的是版本迭代的**机制**，没有任何性能对比数据。不得把任何 INCONCLUSIVE 解读为策略有效或无效的证据。
2. **因子标注「样本内、未经验证」**：六个财务因子（ROE / 毛利率 / 毛利率变动 / 存货周转 / FCF 率 / DuPont）的有效性结论需 ≥120 交易日 walk-forward 样本 + 按日聚类 + 扣成本 + 基准对照。本轮无此数据，不得用于策略选择。
3. **横截面仅 17 只个股（其中 2 只有 bars）**：中期/长期池的横截面分位排序实际只在 17 只里做比较，不代表全市场水平。最终进入中期/长期池的 000333 和 600690 是因为有 bars 历史通过了 pre_screen，不是因为「全市场最优」。
4. **15 只标的 `insufficient_history`**：原因是 `ingest bars` 仅覆盖 DEFAULT_UNIVERSE。这不是财报系统的问题。
5. **金融股结构性 NA**：3 只银行/保险标的缺 `gross_margin` / `gm_yoy_pp` / `inv_days`，这是报表结构固有约束，不是采集失败。
6. **行业字段非 PIT**：`industry_name` 无历史快照，已在 ADR-016 D-04 显式披露。
