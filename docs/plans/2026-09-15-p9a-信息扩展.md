## 1. 设计决策

### 1.1 为什么三条信息全部走「条件化 sigma」这一条通道

`rw-mu0` 已证明 `mu` 本身几乎没有方向信息（置 0 反而方向显著变差 = 基线的 `mu` 也**不是** edge，
只是把概率质量从一个尾部搬到另一个尾部）。把量能接成「条件化 `mu` 幅度」在机制上是**同一个
噪声项再乘一个系数**，可预期的信息量更低，而且它要新增一个 `mu_mode` 取值
（改动既有 `MU_MODES` 契约）。三条信息有一个**共同且机制明确**的落点：**波动率状态**。

- 波动率聚集（vol clustering）是金融时间序列里最稳健的典型事实：今天的 RV 能预测明天的 RV。
  基线的 `sigma` 是 **60 日无条件样本标准差**，它把「当前处于高/低波动状态」这件事**平均掉了**。
  用 PIT 可观测的状态分位去缩放它，是对**校准度（Brier）**的一个有理论支撑的改进。
- 三条信息对应三个**互不相同**的 PIT 量：
  1. **量能**：`volume` 相对自身近期均值的 z-score → 经标准正态 CDF 映射成 (0,1) 分位
     （mixure-of-distributions：成交量与波动率同向）。
  2. **自身波动率状态**：20 日已实现波动率在**自身**过去 250 个交易日 RV 中的分位。
  3. **指数状态**：`sh000300` 的 20 日 RV 在自身过去 250 日 RV 中的分位（市场级状态，
     与个股自身的 RV 相关但不相同）。**只取波动率，不取方向** —— 方向那条路已由
     `index-mom-dir` 否证，不重复。

于是三条变体**改的是同一个字段** `sigma_mode` 的三个不同取值。这不是「一次改三个变量」：
每个变体相对基线**恰好改 1 个字段**，`assert_single_variable()` 仍然机械强制。

> **降级说明（提前写死，避免下一轮重复）**：本轮**没有**测「条件化 `mu` 幅度」的变体。
> 理由是 `mu` 已被 `rw-mu0` 否证，且改它要动 `MU_MODES` 契约；若本轮 sigma 通道也没有增量，
> 下一轮应优先换**信息源**（例如更长历史 / 更快频率），而不是再调 `mu` 的系数。

### 1.2 缩放公式：先验固定，**不做参数搜索**

```
factor = SIGMA_SCALE_MIN + (SIGMA_SCALE_MAX - SIGMA_SCALE_MIN) × q      # q ∈ [0,1]
sigma  = sigma_base × factor
SIGMA_SCALE_MIN = 0.5   SIGMA_SCALE_MAX = 1.5
```

- 无窗口搜索、无系数拟合：`0.5 / 1.5` 是**先验固定**的对称带宽（±50%），不是调出来的。
  改它就是第二个变量，本轮禁止。
- `q` 的三种来源都天然落在 `[0,1]`：`vol_z → Φ(z)`；RV 分位 → `(# ≤ 当前)/N`。
- `q = None`（历史不足 / 量能缺口）→ `DegenerateInput`，**该行对变体侧不可评分**，
  在 `skipped` 里计数 —— 不许静默当成 0 或 1。

### 1.3 结构上守住三件事

1. **默认路径零改动**：`sigma_mode` 默认 `"const"`，`compute_forecast` 里走
   `if sigma_mode != "const":` 分支 —— 基线（`spec=None`）连 `features` 都不读，
   报告 sha256 `a61d026b…f4eb` 必须逐字节不变。
2. **`amount` / `turnover` 结构上不可用**：特征模块的 **AST 里不出现这两个属性名**
   （测试直接扫 AST，不靠自觉）；另外有一条行为测试：把这两列改成 `None` 或改成天文数字，
   特征值必须**逐位不变**。
3. **PIT 靠「函数签名拿不到未来」**：每个特征函数第一件事就是裁掉 `> asof` 的行；
   有「塞一根未来暴涨 bar → 值纹丝不动」的测试 + 一条**正向对照**（故意注入前视实现，
   断言值确实变了），证明这组断言真有鉴别力。变异 `mutations_p8.py#5` 把裁剪打掉 → 必须变红。

## 3. 预注册要点（**先写台账，后跑**）

- 每份台账写死：唯一变量、基线值、变体值、**可证伪的预测**、**失效条件**、多重比较声明。
- **多重比较处理**：本轮 3 个变体共享**同一段 validate**（同交易日、同标的、同标签带），
  彼此不独立 → **不做 Bonferroni 校正**；因此**任何**变体的 validate `WIN` 一律**不直接晋级**，
  只记为待复现信号，须下一轮同变体同判据不调参复现。
- **test 一律不打开**：本轮 CLI 用 `--keep-test-sealed`，即使 validate `WIN` 也不读封存段
  （「是否开 test」留给下一轮）。
- 可比对手：`always_up` / `always_down`（PIT 口径）。**不把 `sh000300` 当预测对手**
  （P8 已判定同窗口/含未来信息/不可交易）。

## 4. 风险与反方预期（提前写死）

- **最可能的真实结果**：Brier 显著改善、方向不动 → gate `FLAT` → `inconclusive`。
  这个结果**有信息**（校准可改善、方向无增量），必须如实分开报，**不许**把 Brier 的改善
  说成「赢了」。
- **反方预期**：基线 sigma 是 60 日窗，本身已经是波动率的平滑估计；RV20 分位带来的增量
  可能落在噪声里（`FLAT`）甚至变差（`LOSE`，过度自信）。真出现 `LOSE` 就是**否证**。
- **不许**：用 validate 反复调到 `WIN`（同一变体只跑一次）、改口径、挪 split、删既有失败记录。
