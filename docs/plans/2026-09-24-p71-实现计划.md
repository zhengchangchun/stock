## 硬约束（实现时守住）

1. **不联网**：测试一律假 fetcher / fixture；`HttpClient` 只在 `universe build`（nanobot 侧）真实调用。
2. **不写真库**：`sync`/`doctor` 实测只在 `/tmp` 副本上；真库一律 `mode=ro&immutable=1`。
3. **默认路径逐位不变**：`paper/**`、`m2/**`、`plugin/**` 零行为变化；红线三目标**不 regen**。
4. **不改主干常量语义**：`SEED_UNIVERSE` / `SEED_CODES` / `DEFAULT_UNIVERSE` / `ETF_WHITELIST` 取值不动。
5. **提交纪律**：只用**显式路径**；`docs/` 与代码分开提交。
