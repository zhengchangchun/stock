# P69 模拟操盘可见性 · 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development 或
> superpowers:executing-plans 逐任务执行。步骤用 `- [ ]` 复选框跟踪。

**Goal:** 把「谁在跑 / 跑了什么 / 赚了多少 / 口径哪天变过」四件事变成 `/lab/paper` 上可读的，
同时修掉「占位臂每天制造假警 ⇒ 日更退出码恒 1」的结构性缺陷 —— 不新增任何写入口、不新增第二套口径。

**Architecture:** 三处小改 + 一处新取数 + 一处新渲染。
① `paper agent run` 加 `--arm` 纯选择器（默认路径逐字段不变）；
② `params_json.live`（缺省 `true`）给出「停飞」显式位，`agent_claim_accounts` 与
`decision_expectation` 读它；
③ 页面标签/颜色/顺序改成**按 `params.executor` + 台账**分档（不再按 `arm=='agent'` 一刀切），
家族按前缀纳入；
④ 新增「AI 操盘手」专节，取数 `paper_data._agent_ops`（只复用 `track` 已建好的 `arms` /
`performance` 与 `store.load_nav` / `paper_agent_decisions` / `plugin_scripts`，一列新口径都不造）。

**Tech Stack:** Python 3.12（`.venv/bin/python`）、sqlite3、pytest、自研 HTML 渲染（无框架）。

## Global Constraints

- 真库 `data/stocklab.db` **全程只读**（`sqlite3.connect(f"file:{DB_PATH}?mode=ro", uri=True)`）；
  任何写入只在 **库副本** 上做（副本放 `/tmp`）。
- **不改**：账本/决策/成本/PIT 语义、`CLOSE_STEPS`、任何主干常量（`paper/config.py` 的数值）、
  红线基线（`docs/baselines/redlines.json` 三目标 **逐位不变**，不得 `--regen`）。
- **不加任何写入口**；页面永远只读。
- **不新增第二套「AI 臂收益」口径**：净值/盈亏一律读 `paper_nav_daily` 的列或复用
  `paper.engine` 既有函数（`build_report` / `agent_block` / `store.load_nav`）。
- 提交只用**显式路径**（禁 `git add -A` / `git commit -a`）；每个逻辑单元一个 commit，
  message 带 `P69`。
- 测试命令：`.venv/bin/python -m pytest -q`（解释器固定 `.venv/bin/python`）。

```python
def agent_run(conn, asof, *, now, arms: Sequence[str] | None = None) -> dict:
    claim = agent_claim_accounts(conn)
    if arms:                                  # 纯选择器：默认路径（arms=None）逐字段不变
        wanted = list(dict.fromkeys(str(a) for a in arms))   # 可重复传参 ⇒ 去重保序
        known = {str(a["account_id"]) for a in claim}
        unknown = [a for a in wanted if a not in known]
        if unknown:
            raise PaperError(
                f"--arm 点名的账户不在本命令的认领范围：{unknown}。"
                f"`{EXECUTOR_KEY}={EXECUTOR_AGENT_DECISION}` 的**在飞**账户只有 "
                f"{sorted(known)} —— 停飞账户（params.{LIVE_KEY}=false）与别的执行者"
                f"（如通路 A）不由本命令落日终。**不静默跳过**")
        keep = set(wanted)
        claim = [a for a in claim if str(a["account_id"]) in keep]
    if not claim:
        raise PaperError(...)   # 既有措辞不变
```
（`agent_run` 的其余部分一字不动：`decision_expectation` / `_step_all` / 平盘分支 / `already`。）

```python
# config.py
LIVE_KEY: str = "live"
HALTED_LABEL: str = "历史版本（已停飞）"

# engine.py
def live_of(params: Mapping) -> bool:
    value = params.get(LIVE_KEY)
    if value is None:
        return True                      # 缺省在飞：老账户不加键也照跑
    if not isinstance(value, bool):
        raise PaperError(
            f"params.{LIVE_KEY} 必须是布尔（现在 {value!r}）—— "
            f"写成字符串会让「停飞」被读成「在飞」，这是**假警的反面**：漏报")
    return value

def is_live(account: Mapping) -> bool:
    return live_of(json.loads(account["params_json"]) or {})

def decision_expectation(conn, *, account, asof) -> dict:
    day = is_trading_day(conn, asof)
    live = is_live(account)
    in_flight = live and asof >= str(account["start_date"])
    return {"asof": asof, **day, "live": live, "account_in_flight": in_flight,
            "expected": bool(day["is_trading_day"]) and in_flight}

def agent_claim_accounts(conn) -> list[dict]:
    return [a for a in store.load_accounts(conn)
            if executor_kind(a) == EXECUTOR_AGENT_DECISION and is_live(a)]
```
迁移：目标由「**逐条点名**」给定（`arm-agent`、`arm-agent-ds-v1`），不按 kind 批量 ——
停飞是**每条臂的账**，写进迁移常量 `_P69_HALTED_ARMS` 并注明理由。
