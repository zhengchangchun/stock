## 1. 为什么这个需求要「先定口径再写代码」

凯利公式是本项目里**最容易自欺**的东西：它看起来像一个「告诉你该买多少」的答案，实际上它的
输出完全由输入决定 —— 而输入（胜率 p、赔率 b）恰恰是我们**测不出来**的那部分。本项目已有的
硬事实：

- `pit-rw-v1.0.1` 方向能力 ≈ 0（行级 38.14%，按日聚类 CI 0.3819 ± 0.0070；Brier 0.6581 vs 随机 0.667）；
- 已否证三条变体（`rw-mu0` / `index-mom-dir` / sigma 系列），趋势状态标签**不预测方向**（Δ 不显著）；
- 唯一站得住的量化事实是 `range_80` 覆盖率 81.68%（校准）与趋势状态的**波动分层**。

因此：**严格凯利在本项目上的正确答案是「不下注」**（f* ≤ 0）。把它写进程序，第一价值不是
「算出一个仓位」，而是**当一个诚实的不下注开关**：它逼着人先拿证据说话。任何让输出看起来
「有仓位」的实现（手设 p=0.55、挑样本内窗口、拿 `invalidated` 子群当胜率）**一律禁止**。

## 2. 落地范围（只做这些）

### 2.1 `stocklab/risk/kelly.py` —— 凯利核心

| 项 | 口径（写死，可单测） |
|---|---|
| 二元凯利 | `f* = p − (1−p)/b`；盈亏平衡 `p_be = 1/(1+b)` |
| 连续近似 | `f* ≈ μ_over / σ²`（同一频率；μ 为超额收益均值，σ 为该频率收益标准差） |
| 保守化（强制） | `p_used` = 历史胜率的 **Wilson 95% 单侧下界**（不用点估）；`b_used` = 赢的幅度分布的 **下四分位** ÷ 亏的幅度分布的 **上四分位**（对赢打折、对亏加码） |
| NO_BET 规则 | `p_used ≤ p_be` → `f* = 0`，`verdict = "NO_BET"`，`reason = "edge_not_significant"`，并在 JSON 顶层给 `edge_significant: false` |
| 分数凯利 | `f = k · f*`，`k` 默认 **0.25**（可选 0.5 / 1.0），非 0.25 时输出 `fractional_kelly` 说明 |
| 过注保护 | `f > 2·f*` → 期望对数增长为负 → **硬拒绝**（clip 到 `2·f*` 并给 `overbet_rejected` 警告） |
| 上限 | `f_cap` 默认 = 单票上限 **0.40**（用户纪律）；`0 ≤ f ≤ f_cap`，无杠杆、无负仓位 |
| 输出 | 稳定 JSON：`{p_used, p_point, p_be, b_used, f_star, k, f_fractional, f_cap, f_final, verdict, edge_significant, warnings[], inputs{rule, window, n, cost_bps}}` |

**p/b 的来源（唯一合法路径）**：由 CLI 参数指定的**明确规则** `--rule` 在 PIT 历史数据上回放统计，
且**必须扣成本**（往返 0.27%，含滑点），**必须按日聚类给 CI**，**必须报样本量**（<120 交易日 →
`sample_gate.meets=false`，并且**不允许**据此下注）。内置规则（PIT，无未来函数）：

- `trend-state`：状态从非 UP 转 UP 时买入，转出 UP 时卖出（默认；与我们已测的状态标签同源）
- `ma-cross`：MA20 上穿 MA60 买入、下穿卖出
- `buy-hold`：买入并持有（作对照，给「无择时」的 p/b 基准）

### 2.2 `stocklab/risk/sizing.py` —— 仓位与硬约束裁剪

输入：`f_final`、总资产、现金、现价、现有持仓、最小单位 100 股。
输出：`suggested_shares`（`floor(f·总资产/(price·100))·100`，不足 1 手 → 0 并说明）、
`binding_constraints[]`（**逐条说明哪条约束把数字压下来了**）、`cash_after`、`position_pct_after`。

叠加的硬约束（用户的真实纪律，逐条 clip，不许静默取最小值）：

| 约束 | 阈值 |
|---|---|
| 单票市值占比 | ≤ 40% 总资产 |
| 现金目标带 | ≥ 45%（买入后跌破则削减买入量） |
| 单次动用现金 | ≤ 总资产 5% |
| 追高禁止 | 现价 ≥ 87.00 → 禁止加仓（规则，非公式） |
| 整手 | 100 股整数倍 |

### 2.3 `stocklab/risk/metrics.py` —— 风险预算指标（PIT，只用 ≤asof 数据）

- 20 日 RV（年化）、历史法 **VaR95 / CVaR95**（5 日视界，经验分位，声明样本量与窗口）；
- 最大回撤（近 250 交易日 / 上市至今）、索提诺、Calmar；
- **波动率目标仓位** `w = target_vol / realized_vol`，clip `[0,1]`，`target_vol` 默认 15%；
- **破产风险**（fixed-fractional 简化式）`R ≈ ((1−A)/(1+A))^U`，`A` = 每单位保守 edge（可为 0），
  `U` = 可用单位数（总资产 / 单次风险额）；**`A ≤ 0` → 输出 `R = 1.0` 并标注「长期必败」**（诚实输出）。

### 2.4 `stocklab/risk/stops.py` —— 止损位并列（描述，不预测）

并列显示并标出**哪个先触发**与距现价 %：纪律止损 `85.00`（收盘口径）/ `83.25`（周线口径）；
`MA60`（当前 83.50，与周线止损几乎重合，必须显式指出）；`ATR(14)` 止损 `close − 2·ATR14`。
