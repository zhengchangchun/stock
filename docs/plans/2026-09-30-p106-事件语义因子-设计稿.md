## 3. EV-B 构造定义（逐字公式，冻结）

> 形状**完全沿用 P95 §5.4**，不新增构造。

**主读数（哑变量，`kind="main"`）**

```
ev_<类>(code, asof) = 1  if  count( a ∈ announcements :
                                     a.code = code
                                 ∧   a.notice_date ∈ W20(asof)
                                 ∧   a.column_name ∈ TABLE_<类> ) > 0
                    = 0  otherwise
```

**次读数（同窗计数，`kind="secondary"`，只报不判）**

```
ev_<类>_n(code, asof) = count( 同上 )
```

**`W20(asof)`** ＝ 以 `trading_calendar.is_open=1` 的日期序列取 **`<= asof` 的最后 20 个交易日**，
窗口 = `[第 20 个交易日的日期, asof]`**闭区间两端**（与 `ann_count_5d` 的 `(asof − 5 个交易日, asof]` 同族写法）。

| 口径项 | 取值（冻结） |
|---|---|
| PIT 锚 | `notice_date <= asof`（**含当日**，DDL 明写的锚）；`display_time` **不得**参与筛选 |
| 日内歧义 | 源站会列出**次日**公告（P95 §5.4 实测 `000333`：`notice_date=2026-09-28` 而当日为 09-27）⇒ 稳健性读数用 `notice_date < asof` **只报不判**（独立列，不许事后切换） |
| 缺失语义 | **真 `0`，不是 `None`**（与 `ann_count_5d` 同规，与 `mf_ratio_5d`/`ep_ttm`/… 的「算不出 ⇒ `None`」**相反**）—— 必须在预注册里**显式点名这个例外** |
| 极值 | 哑变量无极端值；计数次读数不截断、不透视（只报） |
| 单位 / 符号 | 无量纲；符号先验**不设**（回购/增持/分红预期为正、质押/诉讼/处罚预期为负 ⇒ **分别报，不做符号合并**） |
| 停牌/无公告代码 | 真 0（不是缺失）；`announcements` 未覆盖的代码也判真 0 |

**为什么 20 交易日窗**：P95 §5.4 已写死该窗（本稿不改形状）。代价＝与 5 个交易日一次的调仓节奏
**高度重叠**（相邻 mark 共享 15/20 = 75% 的窗）⇒ 由 §6 的**重叠折扣门**处置，**不改窗口**。

## 5. 度量口径与判定（冻结，全部预先写死）

### 5.1 一次跑完 12 个（**这是纪律，不是优化**）

```
research factor-ic --pool short --start <S> --end <E> --universe csi300-500 \
    --prereg docs/experiments/<date>-event-factors-csi300-500.md \
    --factor ev_buyback --factor ev_holdings_change --factor ev_pledge \
    --factor ev_equity_incentive --factor ev_major_contract --factor ev_litigation \
    --factor ev_related_party --factor ev_dividend --factor ev_institution_research \
    --factor ev_auditor_change --factor ev_earnings_forecast --factor ev_regulatory \
    --out reports/research/
```

- 一次命令 ⇒ 12 个读数**共享**同一套打分与远期收益重算（12 次分跑的 CPU 是 12×≈3.7 h，本机不可接受）。
- 预注册的 `factors` 键必须**逐位 == `MAIN_FACTORS + 12 个 selected`**（P97 的 fail-closed 规则，不许绕）。
- `ann_count_5d`（EV-A，已在册）**不计入本 family**，但要在报告里**并排展示**作为对照
  （P98 #4 已读：IC +0.0053、95% CI 跨 0）。

### 5.2 四条门（**全部通过**才可进 stage-2）

| 门 | 判据 | 不过的处置 |
|---|---|---|
| **① 覆盖门** | 验证段内 `prevalence > 0` 的日期数 **≥ 120** | `INCONCLUSIVE`（**不许**用全窗读数替代） |
| **② 显著门（family 校正）** | IC > 0 且 **重叠折扣后**的 95% CI 排除 0，且 `α/12` 水准下显著 | `NOT_SIGNIFICANT` |
| **③ 分辨率门** | `tie_ratio_p50 ≤ 0.90`；> 0.90 记 `LOW_RESOLUTION` | 该类的哑变量读数**不足为凭** ⇒ 需**计数次读数同向且显著**才可继续 |
| **④ 冗余门** | 与既有注册因子的**平均横截面秩相关** `ρ̄ ≤ 0.70` | 记 `REDUNDANT`（⚠️ **此门当前未实现**，见 §5.4） |

**Bonferroni 是主判据**（`α/12 = 0.004167`）；Benjamini–Hochberg FDR 只作**参考列**，不许用它放宽判定。

### 5.3 重叠折扣门（本稿新增的保守修正，必须写进预注册）

- 问题：调仓每 **5** 个交易日一次、窗口 **20** 个交易日 ⇒ 相邻两期共享 **75%** 的窗，
  IC 序列**高度自相关**；`signal.py` 的 `std/√n` 置信区间**假设日期独立** ⇒ 会**系统性高估**显著性。
- 冻结修正：**`n_eff = n_dates × 5/20 = n_dates / 4`**（每个 20 日块只算一次，保守到「宁可放过」）。
  判定用**折扣后**的 CI；报告里**同时打印原始 CI 与折扣 CI**，并写明「原始 CI 仅供参考、不作判定」。
- 明确不做的：不做 Newey–West / 块自助（超范围）；**不许**因为折扣后全不显著就回来改折扣系数。

### 5.4 一个已知缺口（必须由 P107 补齐，不许默默跳过）

审计 §8 已点名：**「冗余门 `ρ̄` 至今没有实现」**（4 条历史候选都记「缺口未执行」）。
⇒ P107 的**验收判据里包含**：对任何通过 ①②③ 的类，**必须**并排给出
`ρ̄ = mean_{f ∈ 既有注册因子}( |Spearman_cross_section(ev_类, f)| )`（逐调仓日算、再取中位数），
并给出是否 ≤ 0.70 的判定。**实现方式不限**（可落在 `research/factor.py` 的只读辅助函数里，
不得改 `candidate/` 打分载荷形状）。若某类无任一读数是显著的，则本门**如实记 `SKIPPED`**（不是 pass）。

### 5.5 判定词的执法边界

- `NOT_SIGNIFICANT` **只能**读成「**在这套构造与这个池上，没有可测的排序能力**」；
- **不许**读成「事件类信息无效」「公告没用」——度量的是「**20 日窗二值化的截面排序能力**」，
  既不是事件本身的信息量，也不是事件研究法的超额收益；
- **不许**把 12 个读数里最大的那个单拎出来当结论（family 校正的全部含义就是禁止这件事）；
- 窗口/切分/构造**一个字都不许事后改**；改 = 新一轮预注册 + 新 family 编号。
