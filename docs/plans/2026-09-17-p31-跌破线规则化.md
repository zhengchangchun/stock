# P31 —— 000333 跌破线从拍数 85.00 换成有依据的规则值

- 日期：2026-09-17
- 状态：已接受（口径变更，用户 2026-09-16 晚直接要求）

## 背景

`discipline.PER_CODE_LINES['000333']['stop_loss_close'] = 85.00` 是**拍脑袋**的数：
仓库里只有值、没有任何公式/推导（唯一注释是「围绕 86.80 建仓价定的」，那只是
事后对「-2.07%」的再描述，不是生成规则）。用户要求换成**有依据的规则值**。

## 决策（规则）

`stop_loss_close = MA60 − 1×ATR14`，全部用 `bars_daily` 的**不复权**（`adj_mode='none'`）日 K：

- `MA60` = 近 60 根不复权收盘价的**简单均值**；
- `ATR14` = 近 14 根 **True Range** 的**简单均值**（不是 Wilder 平滑）——
  `TR = max(H−L, |H−C₋₁|, |L−C₋₁|)`，首根退化为 H−L（与 `stocklab/risk/stops.py` 同口径）；
- asof = `bars_daily` 里 000333 的**最新 bar 日期**。

## 实测值（asof = 2026-09-16）

- MA60 = **83.7893**
- ATR14 = **1.6521**
- 目标线 = 83.7893 − 1.6521 = 82.1372 → **82.14**

> 参考值 nanobot 曾估「82.10 = 83.79 − 1.65」，但 83.79 − 1.65 = **82.14**，
> 参考值自身算术不自洽（少算了 0.04）。以复算的 **82.14** 为准，如实记录不一致。

## 误触频率（规则灵敏度，**不是**准确率/收益结论）

「收盘 < 该线」的单日频率，见 ADR-012 §误触证据。要点：

- 用**固定线 82.14** 去量不复权全历史 → 94.67%（全历史）/ 77.20%（近 250 日）——
  **这个数字无意义**：不复权序列有除权除息造成的历史价格水平跳变（16.57–107.11），
  早期股价天然低于 82，固定线频率测的是「当时股价更便宜」，不是「跟踪止损会触发」。
- 有意义的**规则灵敏度**是每天用 asof 当时可见的 MA60−ATR14 重算线（trailing）：
  **30.59%（全历史）/ 11.20%（近 250 日）**；其中近 250 日窗口内无除权除息，数字干净，
  全历史数字同样被除权跳变污染。

## 异常与取舍（如实指出）

1. 当前收盘 85.00，新线 82.14，距现价 **−2.86 元 / −3.36%**——没在今天就跌破，缓冲合理。
2. **日线/周线顺序倒挂**：原设计日线（85.00，−2.07%）比周线（83.25，−4.09%）**更紧**；
   新日线 82.14（−5.37%）比未动的周线 83.25 **更松**，顺序反转。
   周线线先**保持不动**（口径变更需用户点头）；建议值见 ADR-012 §周线线未动的说明：
   `MA60 − 2×ATR14 = 80.49`（与 `risk/stops.py` 的 `ATR_MULT=2.0` 同口径，恢复日紧周松）。
