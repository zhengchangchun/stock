# 计划：P4 前置 —— 复权因子链（扫清「回测收益失真」）

- 日期：2026-09-15
- 前置：ADR-001 §复权方案（落不复权 OHLC + 自建 PIT 因子链）
- 探针证据：`docs/decisions/evidence/probe-corp-actions-2026-09-15.json`
- 决策：`docs/decisions/2026-09-15-ADR-004-复权落点.md`

## 背景（为什么必须先做）

`adj_factors` 表为空、无采集/读取路径，而 P3 特征层在**不复权价**上算 `ret_1d/ma/atr`。
除权日会产生假跌幅 → P4 回测收益失真 → 之后所有准确率数字不可信。

## 探针实测结论（决定实现方案的 4 条）

| # | 发现 | 对方案的影响 |
|---|------|-------------|
| 1 | `adj=none`（不复权）响应**也带事件行**（行尾第 7 元素 dict，字段 `cqr/djr/fh_sh/FHcontent/nd`） | 事件从**不复权流**取：2000/页，000333 2 次请求；qfq 需 4~5 次且受 800 上限 |
| 2 | `qfq` 请求 801/900/2000 实测均**静默夹到 800**（ADR-003 记的 640 已复现不出） | 上游静默降级**行为本身不稳定** → 客户端硬守卫（`MAX_QFQ_COUNT=800`）必须保留 |
| 3 | 腾讯 qfq 是**减法式**（原价 − 累计每股派息）：000333 2013-09-18 = **-12.649 元** | qfq 序列**不可用于比率类特征**（负价跨零点）；自建**乘性**因子链是唯一可行方案 |
| 4 | `fh_sh` 不可信：2014/2015 事件是**税后值**（20→19、10→9.5）；送转-only 事件**为空**（600690 因此被现有解析器**静默丢弃 9/36 条**） | 事件条款以 `FHcontent` 原文为准；`fh_sh` 仅作交叉校验并留痕 |

## 交付物与任务拆分

**Task A — 探针 + ADR-004**（已完成）
- `scripts/probe_corp_actions.py`（联网，非测试套）
- `docs/decisions/evidence/probe-corp-actions-2026-09-15.json`
- `docs/decisions/2026-09-15-ADR-004-复权落点.md`

**Task B — 事件采集**
- `tencent.parse_corp_actions`：改为**按 `cqr` 存在与否**识别事件（`fh_sh` 可缺）；
  从**不复权**流解析（`adj_mode="none"`）。
- `data/fetch.py::fetch_corp_actions`：复用 `end` 锚点翻页（2000/页），不走 qfq。
- `schema.sql` 新增 `corp_actions`（PK `(code, cqr)`）。
- `repo.insert_corp_actions`：幂等 upsert，**保留 `first_seen`**，返回被修订条数。

**Task C — PIT 因子链**
- `stocklab/data/adjust.py`（纯函数）：
  - `parse_terms(content)` → `(cash_per_share, share_ratio)`，无法解析**抛错**（禁静默）
  - `event_factor(pre_close, terms)` = `(pre - cash) / (pre * (1 + share))`（现金-only 时退化为 ADR-001 的 `1 - cash/pre`）
  - `build_factor_chain(dates, events_with_k)` → `{date: Π_{cqr<=date} k}`（**PIT 唯一防线**）
- `repo.insert_adj_factors` 落 `adj_factors`（全量重算、幂等）。

**Task D — 复权读取层**
- `load_bars_adjusted(conn, code, as_of)` → `multiplier(t) = factor(as_of)/factor(t)`，
  `Bar.adj_mode="qfq"`（**写入路径会自动拒绝它**，见 `insert_bars` 守卫）。
- 缺因子 → `MissingFactorError`，**禁止回退到不复权**（ERROR_DIARY 2026-09-14）。

**Task E — 特征层切换**
- `registry.FEATURE_VERSION` `v1 → v2`（旧快照不覆盖，append-only 天然隔离）。
- `cmd_features_build`：先复权再 `build_snapshot`；复权失败 → 记 warn + skip。
- 新增 `ingest actions` CLI 子命令。

## 验收方式（每条都要贴真实输出）

1. `.venv/bin/python -m pytest` 全绿且用例数 ≥ 293
2. `unshare -n .venv/bin/python -m pytest` 全绿
3. `bash scripts/verify.sh`
4. **除权日反证**：`test_ex_dividend_day_has_no_fake_drop` —— 同一份 K 线，
   不复权 `ret_1d ≈ -X%`，复权后 `ret_1d ≈ 0`；并断言「用不复权就是假跌幅」这一失败模式
5. **PIT 反证**：`test_future_event_does_not_affect_past_factor` —— 注入 `cqr > T` 的事件，
   T 日因子与复权价**逐位不变**（先真红后绿）
6. **真实数据**：000333 / 600690 采集事件条数 + 除权日复权前后 `ret_1d` 对比 + 覆盖区间/缺口
