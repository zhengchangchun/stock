## 0. 背景

### 0.1 一句话

用户 2026-09-26 要求 AI 操盘手具备「**不断分析市场、复盘总结自己**」的能力。
P84 已经把「市场状态」与「自己的历史」写进 PIT 上下文（`market` / `own_history` 块）。
本站补**另一半**：让 AI 能把「对上一笔决策的复盘」**写进 append-only 台账**，且**每句必须带可在库里
核对的证据指针**（读数不许编），并把**重复出现、已被确认过的教训**作为「事实」回注到下一轮上下文。

一条硬口径：**复盘是文字与读数，不是参数**。AI 不许通过复盘改公式/改参数/做参数搜索
（`rules.py` 的五字段白名单与执行层常量一动不动）。

### 0.3 不许回退的口径

1. append-only：新表两只触发器；旧表**一个字不改**。
2. PIT：复盘只能引用 `date/asof <= 复盘日` 的行。
3. 确定性：`facts`（已确认事实）是**纯函数**（同库同 arm ⇒ 同结果，不含时间戳/自增 id）。
4. 执行层零改动：`paper/rules.py`、`paper/config.py` 既有常量、`paper/engine.py` 的执行函数
   （`plan_orders` / `plan_target_weight` / `_settle` / `_gate_cash` / `tradable_verdict` /
   `max_lots_affordable` / `min_weight_pct`）**一个字不改**。
5. 本仓 `paper/` 只许 import `calendar/config/costs/paper/portfolio` 一族 + stdlib。

## 0.5 锁定口径（K1–K8；要改先回来说）

- **K1 新表 `paper_agent_reviews`**（append-only，列逐字如下）：

  ```
  review_id      INTEGER PRIMARY KEY AUTOINCREMENT
  arm            TEXT NOT NULL
  asof           TEXT NOT NULL          -- 被复盘的那个交易日（= 复盘日）
  kind           TEXT NOT NULL          -- 本期唯一值 'daily'（留扩展位）
  model_id       TEXT NOT NULL
  prompt_sha256  TEXT NOT NULL
  context_sha256 TEXT NOT NULL          -- 写这条复盘时所依据的上下文的指纹
  n_items        INTEGER NOT NULL
  n_lessons      INTEGER NOT NULL
  payload_json   TEXT NOT NULL          -- 全文（见 K2）
  created_at     TEXT NOT NULL
  UNIQUE(arm, asof, kind)
  ```

  幂等键 `(arm, asof, kind)`；重复写入 ⇒ **exit 1（conflict）**，零写入。
  迁移函数 `migrate_p85_agent_reviews(conn)`（幂等，重入返回 `[]`），**只加表与触发器，不改任何既有表**。
- **K2 载荷 schema（结构校验 fail-closed，`additionalProperties: false`）**：

  ```json
  {"asof": "2026-09-24", "arm": "arm-agent-ds-v3", "kind": "daily",
   "items":[{"claim":"…",
             "evidence":{"kind":"decision","decision_id":4}},
            {"claim":"…","evidence":{"kind":"trade","trade_id":3}},
            {"claim":"…","evidence":{"kind":"metric","metric":"cum_return","date":"2026-09-24","value":-0.022316}},
            {"claim":"…","evidence":{"kind":"market","field":"breadth.up_ratio","date":"2026-09-24","value":0.61}}],
   "lessons":[{"key":"lot_floor_small_account","kind":"fact","text":"…"}]}
  ```

  - `evidence.kind ∈ {decision, trade, metric, market}`；四种指针的校验见 K3。
  - `claim` / `text` 非空字符串（`text` ≤ 200 字）；`lessons[].key` 为 `[a-z0-9_]{3,48}`；
    `lessons[].kind ∈ {fact, habit}`；**除表里这些键，别处一律不许加键**（越界即 exit 2）。
- **K3 证据指针必须能在库里核到**（**这是本站最核心的判据**；任一不成立 ⇒ exit 2、零写入）：

  | kind | 校验 |
  | --- | --- |
  | `decision` | `paper_agent_decisions` 存在该 `decision_id`、`arm` 相符、`asof <= 复盘日` |
  | `trade` | `paper_trades` 存在该 `trade_id`、`account_id == arm`、`date <= 复盘日` |
  | `metric` | `metric ∈ {nav, cash, market_value, cum_return, cum_cost, drawdown, net_deposits}`；该臂 `paper_nav_daily` 里存在 `date == evidence.date（缺省 ⇒ <= 复盘日的最近一行）`；**`value` 必须与库里读数一致（容差 1e-6）** |
  | `market` | `field` 必须在**当日 `market` 块**的实际字段路径白名单里（由 `market_block` 的键**动态**枚举，不许手抄）；`value` 与该字段一致（容差 1e-6；百分比字段用 `round(x,4)` 后的值） |

  「读数不许编」这条要**真的挡住**：用例必须包含「`value` 差 0.01 ⇒ exit 2」、「引用不存在的
  `decision_id` ⇒ exit 2」、「引用 `asof` 之后的决策 ⇒ exit 2」、「`market.field` 不存在 ⇒ exit 2」。
- **K4 `facts`（已确认教训）＝纯函数**：
  从该 arm **全部** `kind='daily'` 的复盘里，按 `lessons[].key` 聚合；
  **同一 `key` 出现在 ≥2 条不同 `asof` 的复盘里 ⇒ 该 key 进 `facts`**（`text` 取**最新**一条，
  并在 `seen_at` 里列全部 `asof` 升序）。`facts` ≤ 10 条（超出按 `seen_at` 条数降序、再按 `key`
  字典序截断，**截断数写进 `n_facts_truncated`**）。同一 `key` 在不同复盘里 `text` 不一致 ⇒
  `"conflict": true` 且两条 `text` 都列出（**不取平均、不猜**）。
- **K5 回注位置**：`own_history` 块内新增两个子键（**顶层键集不变**、`DECISION_HASHED_KEYS` 不动）：

  ```
  own_history.recent_reviews = [ {"asof","kind","context_sha256","n_items","n_lessons",
                                  "items":[{"claim","evidence"}],        # 原样搬运
                                  "lessons":[{"key","kind","text"}]} ]   # 最近 ≤3 条，升序
  own_history.facts          = [ {"key","text","seen_at":["…"],"conflict":false} ]  # ≤10 条
  ```

  两块都受 PIT 约束（`asof <= 决策日`）并**进** `decision_context_sha256`（因为 `own_history`
  已经在指纹里 —— 用例钉住：给 `asof` 之后加一条复盘 ⇒ 指纹不变）。
- **K6 复盘是文字，不是参数**：载荷里**没有**任何「改参数/改公式/改权重上下限」的字段（K2 的
  `additionalProperties: false` 从结构上堵住）；`facts` 只以**文本**进入上下文；
  `agent_spec.SPEC_SCHEMA` 与执行层常量零改动。`NON_GOALS` 追加一条（逐字）：

  > `"复盘只写文字与读数：教训（facts）是**经验陈述**，不许当成参数改动的载体 ——"`
  > `"五字段白名单、成本口径、整手口径、熔断阈值都不在复盘的触达范围内"`

- **K7 CLI（只增子命令，既有子命令 stdout 键集不动）**：

  ```
  paper agent review  --asof <YYYY-MM-DD> --arm <arm> --file <review.json>
                      [--model-id <s>] [--prompt-sha256 <64hex>]
  paper agent reviews --arm <arm> [--limit N]     # 只读列出（JSON，含 payload 全文）
  paper agent facts   --arm <arm>                 # 只读打印 K4 的 facts（确定性）
  ```

  `review` 成功 ⇒ stdout 一行 JSON：`{"written": true, "review_id": N, "arm":…, "asof":…,
  "n_items":N, "n_lessons":N, "facts":N, "context_sha256":…}`（`context_sha256` 由
  `decision_context_for(conn, arm=arm, asof=asof)` 现算，**不信调用方**）。退出码 = §0.2 约定。
- **K8 `own_history` 只增子键**：既有键（`nav_series` / `trades` / `decisions` / `n_*` /
  `realized_fees_total` / `notes`）**逐位不变**；新子键放最后。
