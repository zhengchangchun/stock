| 15:00:22 | 17 条 LIVE 预测落库，**基于半截 bar** | `predictions` 里 asof 2026-09-22 的 17 行 `created_at=15:05:22`（patrol 子进程实际写库时刻）；patrol stdout 列出 17 个 `payload_sha256` |
| 15:30:02 | close 链正常跑：`ingest bars --days 30` 用 `ON CONFLICT DO UPDATE` 把 09-22 覆盖成**真收盘价** → `predict run` 重算 → **17 条载荷全变** → append-only 全部拒绝 | `close.out.log` 里 `predict_run` 的 `stderr_tail` 有连续的 `❌ 601088/601318/601398/603868 …`；close 链 exit 1 |

**后果**：asof 2026-09-22 的 17 条 LIVE 预测是**收盘前版本**；按 append-only 纪律不可改写（要改只能升 `MODEL_VERSION`，代价不成比例）。close 链因此 exit 1（12 步里 11 步成功）。

**为什么这是「每天复现」**：patrol 的补步清单里**没有 `ingest bars`**，所以它 15:00 跑 `predict run --asof <今天>` 时，**当天的 K 线必然缺失或为盘中值**；而 15:30 的 close 链一定会把当天 K 线更新成终值 ⇒ **每个交易日都会产生同一批冲突**，并让当天 LIVE 预测永久停在收盘前口径。
