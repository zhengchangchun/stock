## 2. 预测-验证校验（A3/B1 的五件读数）

**对象** = `m2_forecasts`（D-39：模块2 的预测**不进** `predictions`）。

**产物不许写回** `predictions` / `verifications`（后者的 `pred_id` 是外键，混进去会把插桩预测
卷进「模型准确率」统计 —— D-30 的口径分工）。

五件读数（需求书 §3 点名，逐件都要有）：

| # | 读数 | 口径要求 |
|---|---|---|
| 1 | **胜率**（方向命中率） | 命中定义必须与 `verify/` 的**方向判据逐位一致**（同一套「涨/平/跌」与 `FLAT_BAND` 阈值）；用**对拍测试**钉住（同输入同结果），不得另立定义 |
| 2 | **收益偏差分布** | `预测区间/关键位 vs 实际` 的偏差分布，按分位给（不要只给均值）；空样本 ⇒ 「无」不写 0 |
| 3 | **盈亏比** | 复用 P41/`backtest/metrics.py::profit_loss_ratio` 的既有语义（只有赢或只有输 ⇒ `None`）；**不许另写算法** |
| 4 | **最大回撤** | 复用既有净值/回撤实现（`paper/engine.py::drawdown`），不得另写 |
| 5 | **错判案例集** | 列出「方向错」的样本（`input_sha256` / 预测 / 实际 / `script_version`）；**归因字段恒空**（D-31：禁自动填充，人工确认是 P50 的事）；必须显示**样本总量**与**条数上限**，且**没有「挑好看的/最有利的」筛选参数**（要列就按时间倒序取最近 N 条） |

**落库判据（本轮拍板）**：校验结果**必须落库**（新表 `m2_forecast_scores`，append-only + 触发器），
不许「页面实时算不落库」——否则「当时的分数」不可复现，下一轮换口径后读到的就不是当时那个数
（错误日记 #36/#59 同型）。幂等键 = 一条预测一行分数；改口径 = 升 `script_version`，不覆盖历史行。

**分版本纪律（D-38 同型）**：所有读数按 `plugin_id` + `script_version` **分列**，
两版**不许相加、不许求平均**（并页面上写明这一点）。

**样本门禁**：A3/B1 的已评分预测对 <120 ⇒ 同样判 `insufficient`、同样禁结论文案。
