## §0 背景（实测，不是转述）

### 0.1 事故现场（2026-09-30 18:34）

- 模型回传：`{"kind":"metric","metric":"cum_return","date":"2026-09-29","value":-0.0115}`
- 库真值：`paper_nav_daily(account_id='arm-agent-ds-v4', date='2026-09-29').cum_return = -0.011548`
- `stocklab/paper/review.py:75` 的 `TOL = 1e-6` ⇒ `abs(-0.0115 - (-0.011548)) = 4.8e-05 > 1e-6`
  ⇒ `_check_metric`（`review.py:227`）判「读数不许编」，**拒绝、零写入**。

### 0.2 根因：两条口径不自洽（不是模型编数）

| 侧 | 口径 | 位置 |
|---|---|---|
| 写（上下文） | 净值/成交读数**截到 4 位小数**进上下文 | `paper/own_history.py:95-96`（`_round4`） |
| 校验（metric 腿） | 与**未舍入的库值**差 ≤ 1e-6 | `paper/review.py:220-230`（`_nav_row` 直接 `SELECT {col}`） |

⇒ 模型**只能看到 4 位小数**，却被要求与 ≥6 位精度逐值相同。4 位小数必带 ≤5e-5 的舍入误差，
**1e-6 在数学上不可能满足**：凡该列读数的小数第 5 位非 0，这条复盘必被拒。

### 0.3 对照：`market` 腿天然没这个问题（这就是修法的样板）

- `market` 腿（`review.py:267-294`）拿的是**当日 `market` 块自己的值**（`market_view.py` 已统一
  `round(x, 4)`：`:72/:127/:221/:223/:261/:297`）⇒ 模型照抄块里的值，比对**必然**通过。
- 实证：库里唯一成功的 `review_id=1`（`arm-agent-ds-v4 / asof 2026-09-29`）**3 条 item 全是 `market`**，
  值 `0.1905 / -4.3872 / -34.9256` 逐字来自块。
- 反过来说：**失败的必要条件是「引用了 `metric` 腿」**（`cash` / `market_value` 的历史序列本就没进
  上下文，见 `prompts/trader-v4.txt:44-45`，所以实际只会命中 `cum_return` / `drawdown` / `nav` /
  `cum_cost` / `net_deposits`）。

### 0.4 影响面（为什么必须修，而不是「下次注意」）

- v4 臂的定位就是**先复盘再决策**（P85/P86）⇒ 复盘写不进去 = 当天闭环的输入侧缺一块，
  且 `paper_agent_reviews` 的 `n_items` 永远上不去、`derive_facts` 的「已确认教训」永远为空
  （09-30 那天就是 `n_lessons=0`）。
- 触发概率＝「净值列小数第 5 位非 0」≈ 天天。**不修，这条闭环每天都会掉一次。**

### 0.5 已锁定的口径决定（D1–D6，站不许改）

- **D1（核心）**：`metric` 腿的比对基准＝**模型在上下文里实际看到的那个读数**，即
  `round(库真值, DISPLAY_DP)`（当前 `DISPLAY_DP = 4`），**容差仍 `1e-6` 不动**。
  口径从「与库值一致」改为「**与展示值一致**」——与 `market` 腿同构（那里一直是这样，只是没人写明）。
  ⛔ **禁止**「把 `TOL` 放宽到 1e-3 / 1e-4 / 2e-3」这类放水（那会同时放过真编的读数）；
  ⛔ **禁止**去改上下文的展示精度（那会改 `context_sha256` 序列）。
- **D2**：展示精度**单点化** —— `DISPLAY_DP` 定义在 `paper/review.py`（它不 import `own_history`，
  反向 `own_history` 已 import `review` ⇒ 放这里不会成环），`own_history._round4` 改为引用它。
  **数值逐位不变**（`round(x, 4)` 还是 `round(x, 4)`），靠一条用例钉住「两个模块用的是同一个 dp」。
- **D3**：失败文案必须让人一眼看出怎么改：同时打印**上下文展示值**与**库真值**，例：
  `与上下文里的读数不一致：2026-09-29 的 cum_return 展示为 -0.0115（库真值 -0.011548）（差 4.8e-05 > 1e-06）—— 读数不许编`。
  文案里「读数不许编」这五个字必须保留（既有用例/文档在引它）。
- **D4**：**不许改历史**。`paper_agent_reviews` 既有 1 行、所有决策行、所有净值行一字不动；
  两张 append-only 触发器不动。
- **D5**：**本站不补写 09-30 那条复盘**（补写要真调模型，由 nanobot 在修复上线后走生成器做）。
- **D6**：零结构变更（不动 `store/schema.sql`）、真库零写入（写实测只在 `/tmp` 副本）、
  红线三目标**不 regen**。
