## 0. 一句话

`adjust.load_chain` 还会从**另外两条**没人保护的地方穿出去，让**一只 code 判死整轮**：

1. **`cmd_adj_rebuild`**（`stocklab/cli/main.py:610–617`）：per-code 循环体
   （`load_chain` → `insert_adj_factors`）**完全没有 try**。
2. **`cmd_features_build`**（`stocklab/cli/main.py:1585`）：`load_chain` 在 `try` **之外**，
   那个 `try` 只包 `adjust_bars`。

**第 2 条不是理论风险 —— 它在真库上 100% 复现**：`cmd_features_build` 的 code 列表是
`SELECT code FROM instruments WHERE active=1`（**没有** `type='stock'` 过滤），而 21 只种子里有
**4 只 ETF**（`510300/510880/512890/518880`），`load_chain` 对它们一律抛
`EtfChainUnsupported`（ADR-008，**设计如此**）⇒ `features build` 每次都在
**第 8 只**（`300750` 之后就是 `510300`）整轮 abort。

本站按 #77 的判据把**这一族**的边界补齐：**逐 code 记名 + 不中断 + 退出码如实**。

## 2. 风险点（查 ERROR_DIARY 后）

- **#81（P75）**：兜底要 catch 的是「**这一类失败**」，不是「已知的那几个子类」。本站的
  `except Exception` 是有意的（`noqa: BLE001`），**但必须留痕**：记名 + `log_event` + 进 `failed` + 非零退出。
  **容错 ≠ 吞错**，禁止 `except: pass`。
- **#77（P68）**：修一处 ≠ 修一类 —— T0 就是这条的执行形式。**别只改 `main.py` 里那两行就宣布收工**。
- **#54**：退出码不能被「容错」稀释成恒 0。本站把 `cmd_adj_rebuild` 的恒 `return 0` 改成
  `1 if failed else 0`，改完要**主动核对**既有用例有没有把「恒 0」当契约钉住。
- **#51 / #55**：别把测试产物写进仓库 `reports/`、别起真子进程跑联网命令
  （`conftest` 有 autouse 夹具；`ingest *` 不接受 `--db`）。
- **不要动**：`stocklab/data/adjust.py`（J5）、`stocklab/store/repo.py::insert_adj_factors`、
  `stocklab/ops/`、`stocklab/paper/`、`stocklab/m2/`、`stocklab/predict/`、`config/universe.py`。
- **别 regen 红线**：`docs/baselines/redlines.json` 是 append-only 台账，红了先归因，不许 `--regen`。
