## 1. 要改的（逐条对 §E，**不许扩大**）

| # | 项 | 判据 |
|---|---|---|
| T1 | **公告日不再是 DMSK 的 `NOTICE_DATE`**：改取 `RPT_F10_FINANCE_*` 的 `NOTICE_DATE`，取不到时**回退法定披露截止日**（年报/一季报 4-30、中报 8-31、三季报 10-31），并**新增列 `notice_date_source ∈ {f10, statutory}`** | 美的 2025-12-31 那期的可读日回到 `2026-03-31`（现状是 `2026-08-29`，把 2025 年报「藏」了 5 个月）；配一条质检 `report_date < notice_date ≤ report_date + 120d`，越界 → `warn: notice_date_suspect` |
| T2 | **补 `parent_equity`（归母权益）列**，`roe`/`dupont` 口径不再打架 | 同口径恒等式测试：`abs(净利率 × 周转率 × 权益乘数 − roe) < 1e-9`；并加**负例**：换回「合计权益」必须失败（现状：分子归母、分母合计，美的差 **5.7%**，且两个数同一份 `features` 里互相打架、不报错） |
| T3 | **早期期数 `NOTICE_DATE` 为 NULL 能入库**（主键 `NOT NULL` 装不下：美的资产负债表 17/79 期、现金流量表 14/79 期为空） | 回退法定截止日后插入成功；`report_date` 早于 2007 的期数有专门用例 |
| T4 | **采集补分页与 fail-closed**：`columns=ALL` + `pageSize=500` + 翻页取全；单页失败不得静默截断 | 造一个「>500 行」的响应 → 断言全部入库；造一个中途 500 → 断言**报错而不是留下半份** |
| T5 | **`ctx` 加 `sector`**（中期池排除金融股要显式，不许静默） | 银行/保险标的走中期池时，报告里能看到「因行业排除」的理由，而不是 `pass_flag=False` 了事 |
| T6 | **`features` 补齐完整形状**：不可算的量给 `None` + `na_reasons`，**不许给 `0.0`** | 用例：缺一季数据 ⇒ 该字段 `None` 且 `na_reasons` 有原因；`0.0` 出现即失败（「不知道」≠「最差」，既有口径） |

## 2. 必须先定的一件事（设计稿里拍板，不许静默）

**旧口径行怎么处置？** 库内现有 `financial_reports` 行是用 DMSK `NOTICE_DATE` 落的
（主键含 `notice_date`）。换口径后有两条路：

- **① 只前滚、不动历史**（推荐）：旧行保留，靠新列 `notice_date_source` 区分（旧行回填 `dmsk_legacy`），
  读侧**一律按 `notice_date_source` 过滤**，并在报告里显示口径分布；重采只补缺口。
- ② 重采覆盖（**不推荐**）：`financial_reports` 是不是 append-only 要先查清；若是，这条路根本走不通。

> 判据：选定后写进设计稿 §「旧行处置」；**无论选哪条，都不许「静默改写历史行」**。

## 3. 反目标

- ❌ 不新增因子、不动中期池的评分公式（本站只修「数据对不对」）。
- ❌ 不动 `predict` / `verify` / `MODEL_VERSION` / 红线基线（`docs/baselines/redlines.json` 三目标必须不变）。
- ❌ 不换数据源（仍是东财 datacenter + F10 两张表；不引入新供应商）。
- ❌ 不把「银行/保险取不到 F10」当成可以忽略的边角 —— 要么按 `ORG_TYPE` 选报表名逐只验覆盖，要么明确降级口径并标注。
- ❌ 不 `git commit`、不建分支/worktree。

### 偏离任务书 / 未做

1. **偏离：`report_date+120d` 上界不套 `statutory` 回退值**（设计稿 §5）。
   实测真库 **41 行**合法数据滞后 **121 天**（年报 12-31 → 4-30 遇闰年）。
   照任务书字面实现会年年误报。改法：回退原因拆 `missing`/`implausible`，
   只有后者发 `notice_date_suspect`。**判据本身满足**（越界即 warn），落点收窄。
2. **未做（交 nanobot）：`instruments.sector` 回填未对真库执行**（任务书第 3 条明确要求）。
   命令见设计稿 §9；实测副本已跑通。**执行前建议先备份**。
3. **未做（超范围）：`notice_date_source` 分布未进候选报告**。
   评审 A3 要求「报告里注明该期公告日为推定」。本轮 `ctx`/`features` 未新增该字段
   （会动 `FEATURE_KEYS` 契约与 `PROBE_CTX`），故**留为下一轮**，不静默扩大。
4. **不确定项**：§4 选「都改均值」使 `dupont` 需要**上一年年末总资产**，
   缺该期时 `dupont` 由可算变 `None`。真库每标的最早 2004 年报有资产负债表，
   故现有读数不受影响；但**更早/更稀的标的**可能出现新增 NA，未在真库全量验证。
5. **任务书前提过期**：见 §5 顶部。已在设计稿 §2 逐条列出证据，
   未按原文重做已落地的 T1/T3/T4 主干。
