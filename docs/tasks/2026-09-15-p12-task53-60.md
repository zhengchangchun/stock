# P12 任务拆分：实盘账本 + 组合视图（Task 53–60）

> 设计稿：`docs/plans/2026-09-15-p12-实盘账本与组合视图.md`
> 铁律：一个任务未验证通过，不进下一个。每完成一项立刻 commit。

## 风险点（开工前查 ERROR_DIARY 的结论）

| 风险 | 来源 | 对策 |
|---|---|---|
| 表设计（PK/UNIQUE）与接口语义互斥 | #13「接口说『视为不同记录』先核对 DDL」 | 先定「同价同量同费可能是真单」→ 明确**不加** UNIQUE，改用 `ledger_idem` |
| 幂等判定拿内存对象比库里的行 | #10 canonical 化 | 重复判定一律**查库**后比，不比调用方手里的值 |
| 口径不匹配静默降级 | 2026-09-14「取不到就回退」 | 无现价 → `missing_price`，**不用成本价冒充** |
| 触发器 ABORT 后隐式事务残留 | #4 | `db.connect()` 已 `isolation_level=None`；本次新增触发器沿用 |
| `INSERT OR REPLACE` 绕过 append-only 触发器 | #6 `recursive_triggers=ON` | `connect()` 已开；测试要真的验一次 `INSERT OR REPLACE` |
| 报告数字算错（含 ceil 的算术口算错） | #8 | 所有金额一律用 `round()` 在输出层定死，不口算 |

## 任务清单

### Task 53 — schema 前滚

- 新增 `cash_flows`、`ledger_idem`（`CREATE TABLE IF NOT EXISTS`）。
- `cash_flows` / `real_trades` / `ledger_idem` 补 append-only 触发器（UPDATE + DELETE）。
- 验证：`db init` 在**已存在**的库上前滚成功且幂等（跑两次）；
  触发器实测 ABORT（含 `INSERT OR REPLACE` 路径）。

### Task 54 — `stocklab/portfolio/positions.py`（纯函数）

- `replay_trades(rows) -> dict[code, Position]`，加权均价、部分卖出结转、清仓重建。
- `Position` 含 `avg_cost_incl_fee` / `avg_cost_excl_fee` 双口径。
- 超卖 → 抛 `LedgerError`（写入口复用它做校验）。
- 验证：多笔买卖 / 部分卖出 / 清仓后再建仓 / 超卖 四组单测。

### Task 55 — `stocklab/portfolio/ledger.py`（写入口 + 校验）

- `validate_trade` / `validate_cash_flow`：§5 全部规则。
- `record_trade` / `record_cash_flow`：`--idempotency-key` 幂等命中；
  无 key 时完全相同元组 → 拒绝（除非 `allow_duplicate=True`）。
- `reverse_trade(trade_id, reason)`：写反向记录 + note，**不 UPDATE**。
- 验证：校验矩阵逐条测 + 幂等命中 + 重复拒绝 + 冲正后账回原样。

### Task 56 — `stocklab/portfolio/prices.py`

- `resolve_price(conn, code, asof) -> Price | None`，三分支 + `adj_mode='none'` 硬约束。
- 验证：snapshot（取 ts 最大）/ bars（date ≤ asof）/ 都没有 → None；qfq 行必须取不到。

### Task 57 — `stocklab/portfolio/discipline.py`

- 六条规则，返回 `{check, status, detail, numbers}`；`UNDETERMINED` 用于数据不足。
- 验证：每条规则的 PASS/WARN/FAIL 边界各一测（40% 正好、现金带端点、止损线正好）。

### Task 58 — `stocklab/portfolio/view.py` + CLI

- `build_portfolio(conn, asof)` → 稳定 JSON；`render_table(view)` → 人看的表。
- CLI：`trade add` / `trade reverse` / `cash add` / `portfolio show --asof DATE [--json]`。
- 验证：JSON 顶层与 `positions[]` 字段集合钉死测试；退出码（0/1/2）测试。

### Task 59 — 真实验收

- 20,000 本金 + 2026-09-14 买入 000333 100@86.80 fee 5.09 入库（贴原始回显）。
- `portfolio show --asof 2026-09-14` / `--asof 2026-09-15`（贴原始输出）。
- 口径差异点名：含费现金 11,314.91 vs 用户口述 11,320（不含费）。
- `bash scripts/verify.sh` 结尾 + 回归哨兵 sha256 不变。
