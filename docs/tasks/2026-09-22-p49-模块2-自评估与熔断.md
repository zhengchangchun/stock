## 0. 一句话

把「**N 轮验证周期 → 每轮读数 → 三分支判定（冻结 / 优化 / 微调）→ 提前熔断**」这条主干接起来：
判定只出**建议＋依据**（人 `approve` 才执行），边界越界**拒绝并要求重生成**（不 clamp），
熔断**可复现、幂等、只追加**。

> ❗ 本站**不自动改策略、不自动上线、不自动填归因**——那三条分别属人工闸门（D-1/D-24）与 P50（D-31）。

## 1. 判定的输入与输出（D-44，已拍板）

**输入**（全部只读，已有真源，**不许另造读法**）：

| 输入 | 来源 |
|---|---|
| 周期声明（轮次、单轮天数、参数集、**判据原文**） | `validation_cycles`（P44 已建） |
| 每轮读数 | `validation_rounds.metrics_json`，口径 = **P41 指标集**（P48 已接同一取数函数） |
| 净值/回撤 | `paper_nav_daily` + 既有 `paper/engine.py::drawdown`（**不另写回撤算法**） |
| 错判案例 | P48 的错判案例集（只读引用，**归因字段仍恒空**，D-31） |
| 边界常量 | `stocklab/config/limits.py`（`VALIDATION_ROUNDS_MIN/MAX`、`CIRCUIT_BREAKER_DRAWDOWN`、时长/冻结上限）——**AI 不可改** |

**输出** = 一条**建议**（三个分支之一）＋ 依据清单（哪几条读数、哪个案例、算到哪一步）：

| 分支 | 适用（口径） | 落地动作（**要人 `approve` 才发生**） |
|---|---|---|
| **冻结** `freeze` | 读数未达标**且**没有可归因的改进方向（案例集给不出方向） | 该版本停用，`frozen` 态，**冻结期 ≤ 90 天**；台账一行不删 |
| **优化** `optimize` | 有明确改进方向**且需要改脚本逻辑**（A1/A2 编排或因子层） | 出**新 script 版本**（走既有 plugin 生命周期 + 人工 `approve`）；**新账户 = 新策略版本**（D-26），新周期 |
| **微调** `tune` | 只动**参数**、不动脚本逻辑（因子权重/估值公式/阈值/概率模型超参） | 同 script 版本下**新参数集** ⇒ **必须新开验证周期**，把新 `params_json` 与**判据原文**一并落库 |

**纪律**：
1. 建议**不是执行**：三个分支一律只写「建议 + 依据」到台账/页面；执行路径仍走人工（`approve` 只能人工 CLI，既有护栏不许放松）。
2. **判据原文落库**（`criteria_text`，P44 已建）：事后换口径 = 这一站的典型作弊方式，禁止。
3. **越界即拒**：轮次 ∉ [2,3]、总时长 > 30 天、冻结 > 90 天 ⇒ 拒绝并要求重新生成，**不许 clamp**、不许「取最近的合法值」。
4. **样本门禁沿用 120**：轮次读数不足时不许出「优化/冻结」的**结论性**判定，只写「证据不足」＋现有读数。

## 2. 提前熔断（D-27）

- 判据：**验证期内账户净值自峰值回撤 ≥ `CIRCUIT_BREAKER_DRAWDOWN`（0.10）** ⇒
  立即标记本轮策略失效、**终止本轮验证**、写 `validation_events(kind='circuit_breaker')`，
  `at_value`（实测回撤）与 `threshold`（判据阈值）**分开存**，`criteria_text` 记判据原文。
- **不改写历史台账**：终止 = 追加事件 + 追加一轮/周期收尾行，绝不 UPDATE 既有行。
- **可复现**：同一历史输入重放必须得到同一判定（同一天、同一份净值 ⇒ 同一 `at_value`）；
  不许读墙上时钟、不许读「当前最新净值」以外的输入。
- **幂等**：同一 `(cycle_id, asof)` 重复检查**不重复写事件**（结构性防线优先：唯一索引或等价的 append-only 幂等键）。
- 熔断触发后：**账户不再下单**（通路侧的行为由 P47 的通路读取「周期已终止」状态决定，本轮只需把状态与判据暴露出去）。

## 3. 错判案例回流模块1（D-31 的边界）

- 回流 = **只读汇总**：把某周期内 P48 的错判案例按 `code`/区间聚成「待复核清单」，写进台账/页面；
- **归因字段恒空**、**不许自动填**、**不许把回流清单当结论**展示；
- 回流产物必须带**来源指纹**（`input_sha256`/`script_version`）与**生成时间**，便于事后对账。

## 4. 入口与页面

- CLI：`m2 cycle start|round|judge|fuse-check|status`（名字可调，**写进任务书 §7 进度表**）；
  退出码语义与既有 CLI 一致：成功 0、输入不合法 2、**冲突/已存在 1**（照抄既有惯例，不发明新语义）。
- 页面：判定结果与熔断事件展示在 **`/lab/m2`**（P48 建的页）新增一节，
  **只读、不提供任何写入口与「触发判定」按钮**（ADR-021 的「Web 零写入口」判据不许破）。

## 5. 测试（先红后绿）

| # | 判据 | 怎么测 |
|---|---|---|
| T1 | **边界越界即拒** | 轮次 1 / 4、总时长 31 天、冻结 91 天 ⇒ 拒绝 + 明确文案；**断言库里没有半截行**（拒绝了就不许写） |
