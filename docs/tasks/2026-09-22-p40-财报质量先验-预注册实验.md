## 0. 一句话

财报数据层**已经落地**（`financial_reports` 1443 行 / 17 codes、ADR-016、6 个因子 + 极性规则都在），
**缺的是「它有没有信息量」的样本外证据**。本任务＝按预注册文件实现 2 个 `mu_mode` 变体、
跑 validate、出报告、把结论追加进预注册文件第 6/7 节与实验台账。**只准跑，不准调参。**

## 1. 要实现的三个 0-改动之外的件

### T1 变体 V1 `fin-quality-pct`（横截面，本项目第一条横截面轴）

- 新增 `ForecastSpec.mu_mode` 取值 `fin_quality_pct`（**只加一个枚举值，不改别的字段语义**）。
- 新增符号加载函数（放在 `experiments/variants.py` 既有 `load_mf_sign` / `load_val_pe_pct_sign` 旁边，
  命名与 docstring 风格照抄）：
  - 输入 `(conn, code, asof)`；**先按 asof 缓存整批**（同一天 17 只各查一次 = O(N²)，必须按 `asof`
    缓存一批，缓存键只含 `asof`，不许含未来信息）；
  - 取数：`SELECT * FROM financial_reports WHERE notice_date <= :asof`（**只此一句 PIT 边界**），
    按 `code` 取**最新 `report_date`** 的那期 → `data.models.FinancialReport` →
    `candidate/indicators.py::factors()`（**复用，不许重写因子公式**）；
  - 合成：可用因子（`factors()` 里非 `None` 的 6 个）**至少 3 个**才参与，`q_raw = mean(可用因子分位)`，
    分位的**极性规则复用 `candidate/cross_section.py` 的同一个真源**（`inv_days` 越小越好，其余越大越好；
    不许在变体里再写一份极性表 —— 两份必然走样）；
  - 对 `q_raw` 取横截面分位 → `q ∈ [0,1]`；`q ≥ 0.70 → +1`、`q ≤ 0.30 → −1`、其余 `0`；
  - 分位样本 `n < 5`（横截面太小，分位无意义）→ 返回 `None`。
- PIT 硬约束：`notice_date > asof` 的行**读不到**（要有测试钉住）；不许「取最近一根」兜底。

### T2 变体 V2 `fin-roe-yoy`（时序轴）

- 新增 `mu_mode` 取值 `fin_roe_yoy`。
- 自身 `roe(TTM, 本期)` 与 `roe(TTM, 去年同期)` 比较（**复用 `indicators.factors()` 的 TTM 口径**，
  不许另写 TTM）：`Δ > +0.01 → +1`、`Δ < −0.01 → −1`、其余 `0`；任一侧不可算 → `None`。

### T3 两个变体都注册到 `VARIANTS`

- 照抄既有条目结构：`name` / `changed_axis="mu_mode"` / `spec=ForecastSpec(mu_mode=...)` /
  `hypothesis`（**逐字**取自预注册文件 §1，不许改写）/ `prereg_doc="docs/experiments/2026-09-22-financials-quality-prior.md"`。
- 变体生效但当日返回 `None` 时，**必须**走既有的 `DegenerateInput` 硬拒绝语义（与 P29 同款），
  不许静默回落基线；报告要能看出「实际用变体的天数」。

## 2. 必须新增的测试（先红后绿）

1. **PIT**：构造 `notice_date = asof + 1` 的财报行 → V1 不得看见它（断言取到的期数/因子值来自更早的期）；
   `notice_date == asof` **可用**（口径见预注册 §2）。
2. **横截面**：手工 5 只标的、因子分位已知 → 断言 `q` 与符号与手算逐位一致（含极性：`inv_days` 最小者
   应得**最高**质量分位）。
3. **退化**：可用因子 < 3 / 横截面 n < 5 / 无任何财报 → 返回 `None` 且**不抛未受控异常**。
4. **单变量不变量**：两个新变体都能过 `assert_single_variable`（既有机制，加断言即可）。
5. **极性真源**：源码扫描或等价手段钉住「变体没有自带第二份因子极性表」（ERROR_DIARY #50 同款：
   用检查把「文件说谎」变成不可能）。
