## 0. 一句话

真库 800 只采集的 **B5（`ingest actions --universe csi300-500`）整批 exit=1**，根因是
`600602`（云赛智联）1992 年的源站脏条款 `10派100元`（每股现金 10 元 ≥ 除权前收盘 9.35 元）算得
`k = -0.0695 ≤ 0`，`event_factor` 抛的是**裸 `AdjustError`**，而 `build_chain` 只 catch
`UnpriceableTerms` ⇒ 异常穿出 `load_chain`、穿出采集循环（那只 catch 了 `fetch_corp_actions`）
⇒ **整批 800 只 abort**。本站把「条款荒谬 ⇒ k 越界」并进已有的「不可定价事件」档
（`UnpriceableTerms`，不改口径、不夹紧、不静默），并给采集循环加**按 code 容错**，
让**一只坏码不再拖垮整批**。

## 0.1 证据（2026-09-25 实测，可复现）

1. **失败点**：`/tmp/p75/result-resume.json` B5 `ingest actions --universe csi300-500`
   `exit=1`、`corp_actions` 417 → **8,439** 行（131.1 min）后中断；自动重试**同因失败**。
2. **脏行**（真库只读复现）：

   ```sql
   SELECT * FROM corp_actions WHERE code='600602' AND cqr='1992-03-09';
   -- code=600602 cqr=1992-03-09 djr='0000-00-00' fh_sh=NULL content='10派100元' source=tencent
   ```

   同期不复权 K 线（`bars_daily`）：`1992-03-02…03-06` 收盘 **9.35**，`1992-03-09` 起 **9.25**
   ⇒ 真实跌幅只有 **0.10 元/股**，条款数理上应是「10派1元」，源站把**数量级写错**。
3. **抛点链路**：`stocklab/cli/main.py:322 cmd_ingest_actions` → `stocklab/data/adjust.py:346 load_chain`
   → `:238 build_chain` → `:159 event_factor`

   ```
   AdjustError: 复权系数越界：pre_close=9.35 cash=10.0 share_ratio=0.0 → k=-0.0695
   ```

   `build_chain`（`:241`）只 `except UnpriceableTerms`；`cmd_ingest_actions`（`:302–322`）
   的 `try` **只包 `fetch_corp_actions`**，不包 `adjust.load_chain` ⇒ 整批 abort。
4. **影响面**：468 个有事件的 code 里**只有 600602 一条链算不出来**（其余全 ok）。裸 tuple 读库会
   误报「351 条 TypeError」，必须 `conn.row_factory = sqlite3.Row` 才复现 —— 别被自己的探针骗了。
   真库现状：`corp_actions` 468 个 code / 8,439 行；`adj_factors` 只有 **189** 个 code / 1,121,013 行；
   研究池 800 只里 **279 只「有事件但没有因子行」**（＝被 abort 跳过的段）+ 600602 自己
   （`SELECT count(*) FROM adj_factors WHERE code='600602'` = **0**）。
5. **已有先例**：同库里 `600602` 的 `cqr=1999-12-02 content=''` 已被 `parse_terms` 判为
   `UnpriceableTerms` ⇒ 记进 `chain.unusable`、`usable_from` 取最晚那条、采集侧打 warn 继续跑。
   本站要的就是**同一档待遇**，不是新机制。

### 7.1 T1 落地

≥ 除权前收盘）判**不可定价**，`k > 1` 判**解析 bug**、仍炸。异常消息对 `k <= 0` 改写成
`复权系数越界（条款疑似荒谬，按不可定价事件处理）：…` —— **「复权系数越界」子串保留**，
故未改动的 `tests/test_adjust.py:103 test_event_factor_rejects_dividend_larger_than_price`
（`pytest.raises(AdjustError, match="复权系数越界")`）**天然保持绿**（子类 + 子串双保险）。
