## 0. 一句话

### 5.1 偏离任务书（**一处一行，不许静默**）

1. **`hold_override` 的类型从建议的 `list[str]` 改成 `Mapping[str, Sequence[str]]`**
   （`{调仓日: [code, ...]}`）。理由：对照臂「该池全部合格标的」是**逐调仓日不同**的集合
   （当日已公告的财报/K 线决定谁合格），扁平列表表达不了 `d0 的合格集 ≠ d1 的合格集`；
   而两者不等正是成本项（调仓账单）的来源 —— 传同一个集合会让换手恒为 0 ⇒ **成本被悄悄抹掉**。
   任务书对这个类型写的是「建议」，语义要求在此之上。
2. **`benchmark_excess` 多了一个 `hold_override` 透传 kwarg**（同一个变量，不是第二个变量）。
   理由：对照臂的「同口径超额」不经透传就只能 (a) 另写一份对齐逻辑（= 第二份口径，撞硬约束 2）
   或 (b) 把对照臂的超额报成现状臂的（= 报错数）。透传不新增任何口径。
3. **价格侧 PIT 守卫落在 `candidate/replay.py`**（`_close_on` 那一侧），因此
   `candidate/replay.py` 新增一条**延迟** import 到 `paper/rules.py`。
   理由：硬约束 5 点名「复用 `check_no_lookahead`，同一个函数，不另写」，而 T2 又要求
   研究模块不许 import `paper` 内部 —— 放在回放侧**同时满足两条**，且这正是设计稿 §Q3
   的原话（「给回放侧补一个结构位」）。研究模块 `research/xsec.py` 因此**零** `paper`/`m2` 依赖。
