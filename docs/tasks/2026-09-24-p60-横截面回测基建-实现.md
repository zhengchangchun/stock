### T2 实现（只读命令 ＋ 一处显式参数）

- 新子命令组 `research` ＋ `research xsec-topn`：
  `--pool`（只能 `short`，其余 exit 2）／`--start`（必填，`< 2015-01-01` exit 2）／`--end`（默认今天）／
  `--prereg <md 路径>`（必填）／`--out <dir>`（默认 `reports/research/`）／`--arm all|topn|both`（默认 `both`）。

  **等价性用例**：`hold_override=None` 时与改动前**逐位相同**（用同源夹具）。
- 新模块建议 `stocklab/research/__init__.py` ＋ `stocklab/research/xsec.py`（只读、可 import `candidate`/`plugin`；
  **不许** import `paper`/`m2` 内部来「借用」口径）。
- 判定**复用** `plugin/sandbox.py` 的既有函数与常量（`MIN_VALID_PERIODS=120`、`_BOOTSTRAP_N=2000`、
