## 0. 一句话

把模块2 的四件「外围」补齐：**误差归因结构位（人工确认，禁自动填）**、
**只读配置视图（主干常量 + 当前生效策略参数 + 来源）**、**可视化报表（复用既有图，不另画一套）**、
**事件旁路触发（幂等、留痕、不等周期结束）**。

## 1. 误差归因结构位（D-31）

- **四分类**（原文）：大盘冲击 / 行业黑天鹅 / 个股突发利空 / 因子失效。
- **程序只给候选**：由**可计算信号**推出候选标签，必须写明用了哪个信号、阈值是多少、算到哪一步，例如
  - 大盘冲击 ⇐ 当日 `sh000300` 涨跌幅 ≤ 阈值（组合超额与指数同向）；
  - 个股突发利空 ⇐ 该 `code` 当日出现 `corp_actions` 新事件 / 停牌 / `data_quality` 异常 / 单日跌幅超阈值；
  - 行业黑天鹅 ⇐ **同行业同日**多只标的同向异动（`financial_reports.industry_name` 或既有 `sector_daily`，取既有真源，不许新造行业分类）；
  - 因子失效 ⇐ 该因子**同期横截面 IC / 命中率**显著掉档（复用既有因子读数，不许新造因子算法）。
- **人工确认**：`attribution_manual` 是**唯一**的"结论"字段；`attribution_auto` 只放**候选**并标注「候选」；
  两者都有的行，页面显示以人工为准并保留候选（对账用）。
- **禁止**：自动填 `attribution_manual`、把候选当结论展示、用「未定」以外的默认值填充
  （既有口径：DATA 之外一律 `UNDETERMINED`）。
- 候选标签的判据（信号 + 阈值）**必须落成常量**（`stocklab/config/`），不许散落在页面/脚本里。

## 2. 只读配置视图（D-32）

- 内容：**主干常量**（熔断阈值 / 自评估边界 / 门禁 120 / 账户命名 / 频率）＋
  **当前生效的策略参数**（`validation_cycles.params_json` 最近一行）＋ **来源**（哪个文件/哪个常量名）。
- **只读**：零写入口（ADR-021 判据照旧：`labweb/` 对写路径零引用 + 页面无表单/按钮提交）。
- 每一项必须能指到**代码里的定义处**（文件:符号），页面不复制数值的逻辑、只在渲染时引用同一常量对象。

## 3. 可视化报表

- 净值曲线 / 回撤曲线 / 因子胜率曲线：**复用既有渲染函数**（`labweb/paper_render.py` 的曲线与
  `dashboard/` 的既有图表代码），**禁止**再写第二套画图/取数实现（源码扫描 + 反向自检）。
- 输出两种形态：页面（`/lab/m2` 或既有页追加小节）＋ **离线单文件报告**（`dashboard build` 的既有产物路径），
  两者**同源**（同一取数函数）、页面不重算。
- 缺数据 ⇒ 图例写「无」＋原因，不画空曲线、不填 0。

## 4. 事件旁路触发（04 §P2-1）

- 语义：某标的出现**重大公告利空**（或等价的机械信号）时，**不等验证周期结束**即触发一次**重打分/重评估**。
- **触发源**：机械信号清单（落常量，可配置）：① `corp_actions` 新增事件（类型白名单）② 单日跌幅 ≥ 阈值
  ③ `data_quality` 出现 `ohlc_inconsistent` 之类异常。**不接外部推送、不新增网络依赖**。
- **幂等**：同一 `(code, 信号指纹, asof)` 只触发一次（结构性防线：唯一索引/幂等键），重复触发返回「已存在」。
- **留痕**：触发事件写入既有台账（`system_events` 或 `plugin_audit`，取既有真源；**不新造事件表**），
  带信号原文与算到哪一步；**触发 ≠ 结论**：重打分的产物仍走既有 `candidate`/`plugin` 链路与人工闸门。
- 网页端**不提供触发按钮**（触发走 CLI）。

## 5. 测试（先红后绿）

| # | 判据 | 怎么测 |
|---|---|---|
| T1 | **归因不自动填** | 构造错误样本 ⇒ `attribution_manual` 恒空、`attribution_auto` 只含候选并带信号与阈值；页面出现「候选」标记 |
| T2 | **候选可证伪** | 给定构造输入（大盘跌 3%、同行业两只同向异动、`corp_actions` 新增）⇒ 候选标签与预期一致；边界（恰好等于阈值）有断言 |
| T3 | **配置视图只读且同源** | 页面显示的常量值 == 直接 import 的常量对象值（逐项）；源码扫描 `labweb/` 对主干常量写路径零引用（**带反向自检**） |
| T4 | **图表不平行实现** | 扫描：曲线取数/绘图函数只有一处真源；喂一段违规实现要判红 |
| T5 | **页面/报告同源** | 页面字段 == 报告生成器函数返回（逐字段）；页面不重算（同一函数被调用两次得到同一结果） |
| T6 | **旁路触发幂等** | 同信号重复触发 ⇒ 台账不增行、返回「已存在」；不同 `asof` 可各触发一次 |
| T7 | **触发不越权** | 触发后策略状态/账户/参数未变；未 `approve` 的脚本不会因此上线（静态扫描：触发路径不调用 approve） |
| T8 | **缺数据不造数** | 无净值/无指数/无行业数据 ⇒ 显示「无」+原因，不写 0、不画空曲线 |
| T9 | 全量 | `.venv/bin/python -m pytest -q` exit 0 ＋ `bash scripts/verify.sh` exit 0（红线三目标；红了先归因，**禁止 regen**） |
