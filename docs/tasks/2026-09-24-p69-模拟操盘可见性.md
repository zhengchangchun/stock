## 0. 一句话

盘面上现在有 **4 条 `agent_decision` 臂 + 1 条通路 A 臂 + 3 条纪律臂 + 2 条静态臂**，但
**真正在跑的那条 AI 臂在页面上没有名字、没有颜色、没有台账**；同时 `paper agent run`
每天把一条**永远不会有决策的占位臂**（`arm-agent`）算成「缺决策」⇒ 日更退出码恒 1、页面上多一条死平线。
本站在**不新增第二套口径、不加任何写入口**的前提下，把「谁在跑 / 跑了什么 / 赚了多少 / 口径哪天变过」四件事变成可读的。

### 1.4 `paper agent run` 的结构性假警（**这是「日更退出码恒 1」的根因**）

`paper/engine.py::run_agent_day` 用 `agent_claim_accounts(conn)` **认领全部** `executor=agent_decision`
的账户，对没有决策的账户写一条平盘净值行并把它记进 `anomaly.missing_decision`（交易日 ⇒ 退出码 1）。

实测 09-23 回执（`~/.nanobot/workspace/artifacts/stock/ai-trader-2026-09-23/run-receipt.json`）：
`accounts` 三条，`arm-agent` 一条 `missing_decision`，`expected=true`，`why=trading_calendar` ⇒ **退出码 1**。
而 `arm-agent` **按定义不可能有决策**（无预注册，`enroll` 也拒收这个内置名）。
⇒ 只要 `arm-agent` 在飞，**日更永远退出码 1**，且页面上永远多一条平线。
