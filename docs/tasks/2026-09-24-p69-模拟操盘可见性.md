## 0. 一句话

盘面上现在有 **4 条 `agent_decision` 臂 + 1 条通路 A 臂 + 3 条纪律臂 + 2 条静态臂**，但
**真正在跑的那条 AI 臂在页面上没有名字、没有颜色、没有台账**；同时 `paper agent run`
每天把一条**永远不会有决策的占位臂**（`arm-agent`）算成「缺决策」⇒ 日更退出码恒 1、页面上多一条死平线。
本站在**不新增第二套口径、不加任何写入口**的前提下，把「谁在跑 / 跑了什么 / 赚了多少 / 口径哪天变过」四件事变成可读的。

**本站不改**：账本语义、决策语义、成本口径、PIT 判据、主干常量、红线基线。

### 1.3 页面缺陷（两条，都能定位到行）

1. **贴错标签（P56 §8.4 已点名、未修）**：`stocklab/labweb/paper_render.py::arm_label`（约 `:107`）
   把**凡 `arm='agent'`** 的账户都叫成 `· 智能体 spec 编排`（P37 的旧文案）。
   `arm-agent-ds-v1/-v2` 的 `arm` 也是 `agent` ⇒ 它们被标成「spec 编排」，而它们实际是
   **P52/D-34 的 LLM 决策台账臂**（`decision_source=paper_agent_decisions`，`executor=agent_decision`）。
2. **真正在跑的臂是「未知账户」**：`_LABELS` / `_STYLES` / `_DISPLAY_ORDER`
   只硬编码了 `arm-agent` 与 `arm-agent-random` 两个 id ⇒ `arm-agent-v1`、`arm-agent-ds-v1/-v2`
   全部落到 `_UNKNOWN_STYLE`（灰虚线），在图上与「别人家」的线无从区分。

### 1.4 `paper agent run` 的结构性假警（**这是「日更退出码恒 1」的根因**）

`paper/engine.py::run_agent_day` 用 `agent_claim_accounts(conn)` **认领全部** `executor=agent_decision`
的账户，对没有决策的账户写一条平盘净值行并把它记进 `anomaly.missing_decision`（交易日 ⇒ 退出码 1）。

实测 09-23 回执（`~/.nanobot/workspace/artifacts/stock/ai-trader-2026-09-23/run-receipt.json`）：
`accounts` 三条，`arm-agent` 一条 `missing_decision`，`expected=true`，`why=trading_calendar` ⇒ **退出码 1**。
而 `arm-agent` **按定义不可能有决策**（无预注册，`enroll` 也拒收这个内置名）。
⇒ 只要 `arm-agent` 在飞，**日更永远退出码 1**，且页面上永远多一条平线。

## 3. 任务（T1–T6）

### T1 `paper agent run` 的认领范围可指定（**必修**，修 §1.4 的假警）

- 新增 `--arm <臂名>`（**可重复**）。不传 = **逐字节保持现状**（认领全部）。
- 传了 ⇒ **只认领点名的臂**：其余账户不写平盘净值行、不进 `anomaly.missing_decision`、
  不进 `n_claimed`；也不会因为「已存在」而报 `already`。
- 判据：
  - `paper agent run --asof <D> --arm arm-agent-ds-v2 --arm arm-agent-random` ⇒ `n_claimed=2`、
    回执 `accounts` 只含这两条、退出码 **0**（两臂都有决策时）；
  - **不传 `--arm` 的旧行为逐字段不变**（用真库副本跑 09-23，与
    `ai-trader-2026-09-23/run-receipt.json` **逐字段相同**，含那条 `missing_decision`）；
  - 点名的臂名不存在 ⇒ 退出码 2 ＋ 零写入（fail-closed，别静默跳过）。

### T2 账户「在飞 / 历史」显式化（**必修**，修页面上两条死线）

- `paper_accounts.params_json` 新增 `live`（缺省 `true`）：`agent_claim_accounts` **跳过 `live=false`**，
  `paper agent show` / 页面对它标「**历史版本（已停飞）**」，**不再判它缺决策**。
- 真库落位（**只两条**，逐条点名、走 §5 的变更纪律）：`arm-agent`（P52 占位、无预注册）、
  `arm-agent-ds-v1`（v1 提示词有 bug、已被 v2 取代）。
- 判据：改后 `paper agent run --asof 2026-09-23` 在**副本**上 `n_claimed` 2、`missing_decision` 空、退出码 0；
  两条停飞臂的**历史台账/净值行一行不改**（逐字段对照备份）。

### T3 页面账户口径（**必修**，修 §1.3 两条）

- `arm_label`：按 `params.executor` + `decision_source` 分档，**不再按 `arm=='agent'` 一刀切**：
  - `executor=m2_channel_a` ⇒ 「通路A · 插桩脚本（`m2_a1`…）· v<策略版本>」；
  - `executor=agent_decision` 且 `preregistered.model_id` 存在 ⇒ 「LLM 操盘臂 · `<model_id>` · <臂名后缀>」；
  - `arm=agent_random` ⇒ 「随机对照（同护栏同成本）」。
- `_STYLES` / `_DISPLAY_ORDER`：**按前缀/正则纳入 `arm-agent-*` 家族**（不得再硬编码 4 个 id），
  紫色家族内用线型区分（LLM 实线 / 随机虚线 / 通路A 点线）。
- 判据：新增一个**用例内虚构**的 `arm-agent-xx-v9` 账户 ⇒ 自动拿到紫色线与人话标签，
  **不需要改渲染代码**；`arm-agent` / `arm-agent-ds-v1` 显示「历史版本（已停飞）」灰线。

### T4 「AI 操盘手」专节（**本站的主交付**，三块）

1. **操盘记录表**（逐日一行）：`asof` / 臂 / 产出者（`model_id`，随机臂写 `random-control`）/ 决策摘要
   （方向 ＋ 标的 ＋ 目标权重%；原文 `reason` 可展开）/ 当日成交笔数 / 当日净值与累计收益 / 是否 `missing_decision`。
2. **盈利/净值表**：每臂 `nav` / 累计收益 / 相对 `sh000300` / 相对「什么都不做」/ 最大回撤 / 持仓数 / 累计成本，
   **外加 `delta_vs_random`（AI 臂 − 随机臂）** —— 归因必需，缺它读作「不可归因」。
3. **策略调整史**：按时间列出「哪条臂的口径哪天变过、改成什么」：
   LLM 臂 = `preregistered.model_id / prompt_sha256` 的版本切换（`arm-agent-ds-v1` → `ds-v2`…）；
   通路 A = `m2_a1` 的版本升级链（`plugin_audit` 的 `submit/sandbox_pass/approve` ＋ `plugin_scripts.version`）；
   spec 台账 = `paper_agent_decisions.spec_before_json → spec_after_json` 的差异（`arm-agent` 家族）。
- 全部**复用既有取数**（`paper.engine.agent_block` / `paper_agent_decisions` / `paper.store`），
  **一列新口径都不许造**；净值/盈亏**读库里的列**，不重算。

### T5 判据（页面）

- `GET /lab/paper` HTTP 200；台账 **3 行全在**（09-23 两条 + 09-24 一条）；
- 每条在飞臂的净值/收益数字 == `paper.engine.build_report` 的同一字段（**逐位相同**，用例钉住）；
- 「今天没有决策」的臂在页面上写「**今日无决策**」，与「今日有决策」**开头就不同**（P56 §2 的既有纪律）；
- 停飞臂显示「历史版本（已停飞）」且**不显示为缺决策**；
- 页面上**不出现**买卖建议 / 方向预测 / 推荐某一臂（`paper/config.py` 的禁令词用例继续全绿）。

### T6 反目标

- ❌ 不改账本/决策/成本/PIT 语义，❌ 不加任何写入口（页面仍零写），❌ 不改主干常量，
  ❌ 不把 `paper agent run` 塞进 `CLOSE_STEPS`，❌ 不写库（真库只读；需要写的一律在**副本**上做，§5）
