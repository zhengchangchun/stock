## 载荷每个字段的计算口径

| 字段 | 怎么来的 |
|------|---------|
| `asof_date` | CLI 入参，必须是「日历 ∩ 行情轴」上的交易日，否则退出码 2 |
| `target_date` | 优先 `trading_calendar` 的下一行（`target_date_source=trading_calendar`）；日历耗尽时按工作日外推并**显式标注** `weekday_fallback`（真实库现在就是这种） |
| `direction` | `r_i = ln(C_i/C_{i-1})` 取最近 `WINDOW=60` 日 → `Normal(mean, stdev)`；`p_down = Φ(ln0.995)`、`p_up = 1-Φ(ln1.005)`、`p_flat = 1-p_up-p_down`（减法 → 三者和恒为 1.0）。阈值 ±0.5% 由总纲 §8.2 规定 |
| `range_80` | `C·exp(μ ± z80·σ)`，`z80 = Φ⁻¹(0.90)` —— 模型**分位数**，不是拟合出来的覆盖率 |
| `key_levels` | 20 日低点/高点；`p_touch` 用**实测**上/下影线均值做日内延展近似 |
| `action` / `size_pct` | flat 最大 → `wait`/0；否则 `add`/`trim`，`size_pct = 100·(1-不利方向概率)`，载荷里明写**「不可直接执行」** |
| `invalidate_if` | 由上面**算出来**的支撑/阻力位格式化生成，不是手写文案 |
| `strategy_mix` | 权重要逐字列出；`degenerate: true`、`excluded`（含引用的实验台账路径）、`benchmark_only` —— 退化态显式化 |
| `model_version` | `stocklab/predict/version.py` 唯一真源，带变更史 |
| `evidence`（**不进 hash**） | `mu/sigma/close/period` 等全部中间量，任何数字都可复算 |

## 遗留问题（明说）

**弱/近似字段**：
1. `target_date` 走的是 `weekday_fallback` —— 不是真交易日历，会把节假日算成交易日。
2. `mu`（漂移项）是**最弱的证据**：真实值 t 值约 0.97~1.49，基本是噪声；载荷原样暴露 `drift_t` 供读者自己判断。
3. `range_80` / `p_touch` 假设对数正态、独立同分布，忽略跳空、涨跌停与日内路径 —— §8.2 的「长期命中率 ≈ 80%」才是对它的真检验（P7 才做）。
4. `size_pct` **不可直接执行**（无成本、无风险预算、不知持仓）。
5. `p_touch` 的日内延展用的是均值近似，非路径模拟。

**因数据缺口无法参与的策略**：
- `trend_ma`：已被样本外否证（510.79% vs buy_and_hold 881.75%），`excluded_falsified`；
- `buy_and_hold`：只作对照，不提供次日方向信息，`benchmark_only`；
- **其余任何已注册策略**：`inactive_unproven`，**权重恒为空** → `degenerate: true`。
  这是**如实反映**，不是「假装有多策略集成」。加入白名单的条件写在 `version.py`。
- 数据只有 2 只标的；`features_daily` 的 `regime_label` / `main_net_5d` / `pe_pct_3y` 全为 NULL → 模型**不读 features_daily 任何一列**（`features_used: []`），从结构上杜绝「NULL 当 0」。
