## 0. 一句话

让模块2 的读数**自己长**：把「通路 A（按**在飞**策略版本）→ 通路 B → 事后打分」接进 `ops close`
的固定顺序，闸门复用 P46 那道「当天 K 线定型了吗」；**没有在飞版本时如实 skipped**，
只有「配置了却坏了」才把链报红。

> 本站**只接线**：不动 `m2 channel a|b`、`m2 score` 的语义，也不动 P41/P48 的读数口径。

## 1. 口径（本站拍板；可单条回退）

1. **单一入口**：新增 CLI **`m2 daily --asof <交易日> [--db] [--now]`**，`ops close` 里**只加一步**
   （步骤名 `m2_daily`，`supports_db=True`，位置 = `paper_step` **之后**、`doctor` **之前**）。
   理由：`CLOSE_STEPS` 是**静态元组**，而「这一轮要跑哪些策略版本」只有运行期才知道；
   把遍历放进 CLI，链的顺序语义与页面的「一行一步」都不会被动态步数搞乱。
2. **跑什么**（顺序即依赖顺序）：
   - **通路 B 总是跑**：`m2 channel b --asof {asof}`（镜像 `arm-now`，与人当天有没有下单无关，幂等）；
   - **通路 A 遍历「在飞版本」**：账户存在（`arm-agent-*`）**且**该版本的验证周期不是 `frozen`、
     未被熔断终止 ⇒ 逐个 `m2 channel a --asof {asof} --strategy-version <v>`；
     **0 个在飞版本 ⇒ 记一行 `skipped` 并把原因写清**（`没有在飞的策略版本`），**这不是失败**。
     > P49 尚未落地时（状态真源还没有 `validating`/`frozen`），退化为「账户存在即跑」，
     > 并在「实施记录」里**点名这条退化**（不许假装已经按状态过滤）。
   - **打分总是跑**：`m2 score --asof {asof}`（只给 `target_date <= asof` 且还没打过分的那批）。
3. **K 线定型闸门（复用 P46，不许另写判据）**：`asof == 今天` 且
   `session/close.py::bars_finalized_on(conn, asof)` 判「未定型」⇒ **exit 2、一行都不写**
   （与 `predict run --asof 今天` 同款 fail-closed；理由见 P46 事故：`m2_forecasts` 也是 append-only）。
4. **退出码**（沿用既有语义，不发明新的）：
   | 码 | 含义 |
   |---|---|
   | 0 | 全跑完（含 `already` 幂等、含「通路 A 无在飞版本」的 `skipped`） |
   | 2 | 未定型 / 库不可用 / 输入不合法（`--asof` 不是交易日） |
   | 4 | **有通路或打分 `rejected`**（配置了却坏了 ⇒ 链上必须报红，不许静默） |
5. **不做重试、不做补写**：通路与打分各自的幂等键已经够（`ran_run` / `forecast_id` UNIQUE）；
   本站**不许**给它们加「重试」「补跑昨天」之类的兜底（兜底会把「漏跑」变成看不见）。
6. **页面**：`/lab/ops` 的步骤表**自动**多一行（步数不许写死）；`/lab/m2` 顶部加一句
   「上次通路运行：`<日期>` / `ran|skipped|rejected`（没有就写「从未」）」，**只读、不重算**、
   不提供任何触发按钮。

### 2. 口径落地（与任务书 §1 的逐条对应）

- **在飞版本 = 两条判据，不加第三条**：账户存在（谓词走既有的
  `paper/engine.py::external_executor == m2/config.EXECUTOR_CHANNEL_A`，不靠前缀猜）
  **且** 该版本**最近一轮**周期既没被 `circuit_breaker` 终止、脚本也不是 `frozen`
  （脚本状态走 `plugin/lifecycle.py::script_state`）。
  「最近一轮」是本站的落地解读（`validation_end` 收尾**不排除**，D-44 的「微调 ⇒ 同版本新开周期」靠它接回来）
  —— 用例 `test_a_finished_cycle_keeps_the_version_in_flight` 把「没顺手加第三条」钉住。
- **路径顺序 = B → A（按版本升序遍历）→ 打分**；打分是 `score_all(asof=asof)`，只给
  `target_date <= asof` 且还没打分的（当天新建的预测目标日必然是下一个交易日 ⇒ 只会数出 `pending`，
  由 `test_t1_score_lands_rows_on_the_following_day` 钉住「`asof` 推到次日就会落行」）。
- **退出码**：0 = 全跑完（含 `already`、含「没有在飞版本」的 skipped）；2 = 未定型 / 库不可用 /
  输入不合法；4 = 有通路 `rejected`（`cli/main.py::EXIT_REJECTED`，**没有新数字**）。
  一步的 `exit_code` 是「它对整轮退出码的贡献」（skipped 的步给 0）。
  **为什么 skipped 不能用 3**：链的停止线把 ≥2 当**结构性失败**（`ops/runner.py::run_steps`）
  ⇒ 报 3 会让一次「等数据」把整条收盘链**截断**（`doctor` 再也跑不到）。理由写在 `m2/daily.py` 模块 docstring。
- **闸门**：`asof == 今天` 时调 `session/close.py::bars_finalized_on`（**P46 那一道，一行判据都没另写**），
  未定型 ⇒ exit 2；历史 `asof` 完全不判。
- **`--asof` 不是交易日**的判据复用 `predict/service.py::assert_session`（日历 ∩ 行情轴），
  与 `predict run` 同一条，不另造交易日判定。
