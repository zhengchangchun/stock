## §0.6 为什么必须锁 ECDF（含自身、右闭）、为什么 `x <= 0` 判缺失

- **ECDF 三条歧义必须一次锁死**：① 含**不含** `x` 自身；② 用 `<=` 还是 `<`；③ 并列（tie）要不要取平均名次。
  三种选法给出**三套不同值域**（含自身 `(0,1]` / 不含自身 `[0,1)` / 平均名次 `(0,1)`）。同一份数据换一种读法，
  `zero_ratio_p50` 与 `tie_ratio_p50` 都会变 ⇒ 口径不写死就没法跟后面的实验比。**本档锁「含自身 ＋ `<=`」**，
  理由＝P95 §5.2 的原话是「当前 PE 处于**自身 3 年区间**的百分位」—— 日常读法就是把当前值也放进去排名。
  另两条理由：`<=` 让横截面值的**单调方向**与 `pe_ttm` 一致（`rank_pct` 升序 ⇒ PE 越高越接近 1.0），
  且「最大值 = 1.0」比「最小值 = 0.0」更好判读（0 会让 `zero_ratio` 误报）。
- **并列取「不平均」**（直接数 `<=` 的个数）：`pe_ttm` 是连续量、实测并列极罕见；引入平均名次会让
  「同一只标的的同一份历史」在两次不同实现下产出不同小数 ⇒ 无收益、只增歧义。**照实报 `tie_ratio_p50`即可。**
- **`x <= 0` 为什么整只判缺失**：负 PE（亏损）不是「很便宜」，把它放进参照集会把整段历史的分位压歪；
  P95 §5.2 明写「负 PE 样本**剔除出参照集**（不是当 0）」。当前值为负时更不可能有「百分位」的日常含义
  ⇒ **整只 `None`**（与 VAL-A 的 `pe_ttm <= 0 ⇒ 缺失` 同规，理由也是「不取绝对值」）。
- **`|S| >= 252` 为什么是硬闸**：756 个交易日里只有 `pe_ttm > 0` 的样本参与排名 ⇒ 长期亏损/停牌的标的
  参照集很小，分位会被少数样本支配。P95 §5.2 逐字要求 ≥ 252（≈1 年）。
- **有效起点（只作注释、不作断言）**：`valuation_daily` 首行 `2018-01-02` ≥ 756 个交易日 ⇒ **2021-02-08**；
  再叠加 `|S| >= 252` ⇒ 实际起点可能更晚。⇒ 全窗实验的**训练段会被砍掉一大截**，验证段有效日期数
  **可能 < 120 ⇒ `INCONCLUSIVE`**（P95 §8 第 471 行已预判）。**这是本档最可能的结果，站不许据此改口径。**
