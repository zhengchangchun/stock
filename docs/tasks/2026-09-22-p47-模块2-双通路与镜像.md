## 0. 一句话

把「候选池」接到**两条并行通路**上，用**既有模拟盘引擎**跑出两个可比较的账户 ——
通路 A（AI 插桩选股 → 模拟执行 → A3 预测）与通路 B（人工真实操作 → 镜像复刻 → B1 预测），
两条通路**资金隔离**、**同一套成交与净值口径**、**可幂等重放**。

## 2. 通路 A（纯模拟，无实盘）

固定顺序（02 §主流程「AI 不可修改流转逻辑」⇒ 步骤顺序写在**主干代码**里，插桩只能填内容）：

1. **A1**（`m2_a1`）从候选池（短/中/长三池）二次选股 → `{picks:[{code, weight_pct, reason}], cash_pct}`；
2. **模拟买入**：按权重与**T 日收盘/次日可成交口径**（沿用既有 `paper` 引擎的成交口径，不新造）；
3. **A2**（`m2_a2`）卖出/调仓/止盈止损 → `{orders:[{code, side:'sell', reason}]}`；
4. **更新账户**：现金 / 持仓 / 净值 / 交易日志（`paper_trades` / `paper_nav_daily`）；
5. **A3**（`m2_a3`）持仓收益预测落库（**append-only，不可篡改**）。

**每周一个决策？不**：决策频率按「每交易日一次」（与 P37 对齐；需求 02 没写频率 ⇒ 这是要落成常量的口径，
见 §6 待澄清）。

## 3. 通路 B（人工 → 镜像）

1. 人工录入真实操作（date/code/side/price/qty/fee）——数据源＝既有 `portfolio/` + `real_trades`
   （⚠️ 既有口径是「实盘账本重放」，不是「人工录入操作的复刻」，见 02 顶部现状注）；
2. **镜像账户**＝按 F 流水**逐笔复刻**（D-25），**复用既有 `arm-now` 实现**，不新建第二套镜像代码；
3. **B1**（`m2_b1`）对人工持仓做收益概率预测，落库；
4. 保存人工交易日志 + 镜像账户快照。
