## 0. 背景

### 0.1 一句话

**`candidate/replay.py::period_returns` 算组合收益用的是未复权价，而全库其它价格路径都走
PIT 复权价** —— 除权日的跳空被算成组合亏损，`xsec-topn` 的 Δ 因此带着一个**未知量级**的口径污染。

### 0.2 代码事实（不是猜测）

| 事实 | 位置 |
|---|---|
| 周期毛收益 = `p1 / p0 − 1`，`p0/p1` 由 `_close_dated` / `_close_on` 直读 `bars_daily.close` | `candidate/replay.py:272-289` |
| `bars_daily` 全表 `adj_mode='none'` ⇒ 上面的 `close` 是**未复权价** | 真库只读实测 |
| 库内唯一的复权读数入口 = `adjust.load_bars_adjusted(conn, code, as_of, *, start)`（只累乘 `cqr ≤ as_of` 的事件） | `data/adjust.py:364` |
| 涨跌停判定走 `_prev_close`（未复权）＋ `_limit_hit` | `candidate/replay.py:159-165, 286, 318, 331` |
| P77 先例：**打分**改走 PIT 复权价、**涨跌停判定保留未复权价** | ADR-029 |

### 0.3 为什么现在做（且为什么不能顺手把默认改掉）

- ADR-030 已把这条写成**已知遗留**并锁定「本站不修、另立任务书评估（先在库副本上量化影响，不改口径）」；
  P77 已经落地，所以此刻改 `replay.py` **不再与别的口径切换混在一起** ⇒ 可以是单变量。
- 但 `period_returns` 同时被 `research/xsec.py`（组合级读数）与 `plugin/sandbox.py`
  （插桩沙盒回放）调用 ⇒ **直接改默认 = 一次改两个消费者的读数**。
  本站因此采用**开关式实现（默认逐位不变）**，评估与采纳分开。

### 0.4 不许回退的既有口径

| 口径 | 谁定的 | 本站 |
|---|---|---|
| 成本模型（佣金/印花/过户/滑点）、`_qty_for` 名义仓位 | ADR-017 D-13/D-14 | **一字不动** |
| 涨跌停判定（未复权 `prev_close`）×  `Finding 2`「d0 涨停不进 gross」 | ADR-017 / P60 | **一字不动** |
| 「用 `hold`（不是 `nxt`）算 `[d0,d1]` 收益」的无未来函数语义 | `replay.py:263-281` | **一字不动** |
| `guard_pit_prices` 守卫 | 硬约束 5 | **一字不动** |
| `candidate/screen.py` / `score.py` / `risk_adjust.py` / `builtin/` / `data/adjust.py` / `paper/` `m2/` `predict/` `verify/` `ops/` | 多处 | **零改动** |

## 0.5 锁定口径（按顺序执行；要改先回来说，不要自作主张）

- **D1｜开关式，默认逐位不变**：`period_returns(..., price_mode: str = "raw")`，
  取值只许 `"raw" | "adj"`。**默认 `"raw"` = 现状**；`plugin/sandbox.py` 的调用**一个字都不改**
  （它不传该参数 ⇒ 自动走 raw）。
- **D2｜只换收益分子/分母**：`"adj"` 模式下 **只**把 `p0 / p1` 换成 PIT 复权收盘价；
  **成本侧成交价、`_qty_for` 整手、涨跌停判定一律保持未复权**（与 P77/ADR-029 同构：
  收益用复权、交易约束用真实价）。
- **D3｜复权不可用必须回退＋计数**：`MissingFactor` / `EtfChainUnsupported` / 该日无 bar
  ⇒ 该只该期**回退未复权价**，按 `(code, 周期)` 去重计入 `n_adj_fallback`；
  **不抛异常、不静默**（`_ADJ_UNAVAILABLE` 式的显式集合，名字照 `candidate/run.py` 的既有写法）。
- **D4｜AS-OF**：取 `d1` 价用 `load_bars_adjusted(conn, code, as_of=d1)`（只累乘 `cqr ≤ d1`）；
  `start` 传该只链的 `usable_from`（`adjust.load_chain` 已有），缩窗口是**显式决定**、要写进注释。
- **D5｜只增键**：结果 JSON 新增 `price_mode`（`"raw"|"adj"|"both"`）、`n_adj_fallback`（int）。
  **不许**改任何既有键的名字或语义。
- **D6｜`--price-mode both`**：一次扫描（`_scan_holds` 只跑一次）下同时出 raw 与 adj 两套读数，
  便于并排对照；`both` 时产物文件名带 `-adj` 后缀，**不得覆盖** `reports/research/` 里既有的 raw 产物。
- **D7｜不做采纳**：本站**只**产出读数与开关；把默认切到 `adj` 是**另一次**决定（另立任务书）。
- **D8｜真库只读**：全量跑一律在真库的 **APFS 克隆副本**上（`cp -c`），真库 sha 跑前 == 跑后；
  红线三目标 `docs/baselines/redlines.json` **不许 regen**。

### 7.1 T1 开关式实现（D1/D2/D3/D4）

- `period_returns(..., price_mode: str = "raw" | "adj")`，默认 `"raw"`；未知取值抛
  `ValueError`（`both` 是 CLI 层「一次扫描出两套」的事，不是本函数的取值）。
  `_ADJ_UNAVAILABLE` 三类与 `candidate/run.py` / `research/signal.py` **同一集合**。
- **raw 分支与改动前逐行等价**：原 `if p0.get(c) and p1.get(c): gains.append(p1[c]/p0[c]-1.0)`
  只是先取成 `q0, q1` 再走同一表达式；`_AdjCloses` 在 raw 档**根本不构造**
  ⇒ 连一次 `load_chain` 都不发生（数值与开销**都不变**）。
- `adj` 档**只**换收益侧的 `p0/p1`；成本侧成交价、`_qty_for` 整手、涨跌停判定、
  `guard_pit_prices` 守卫一字不动（D2 / 与 P77·ADR-029 同构）。
- D3 回退：三类复权不可用 / `d0 < chain.usable_from` / 该日无 bar ⇒ 该只该期回退
  未复权价，按 `(code, 周期)` 去重计入 `n_adj_fallback`（旁路出口 `price_stats`，
  默认不传即零副作用），不抛异常也不静默；裸 `AdjustError` 原样抛。
- D4 AS-OF：`as_of = d1`、`start = chain.usable_from`（显式缩窗口，写在注释里）。

**D4 有一处实现差异，如实记录**：任务书写「取 `d1` 价用
`load_bars_adjusted(conn, code, as_of=d1)`」。本站保留它的**全部三步与全部语义**
（`load_chain` → `assert_blackout_current` → `adjust_bars(..., as_of=d1,
start=chain.usable_from)` —— 这就是 `load_bars_adjusted` 的实现），但把前两步按
`code` 缓存、第三步只传该周期要用的**两根 bar**。理由是实测：真库单只 8500 根 K 线，
`load_bars_adjusted` **32 ms/次**，而它会被逐 `(code, 周期)` 重跑几万次（全窗两臂
≈ 8.5 万次 ⇒ 单臂约 45 min）。拆开后短窗 both 档的 `replay_s` 只有 **13.9 s**（见
§7.4）。等价性**不是自证**：`test_adj_pair_matches_load_bars_adjusted` 直接拿
`load_bars_adjusted` 的**返回值**逐位对照，覆盖三种形态（无事件 / 有可定价事件 /
事件在窗口外）。`d0 >= chain.usable_from` 那条守卫是**显式前提**——变异实验显示
去掉它也等价（`adjust_bars` 自己会按 `start` 滤掉 `d0`），留着是为了让「传两根 bar
与传全量 bars 等价」这条推理的前提**写在代码里**。

### 7.3 T3 用例（`tests/test_replay_price_mode.py`，15 条）
