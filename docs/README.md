# 项目文档

本项目采用「先验证，后交付」的开发工作体系。每次任务都遵循：**需求澄清 → 任务拆分 → 计划 → 实现 → 验证 → 交付**。

## 目录结构

```
docs/
├── README.md              # 本文档索引
├── architecture/          # 架构文档（代码设计思路）
├── tasks/                 # 任务拆分与跟踪
├── plans/                 # 设计与实现计划（superpowers 产物）
├── decisions/             # 设计决策记录（ADR）
├── diagnostics/           # 实测证据 / 复核报告（只记实测数字）
└── errors/                # 错误日记
    └── ERROR_DIARY.md     # 错误与教训记录
```
