# 诊断：命中 `invalidate_if` 的子群，方向准确率为何是 66.9%？

- **日期**：2026-09-15（P8 Task 42）
- **触发**：P7 遗留观察 —— 命中 `invalidate_if` 的 665 行方向准确率 66.9%，
  其余 5373 行仅 34.5%，聚合值像「两个异质子群的混合」，暗示存在可利用的结构。
- **结论**：**(b) 失效条件与结果同源** —— 该子群由**次日收盘**机械决定，
  任何 PIT 可观测的选行规则都复现不出来。66.9% **不可交易**，**不能**当作
  「模型在这些日子上有方向能力」的证据。**不是 (a)（无泄漏），也不是 (c)。**
- **复现命令**：`.venv/bin/python scripts/diagnose_invalidated_subgroup.py`（只读，不改任何口径）
- **本次只诊断**：未改任何代码口径、标签带、split、样本区间。

## 1. 中间量①：条件类型分布 —— 命中哪一侧，实际类就被**机械确定**

`invalidate_if` 的原文是「收盘跌破 `support`（20日低点）或收盘站上 `resistance`（20日高点）」，
而 `close_asof` **按构造落在 `[support, resistance]` 之内**（它是那个 20 日窗口的最后一根）。
于是：

> `close_t > resistance ≥ close_asof` ⟹ `actual_pct > 0`
> `close_t < support ≤ close_asof` ⟹ `actual_pct < 0`

```
  站上上界（突破）     n=  382  实际类={'up': 369, 'flat': 13}  模型预测类={'up': 287, 'down': 84, 'flat': 11}
  跌破下界（破位）     n=  283  实际类={'down': 268, 'flat': 14, 'up': 1}  模型预测类={'up': 96, 'down': 173, 'flat': 14}

  → 命中子群里 actual_class=='flat' 占比 = 4.06%（未命中子群 = 27.47%）
```

**96.6% 的突破行实际是 `up`，94.7% 的破位行实际是 `down`。** 命中子群把
「flat」这一类几乎整个排除了（4.06% vs 27.47%）。

也就是说：`invalidated` **不是**一个关于「预测质量」的变量，它是
**「明天收盘相对今天收盘落在哪一侧」的确定性函数** —— 它本身就在描述明天。

残余的 13 个 flat 突破 / 14 个 flat 破位是可解释的：`close_asof` 恰好**就是**
窗口极值时（`hi == close_asof`），任何微小的上行都会越界，于是
`invalidated=1` 而涨跌幅仍在 ±0.5% 内。那 1 个「破位却 up」的行，
最可能是复权锚点差异（`notes.adj_anchor` 是 `target_date`，而 `support`/`resistance`
在 `asof` 当日算出）—— 属已知的口径细节，不是 bug。

## 4. 中间量⑤：**决定性检验** —— PIT 选行规则能否复现 66.9%？

异质性要能变成策略，就必须有一个**只用 `<=asof` 信息**的规则，把大致同一批行选出来。
最自然的候选：**边界窄**（`min(上界距, 下界距)` 小 → 明天更容易越界）。

```
  min(上/下)距离 最小 10%      n=  603  模型准确率  37.48%  实际命中率  36.98%  其中真命中  223（准确率  68.16%）
  最小 20%                 n= 1207  模型准确率  37.70%  实际命中率  29.49%  其中真命中  356（准确率  71.07%）
  最小 33%                 n= 1992  模型准确率  37.30%  实际命中率  24.10%  其中真命中  480（准确率  68.54%）
  最宽 20%（反向对照）           n= 1207  模型准确率  42.42%  实际命中率   0.91%  其中真命中   11（准确率  63.64%）
```

**读法（这是本次诊断的关键一步）：**

1. 用 PIT 可观测的「最窄 10% 边界」选行，模型准确率 **37.48%** ——
   与全体基线的 38.14% **没有差别**。哪怕这组的实际命中率高达 36.98%
   （全体是 11.0%），准确率**一点没涨**。
2. 「其中真命中」那一列的 68.16% **不是**可拿的成绩：它是在**已经知道**
   `invalidated=1` 之后才数出来的 —— 而 `invalidated` 要等收盘才知道。
   这正是第 1 节那个「结果条件」的量化版本。
3. **反向对照**（最宽 20%）拿到 **42.42%**，比「最窄」还高 4.9pp。
   若真存在「窄边界 → 模型更准」的机制，这里应当反过来。它没有。

> **判定：没有任何 PIT 可观测的选行规则能复现 66.9%。**
> 66.9% 是 `E[准确率 | 明天真的越界]`，而「明天真的越界」在今天就不可知。

## 5. 那个 11.3pp 的「超额」是怎么来的（共享输入，非技能）

```
  按模型预测类条件化的边界距离：
  pred=up   n= 3488  到上界   5.63%  到下界   8.63%  → 命中率  10.98%
  pred=flat n=  274  到上界   3.59%  到下界   3.39%  → 命中率   9.12%
  pred=down n= 2276  到上界   9.69%  到下界   5.52%  → 命中率  11.29%
```

模型预测 `up` 时（`mu > 0`，近期上行），`close_asof` 本就贴着 20 日高点，
**上界只有 5.63% 远、下界有 8.63% 远** —— 上行越界比下行越界容易得多；
预测 `down` 时完全对称。

于是「模型预测的方向」与「会越哪一侧的界」**天然同向** ——
因为两者都是**同一个 20 日窗口形态**的函数：漂移 `mu` 定符号，窗口极值定边界。
这不是模型读懂了明天，而是**边界与预测共享输入**。

（注意：这只解释子群**内部**的相关性，不改变第 4 节的判定 ——
即便相关是真的，选行规则仍然不可 PIT 化。）

## 6. 结论：选 (b)

| 候选 | 判定 | 依据 |
|------|------|------|
| (a) 泄漏 / 口径 bug | **否** | 预测侧全程 PIT（`support`/`resistance` 只取 `<=asof` 窗口，`mutations_p8.py` 变异 1 可打红）；`invalidated` 用的是**次日收盘**，那是**结果**不是预测输入 |
| **(b) 失效条件与结果同源** | **✅ 是** | `close_asof ∈ [support, resistance]` 是构造保证 ⟹ 命中侧**机械决定**实际类（96.6% / 94.7%）；`invalidated` 是 `close_t` 的确定性函数 |
| (c) 真实可解释的异质性 | **否** | 无任何 PIT 选行规则可复现（最窄 10% → 37.48%）；反向对照（最宽）反而 42.42% |

**给下游的一句话**：66.9% / 34.5% 这组数字的分组键是**明天**，
它度量的是「已知结果之后的事后纯度」，**不是**模型的样本外能力。
把它读成「模型在突破日有 67% 方向能力」是本项目最贵的那类错误
（与 `index_300` 把同期共动读成领先信号同型，见 Task 41）。
