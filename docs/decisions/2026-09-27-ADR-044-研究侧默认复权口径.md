# ADR-044 研究侧默认复权口径（P94）

日期：2026-09-27 ｜ 状态：已实施 ｜ 上游：ADR-030 §已知遗留、P82（[`docs/tasks/2026-09-26-p82-组合回放复权价口径.md`](../tasks/2026-09-26-p82-组合回放复权价口径.md)）§7.2 D7、P94 任务书（[`docs/tasks/2026-09-27-p94-研究侧默认复权口径.md`](../tasks/2026-09-27-p94-研究侧默认复权口径.md)）

> 本 ADR 选择**新增一篇**（而不是给 ADR-030 追加「更新」段）。理由：这是一次**分叉**决定
> —— 研究路径默认切复权、契约层保持未复权 —— 与 ADR-030 自己的「本站不修」结论并存而非取代；
> 追加到 ADR-030 会把「度量口径」与「调用方默认值」两件事混进同一篇。

## 背景

ADR-030 把「`candidate/replay.py::period_returns` 的组合收益直读未复权价」写成**已知遗留**并锁定
「本站不修、另立任务书评估」。P82 把它做成开关（`--price-mode raw|adj|both`，默认 `raw`），
并在全窗 `2015-01-01 → 2026-09-24`（`csi300-500`，800 只）跑出并排读数：

| 收益侧口径 | 验证段 Δ/期 | 95% CI | verdict | n_validate |
|---|---|---|---|---|
| `raw` | +0.3025% | `[-0.5076%, +1.1480%]` | **LOSE** | 171 |
| `adj` | +0.2757% | `[-0.5401%, +1.1038%]` | **LOSE** | 171 |

影响面（P82 §7.5 只读实测）：全窗 **453/570 = 79.5%** 的调仓周期里至少一只成员发生除权
⇒ 未复权口径的污染面覆盖八成观测单元，不是边角。P82 的 D7 明确「不做采纳、另立任务书」——
本 P94 就是那次采纳决定。

## 决定

### 1. 研究命令默认切 `adj`，取值集合不变

`stocklab/cli/main.py` 的 `research xsec-topn --price-mode` **argparse 默认值** `raw → adj`
（`choices=("raw","adj","both")` 三档不动）；`stocklab/cli/research.py` 的
`getattr(args, "price_mode", …)` 兜底常量同步为 `xsec.PRICE_MODE_ADJ`（**不写裸字符串**）。
`raw` / `both` 仍可显式指定。help 文案点明「默认 adj = PIT 复权价，与 ADR-030 对齐」。

### 2. 契约层一字不动（本 ADR 的**最硬边界**）

`candidate/replay.py::period_returns` 的形参默认（`price_mode: str = DEFAULT_PRICE_MODE`）
**保持现状**，`DEFAULT_PRICE_MODE` 常量语义不变；`plugin/sandbox.py` 的调用**一个字都不改**
（它不传该参数 ⇒ 自动走 raw）。

**理由**：沙盒读数是插件版本之间的对照基线。默认口径一变，历史 `source_sha256` 的对照关系就漂
—— 那是**跨版本比对**，不是**同版本研究**。本站只改「谁在调」（CLI 默认值），不改「函数怎么默认」。
可证伪：若这两处出现任何逐位变化，本变更作废。

### 3. 基准口径显式化（P82 披露① 收口）

`excess_index300` 用的是指数**自身价格**、**不可复权**（指数没有除权概念；现状即如此）。
报告 JSON **只增键** `benchmark_price_mode`，恒为 `"raw"`，并在 md 口径段（§3）原样点名。
**不把指数塞进复权链、不编造复权基准。**

### 4. 产物名一档一名（P82 披露② 收口）

P82 时 `adj` 与 `both` 共用 `-adj` 后缀（同目录先后跑会互相覆盖）。改为：
`raw` → 无后缀、`adj` → `-adj`、`both` → `-both`，三档**互不覆盖**。
`reports/research/` 里的既有文件**不删、不覆盖**。

### 5. 口径变更是**记账**，不是「策略变好」

两口径 verdict **都是 `LOSE`**。采纳 `adj` 的唯一理由是**不留已知偏差**在默认路径上 ——
**不得**写成「切了 adj 所以策略更好」。既有 `LOSE` 结论在 adj 口径下同样成立，
证据就是上表的 P82 全窗读数（**不重跑、不改写**）。

## 判据（可证伪）

1. 契约层逐位不改：不传 `price_mode` 的 `period_returns` 调用逐位不变（既有用例继续绿）；
   `plugin/sandbox.py` 的调用点不传 `price_mode`（源码扫描 ＋ AST 两档钉住）。
2. 不传 `--price-mode` 的 `research xsec-topn` ⇒ 报告 `price_mode == "adj"`，产物名带 `-adj`。
3. `--price-mode raw` 仍产出无后缀产物、`price_mode == "raw"`、`n_adj_fallback == 0`。
4. `benchmark_price_mode` 在三档都出现且恒 `"raw"`；md §3 点名。
5. 全量 `pytest` 绿、`verify.sh` exit 0、红线三目标 sha 逐位 == 基线且**未 regen**、
   真库 sha 跑前 == 跑后。

## 后果 / 已知边界

- 默认口径变了 ⇒ 与 P82/P60 之前**已产出的** `reports/research/*.json` 里的 `arms`/`delta`
  不再与「今天不传参数跑出来的」逐字段相同（那些产物是 raw 档，其文件名无后缀 ⇒ 仍可显式
  `--price-mode raw` 复现）。**旧读数不会自动重算**，引用时按文件名区分口径。
- `research rank-ic` / `factor-ic` 的前向收益**早已**走 PIT 复权价（ADR-030）⇒ 本次把
  `xsec-topn` 的组合收益对齐到同一口径，ADR-030 那条「两者绝对值不可直接比」的备注**部分缓解**
  （口径已同，仅剩宇宙/度量对象差异）。
- 指数基准仍是 raw（§3），所以 `excess_index300` 不随 `--price-mode` 变。

## 怎么改回来

把 `cli/main.py` 的 `--price-mode` 默认改回 `"raw"`、`cli/research.py` 的兜底改回
`xsec.PRICE_MODE_RAW` 即可（契约层从未移动）；报告层无需回改（`-both` 后缀与
`benchmark_price_mode` 键都是纯增量）。
