# ADR-004 复权落点：读取层复权 + 自建乘性因子链

日期：2026-09-15 ｜ 状态：已采纳 ｜ 前置：ADR-001（落不复权 OHLC）、ADR-003（腾讯分页）
证据：`docs/decisions/evidence/probe-corp-actions-2026-09-15.json`（探针真实联网原始输出）

## 决策

**复权落在读取层，不落存储层。** 库里永远只有不复权 OHLC（`bars_daily.adj_mode='none'`）；
复权是 `adjust.load_bars_adjusted(conn, code, as_of)` 在读取时用因子链现算的。
`adj_factors` 只存**乘性因子**（`factor ∈ (0,1]`），不存复权价。

理由：
1. **as-of 语义只能在读取层表达。** 同一份不复权 K 线在 `as_of=2024-01-01` 与 `as_of=2026-09-14`
   下必须给出不同复权价；写死一份复权价进库，等于把「用哪个 as_of」这个决定固化在写入时刻，
   而写入时刻 ≠ 回测时刻 → 隐性未来信息。
2. **契约强制。** `adjust_bars` 产出的 `Bar.adj_mode="qfq"`，`repo.insert_bars` 直接拒绝
   （测试 `test_adjusted_prices_mark_themselves_as_qfq`）→ 复权价物理上落不了库。
3. **存储层方案需要每年全表重写**（新除权事件会改变全部历史价），而 append-only + 唯一写入口的
   纪律下全表重写本身就是要避免的操作。

## 探针实测（四条，全部真实联网）

| # | 发现 | 后果 |
|---|------|------|
| P1 | **`adj=none` 响应同样携带事件行**，内容与 qfq 完全一致（000333 14/14，600690 36/36） | 事件采集走不复权流：2000/页，000333 两次请求搞定；qfq 上限 800 需 4~5 次翻页 |
| P2 | 事件随 `end` 锚点分页一路回溯到上市首日（600690 到 1993-11-19） | 因子链可以覆盖全历史 |
| P3 | **腾讯 qfq 是减法式**（原价 − 累计每股派息）：000333 2013-09-18 = **−12.649 元** | qfq 序列不可用于任何比率类特征（跨零点翻号）→ 必须自建乘性链 |
| P4 | `fh_sh` 两处不可信：2014/2015 是**税后值**（20→19、10→9.5）；送转-only 事件是**空串**（600690 9/36 条） | 条款**只认 `FHcontent` 原文**；`fh_sh` 仅作参考字段存库 |

## 对 ADR-001 的偏离（明示）

ADR-001 写的规则是 `factor(t)=Π(1−现金分红/除权前收盘)`，**只含现金**。实测 000333 的
`10派20元转15股` 只扣现金得 k=0.957（正确值约 0.383）—— 送转必须进公式，ADR-001 的写法是
标准除权价公式在「纯现金」下的特例。本 ADR 采用：

    k = (pre_close − 每股现金) / (pre_close × (1 + 每股送转比例))

纯现金时退化回 ADR-001 原式（测试 `test_event_factor_matches_adr001_for_pure_cash` 钉住）。
含**配股**的事件解析不了（配股价不在事件行里）→ 抛 `UnpriceableTerms`，**不猜**。

## 无法定价的事件：不静默、不缩窗口

解析不出条款的事件其 k **完全不进链**，后果精确为：**恰好在它除权日那一天的收益里假跌幅原样保留**
（其余日期不受影响，因为 `multiplier(t2)/multiplier(t1)` 只含 `(t1,t2]` 内的事件）。
因此 `adjust_bars` 只要发现窗口 `(t_min, base_date]` 内有不可定价事件就抛 `MissingFactor`；
要放弃那段历史必须调用方**显式**传 `start=chain.usable_from`（缩窗口是一个决定，不替调用方默默做）。

## 对 P3 已落快照的影响

- `FEATURE_VERSION` v1 → **v2**（v1 在不复权价上算 `ret_1d/ma/atr`，除权日失真）。
- v1 快照**不重算、不覆盖**：`features_daily` append-only，主键含 `feature_version`；
  v2 作为新行写入。回测选版本时必须**显式**指定，默认取最新版。
- 留痕：v2 快照的 `data_version = "bars:<date>;adj:<N>events"`，可反查当时用了多少条事件。
- ❌ **不做**的事：不删 v1、不改 v1、不用 v2 覆盖同名行。
