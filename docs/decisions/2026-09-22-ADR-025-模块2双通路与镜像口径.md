# ADR-025 模块2 双通路与镜像口径（D-39 – D-42）

- 日期：2026-09-22
- 状态：**提案 → 已采纳**（四条口径由 Claude Code 按推荐项落地，nanobot 2026-09-22 深夜逐条复核追认，
  见 `docs/plans/2026-09-21-需求澄清录.md` §8；**每条可单条回退**）
- 相关：ADR-010（模拟盘口径）、ADR-021（状态机与主干常量）、ADR-022（插桩契约）、ADR-024（AI 操盘手护栏）、
  需求书 `docs/plans/2026-09-22-模块2-需求书.md`（D-24–D-33）、
  任务书 `docs/tasks/2026-09-22-p47-模块2-双通路与镜像.md`

## 背景

模块2 要求「候选池 → 两条并行通路 → 两个可比较的账户」：
**通路 A**（AI 插桩选股 → 模拟执行 → A3 预测）与
**通路 B**（人工真实操作 → 镜像复刻 → B1 预测），两条**资金隔离**、同一套成交与净值口径、可幂等重放。

P47 任务书 §6 点名四条「不自行拍板」的口径（落哪张表 / 决策频率 / 人工录入真源 / 与 P49·P44 的挂接点）。
实现者先按推荐项落地、逐条标注回退代价，本 ADR 把它们固化为生效口径。

## 决策

### ① 通路 A 的账户与「谁落这一天的净值」（D-35 的落地）

- 账户命名 = `arm-agent-<策略版本>`，**不新开第三套命名**（D-35）。策略版本 = 这一版的**插桩组合**
  （`plugin_audit` 里那几版 `m2_a1/a2/a3`），**不是** `MODEL_VERSION` —— 后者是 `predict` 管线的版本，
  红线基线按它**分列**，拿插桩版本号冒充会污染那套分列。
- 每个策略版本 = **一个 `paper_accounts` 行 + 独立 NAV**（D-26），不共享现金池。
- 账户行在 `params_json` 里显式声明 `executor = "m2_channel_a"`；
  `paper/engine.py::external_executor` 据此**让出**该账户的日终认领权。
  **为什么必须是显式字段**：`paper step` 的幂等判据是「当日 `paper_nav_daily` 行是否已存在」——
  若它也认领通路 A 的账户，就会先写一条「没有成交的净值」，于是那条策略**永远不下单**。
  靠账户名前缀猜路数是不行的：`arm-agent-v1` 与 `arm-agent` 只差后缀，改名字那天没人会记得同步判据。
- 策略版本号形状**保守窄口径**（`^[a-z0-9][a-z0-9._-]{0,31}$`）：不合形状**拒绝**，不做字符替换
  （替换会让「报告里的版本」与「台账里的版本」变成两个东西）。

### ② 通路 A 主干顺序（写死在主干，插桩只能填内容）

`A1(m2_a1) 池内二次选股 → 模拟买入 → A2(m2_a2) 卖出/调仓 → 更新账户（现金/持仓/净值/成交） → A3(m2_a3) 预测落库`

- **不新造成交/费用/净值口径**：成交与费用走 `paper/rules.py::plan_target_weight` + `_fee_parts`，
  净值/回撤走 `paper/engine.py::mark_to_market` / `drawdown` / `arm_state_for`，
  落库走 `paper/store.py::insert_trade` / `insert_nav`，PIT 走 `paper/rules.py::check_no_lookahead`。
- **为什么 `m2/` 不在 `paper/` 里**：`tests/test_paper_discipline_guard.py` 钉住「`paper/` 不 import
  选股链路与插桩」；通路 A 必须同时碰 `candidate` 与 `plugin`，所以它住在 `stocklab/m2/` ——
  **编排在上面，执行口径在下面**。

### ③ **D-39**：A3/B1 落**新表** `m2_forecasts`，模块2 的预测**不进** `predictions`

- 表：`m2_forecasts`（append-only + 触发器），列名沿用 `predictions` 的**落库列名**
  （`range_lo/range_hi`、`direction_*`），不是契约名（`range_80`/`direction`）——契约名是
  `predict/model.py::CONTRACT_FIELDS` 的真源，列名是 `payload_to_row` 的落库约定，两套名字是既有分工。
- 幂等键 `(account_id, asof_date, code)`；**溯源三件套** `script_id` / `script_version` / `input_sha256`
  （哪一版插桩、在什么 PIT 输入上算的）。
- **为什么不复用 `predictions`**：红线基线按 `model_version` 分列（拿插桩版本当 `model_version` 会污染分列），
  且 `verifications` 用 `pred_id` 外键，混进去会把插桩预测卷进「模型准确率」的统计（D-30 的口径分工）。
- 回退代价：改用 `predictions` + `m2-` 前缀版本号 ⇒ 必须显式改红线/统计的分列规则，等于动红线口径。

### ④ **D-40**：通路 A 的决策频率 = **每交易日一次**（`DECISION_CADENCE='per_trading_day'`）

- 与 `arm-agent` 的「每交易日一条操盘决策」同一心跳（与 D-34 同源）；
  两条 AI 臂若不同频，「谁跑赢了」里就混着「谁动得多」。
- **刻意不跟随** `rebalance_cadence`（静态纪律臂的 5/10/15 日再平衡）：那是另一条臂的心跳。
- 非交易日不出决策（走 T7：跳过并留痕，不补造）。

### ⑤ **D-41**：「人工录入」的真源 = `real_trades` + `cash_flows`（`portfolio/` CLI），**不新开第二套录入表**

- 通路 B 只做**镜像复刻**，复用既有 `arm-now`（D-25：不新建第二套镜像代码）。
  `m2/channel_b.py` 不得定义 `mark_to_market`/`drawdown`、必须走 `engine.step_account`；
  `m2/`（除 `store.py`）不得出现 `INSERT INTO`（写路径只有 `paper/store.py`）。
- 判据：同一份人工流水 ⇒ 镜像账户当日 `paper_nav_daily` 与 `arm-now` 那一行 **12 列逐字段相等**。
- 回退代价：新开 `manual_trades` ⇒ 两份「人工流水」，与 D-25 冲突。

### ⑥ **D-42**：与 P49（自评估/熔断）、P44（验证周期）的挂接点本轮**只留结构位**

- `plugin_audit` 事件与 `validation_events` 台账已就绪，**通路未接判定**；判定留 P49。
- 本轮不实现「进 `validating` / `frozen`」的任何触发。

### ⑦ 留痕与退出码（可核对的外部行为）

- `m2_channel_runs`（append-only）记每一次运行：`status ∈ {ran, skipped, rejected}` + `reason` +
  `plugins_json`（脚本版本溯源）+ `n_orders`。
  **部分唯一索引** `WHERE status='ran'`：同一 `(通路, 账户, 日)` 只许有一条成功记录 ——
  不能对整表加 UNIQUE，否则「今天缺 K 线跳过」会永久占住这一格，数据补齐后连一次成功都写不进来。
- **跳过与拒绝刻意分开**：`ChannelSkip`（缺当日 K 线/非交易日 ⇒ 等数据补齐重跑，事务已回滚）vs
  `ChannelReject`（插桩缺失/越界/账户状态异常 ⇒ 要人去看脚本）。合成一个「没跑成」会让
  「等一天」与「出事了」在读数上长得一样。
- CLI：`m2 account init` / `m2 channel a|b` / `m2 runs`；退出码 `ran`/`already` = 0、`skipped` = **3**、
  `rejected` = **4**。`already` **不落库**（幂等重放不是一次新运行）。

## 后果

- `/lab/paper` 与报告里，通路 A 的账户与 `arm-agent` 家族、通路 B 的镜像与 `arm-now`
  **并列同轴**展示；两条通路的资金互不可见（判据：跑 A 后镜像账户逐行不变，反之亦然）。
- 本轮**未做**（点名）：`instruments.sector` 回填与 features 的「公告日为推定」标注属 P53 的收尾；
  绩效对比（P48）、自评估/熔断（P49）、归因与配置视图（P50）不在本站范围。
- 载体口径的**唯一真源仍在代码里**：`stocklab/m2/config.py`（命名/频率/表名/状态码）——
  本 ADR 只记「为什么」，不复制常量值。
