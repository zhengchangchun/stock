# ADR-010 模拟盘口径：不做方向择时、三臂并列、只增不改

日期：2026-09-16 ｜ 状态：已采纳 ｜ 前置：ADR-006（实盘账本口径）、ADR-008（ETF 复权口径）、
ADR-009（raw_cache 当日时效）、`docs/portfolio/2026-09-15-combinations.md`（方向能力实测）
代码：`stocklab/paper/{config,rules,store,engine}.py`、CLI `paper init|step|show`
产物：`reports/paper/YYYY-MM-DD-paper.md`（+ `.json`）、三张 append-only 表

> **编号说明**：`docs/plans/2026-09-15-p19-模拟盘骨架.md` §2.1 已把本文件预留给 ADR-010；
> 当前最大号为 009（raw_cache 当日时效），按「编号顺延、不回收」取 **ADR-010**。

## 1. 背景

模拟盘要回答一个**实盘无法快速回答**的问题：在**扣完成本**、**只用当日之前的信息**的前提下，
几种「不许择时」的持有方式，长期下来各自值多少钱。它不是选股器，也不是收益承诺。

之所以把「不许择时」写成**硬口径**而不是「建议」，是因为模型的方向能力已经被实测证伪：

| 指标 | 实测值 | 出处 |
|---|---|---|
| 行级方向准确率 | 38.14% | `docs/tasks/2026-09-15-p7-验证器-task32-36.md` |
| 按日聚类方向准确率 | **0.3819 ± 0.0070**（[0.3683, 0.3956]，n_days=3096） | 同上 |
| Brier（越低越好） | 0.6581（随机基准 0.667） | 同上 |

按日聚类区间**整个落在 0.5 以下**，且 Brier 只比「抛硬币 + 常数概率」好 0.009 ——
**方向能力 ≈ 0**（不是「不够好」，是「没有」）。既然信号不存在，任何以方向判断为依据的
买卖都会把成本与噪声换成负收益。所以模拟盘从一开始就**不接模型输出**。

## 2. 决策

### D1 禁止方向择时

- 不使用模型预测作为买卖信号，不做参数搜索，不输出买卖建议。
- 不「押单票」：任何一根 K 线形态都不作为加减仓依据。
- 这条不是「暂缓实现」，而是**结论性口径** —— 要推翻它，必须先拿出**样本外**、
  **按日聚类**、CI 整个离开 0.5 的新证据（<120 交易日不算，见 D6）。

### D2 三条臂并列，不挑「推荐」

| 账户 | 口径 | 交易 |
|---|---|---|
| `arm-hold` | 起跑状态**冻住不动** | 全程 0 笔 |
| `arm-now` | **实盘账本镜像**：用户每录一笔真成交，它跟着变 | 跟随 `real_trades` |
| `arm-discipline-05/10/15` | 纪律臂，按 **ETF 目标占比 5% / 10% / 15%** 三档展开 | 只按纪律条文调 ETF 腿 |

- `arm-hold` 与 `arm-now` 起跑日**数值必然相同**（描述同一份状态），区别在**之后**：
  前者证明「什么都不做」的机会成本，后者证明「你自己的操作」值多少钱。
- 纪律臂**三档并列、全部保留**：不得只报最好的那一档、不得从三档里挑一个说成
  「推荐配置」。三档是**敏感性分析**，不是三个候选方案 —— 挑一档报＝用事后结果
  选参数，正是本项目的红线第一条。
- 纪律条文**不另抄一份**，直接复用 `portfolio/discipline.py`（唯一真源）。

### D3 成本口径（引用 ADR-008，不自由发挥）

- 每笔**佣金最低 5 元**（小额交易的实际费率远高于比例佣金，模拟盘必须吃下这个非线性）；
- **ETF 免征印花税**、股票按现行税率；过户费与**滑点**（买 ×1.0005 / 卖 ×0.9995）照计；
- 成本**分列存储**（`commission` / `stamp_tax` / `transfer_fee` / `slippage_cost`），
  存一个合计就再也查不出「ETF 那笔印花税到底是不是 0」；
- ETF 复权口径按 **ADR-008**；
- 净入金 `net_deposits` 与收益分开记，禁止用「净值涨幅」冒充「赚了多少钱」。

### D4 PIT：当日决策只用 ≤ 当日的收盘价

- 决策价一律取自 `bars_daily`（`adj_mode='none'`）中 `date <= asof` 的最近收盘，
  `price_asof` **如实指回那一天**（停牌时是上一交易日，不假装是当天）。
- 任何 `price_asof > asof` → 抛 `LookaheadError`（无 fallback、无静默降级）。
- 幂等：`paper step` 同日重跑不重复下单，stdout 与报告**逐字节一致**。

### D5 append-only 三表，不加滚动清理

`paper_accounts` / `paper_trades` / `paper_nav_daily` **只增不改不删**（触发器 `RAISE(ABORT)`）。

- **不加滚动清理**：净值曲线就是证据链，删掉中间任何一天，回撤与超额都无法复算。
  体积不是问题（5 账户 × 250 交易日/年 ≈ 1250 行/年）。
- 写错只能**冲正**（再写一条反向记录），不能 UPDATE —— 与 ADR-006 同纪律。

### D6 起点、LIVE 与样本量门槛

- 起跑日 **2026-09-15**（初始资金 20,000 元），早于起跑日 `paper step` 直接报错。
- **LIVE = 0**：报告里的 `LIVE（实盘累计）` 在起跑日必然是 0 行；
  回放/样本内的数字**不得**说成实盘表现。
- **<120 交易日不算结论**：起跑日起的任何数字都只标注「样本不足，仅供观察」——
  不得用于选臂、不得写进优化理由、不得与 `index_300` 的超额一起当成绩汇报。
- 基准：同时给 `index_300`（不可直接交易，故**不含成本**，对策略偏乐观）与
  `arm-hold`（可执行对照）两个判定；**跑不赢躺平就明说**。

### D7 `paper show` 的默认 asof 必须回落，且不许静默

不带 `--asof` 时：今天已有净值 → 用今天（`asof_source=today`）；
今天还没有净值行 → 回落到最新有净值的日期（`asof_source=latest_nav`），
并在 `disclosure` 里写明「今日净值未生成，展示 YYYY-MM-DD」。
显式给了 `--asof` 则**照用**（`asof_source=explicit`），空就是空。
理由：默认路径返回 `accounts: []` 会被读成「模拟盘不存在」，是**误导性空值**；
而「今天还没算」与「没建过」是两件不同的事。

## 3. 已知限制（如实记录，不修饰）

### L1 整手约束下，000333 一手就吃掉总资产的 ≈43.5%

真实库 2026-09-15 实测：`000333` 占总资产 **43.53%–43.56%**（5 个账户），
而纪律臂的单票上限是 **≤40%**。引擎**如实标 `[FAIL]`**：
`000333 占总资产 43.53%，**超** 40% 上限 3.53 个百分点`。

**关键推论（这条必须写在纸面上，否则会被误读成「系统建议清仓」）：**

- A 股**整手（100 股）**约束下，持有 100 股 000333 时，纪律臂**只有两个可行动作**：
  **全清**（0 股，占比 0%）或**不动**（100 股，占比 ≈43.5%）——
  不存在「减到 40%」这个选项（那需要 7 股）。
- 于是 `[FAIL]` 是**数据**，不是**建议**。它如实报告「当前持仓与 40% 上限不相容」，
  不构成任何买卖指令，也**不**意味着引擎在推荐清仓。
- 这条限制同时说明：**40% 上限在 2 万元本金 + 86.8 元股价下是失效的约束**
  （一手最小可交易单位就已越线）。要让它有效，只能提高本金或换更低单价的标的 ——
  属于用户资金决策，不在本项目范围内。
- 已知的机制后果：纪律臂在 000333 上大概率**长期停在 FAIL 且不动**（因为「不动」是
  合法解），这会**低估**纪律臂的换手与成本，对照时应把这一点计入解读。

### L2 起跑日数字全部是**样本内**，不是准确率结论

`reports/paper/2026-09-15-paper.md` 里的净值/超额是**第 0 天**的值
（臂与臂之间只差几十元成本），**不构成**任何策略优劣证据。

### L3 指数对照不含成本

`index_300` 不可直接交易，故未扣费 —— 与三臂比较时对策略**偏乐观**，
即便如此跑输也要如实上报（D6）。

## 4. 后果

**正面**：模拟盘的每个数字都可复算（幂等 + append-only + PIT）；
「不许择时」被写成硬口径而不是口号，任何越界都会在代码里报错而不是在报告里解释。

**代价**：短期（<120 交易日）看不到任何结论，报告会一直挂着「样本不足」；
三档纪律臂并列会让报告变长且没有「推荐」可挑。

**明确不做**：不接模型信号、不做参数搜索、不加滚动清理、不在项目内建 cron
（调度见 §5）。

## 5. 接入说明（nanobot 侧，本项目内**不建 cron、不改任何定时器**）

把 `paper step` 加为 **15:30 收盘链的新一步**（排在 `review daily` 之后）：

```bash
cd /root/.nanobot/workspace/projects/stock-lab
.venv/bin/python -m stocklab.cli.main paper step --asof <最新交易日>
# 报告落 reports/paper/<asof>-paper.md（+ .json）；退出码 0=完成（含幂等命中）/ 2=用法或库的问题
```

**前置条件（按顺序，缺一不可）：**

1. **当日 bars 已入库** —— `--asof` 只用 `bars_daily`（`adj_mode='none'`）里
   `date <= asof` 的收盘价。所以 `paper step` 必须排在 **`ingest bars`（15:30 链的第 1 步）
   之后**；若当日 bar 未落库，引擎取不到价会**报错退出 2 并且一行净值都不写**
   （不落半截状态，这是有意的）。
   ⚠️ 参考 ADR-009：15:30 抓日K 可能命中当天盘中冻结的缓存 → 当日 bar 缺失 → 本步会失败。
2. `--asof` 取**最新交易日**（不是「今天」）：非交易日跑会把净值记到一个不存在的交易日上。
   取日历用 `stocklab calendar`（`trading_calendar`），别用自然日。
3. 表已前滚：全新库先跑 `stocklab db init`；建臂只跑一次 `paper init`（幂等）。
4. **补跑安全**：`step` 幂等（同日重跑不重复下单、报告逐字节一致），落库前先补
   `ingest bars` 即可；`paper show` 是只读的，不带 `--asof` 会回落到最新净值日（D7）。

**建议的 15:30 链顺序**：`ingest bars` → `session tick`(15:05 那步) → `review daily` →
**`paper step --asof <最新交易日>`**。本表同时写在 `docs/scheduling.md`（§1 时点表）。
