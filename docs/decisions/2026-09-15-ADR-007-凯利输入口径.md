# ADR-007 · 凯利输入口径（p / b 只能来自 PIT 回放）

- **日期**：2026-09-15
- **状态**：已采纳（P15 补记；机制在 P14 已实现，本 ADR 是**事后定稿**）
- **相关**：`stocklab/risk/kelly.py`、`stocklab/risk/rules.py`、`stocklab/risk/panel.py`、
  `docs/plans/2026-09-15-p14-风险与仓位工具箱.md`、ADR-006

## 背景

凯利公式 `f* = p − (1−p)/b` 看起来像「告诉你该买多少」的答案，实际它的输出
**完全由输入决定**。而 `p`（胜率）恰恰是本项目测不出来的那部分：
P7 实测 `pit-rw-v1.0.1` 行级方向准确率 38.14%（Brier 0.6581）。

于是有一个极强的诱惑：手设一个 `p = 0.55`，就能得到任何想要的仓位。
那不是计算结果，是**输入者的观点伪装成算术**。

本 ADR 把「p/b 从哪来」定死，让这件事在代码里没有第二种可能。

## 决策

### D1 · p / b 的**唯一**合法来源 = 明确规则在 PIT 历史上的回放

`p` / `b` 只能来自 `risk.rules.replay()`：一条**写死的**规则（`trend-state` /
`ma-cross` / `buy-hold`）在 `≤ asof` 的**复权**价上的完整往返统计。

- ❌ 禁止人工指定 p/b；
- ❌ 禁止样本内调参；
- ❌ 禁止为了让输出「有仓位」而换窗口 / 换规则 / 挑子群
  （`invalidated` 子群事件见 ERROR_DIARY #15 —— 那是结果条件子群，不可交易）。

### D2 · 保守化：`p` 取 Wilson 下界，`b` 取四分位保守比

- `p_used = wilson_lower_bound(wins, n)` —— 小样本胜率的下界（不是点估计 `wins/n`）。
- `b_used = Q1(赢幅) / Q3(亏幅)` —— 对**赢**打折、对**亏**加码，
  即分布上的保守端。点估计 `b_point = mean_win/mean_loss` 只作对照输出。

两个输入同时向不利方向取，才能让 `f*` 的**乐观偏差**变成保守偏差。
点估计只用于披露，**不参与** `f_final`。

### D3 · 扣成本

回放用 `config.costs.CostModel`：佣金（含**最低 5 元**）+ 印花税 + 过户费 +
滑点 5bps/边，实算往返 `cost_bps` 并随结论输出。不扣成本的回放统计
等于给策略发一份不存在的收益。

### D4 · 按**日**聚类

`n_days`（交易日数）才是有效样本量，不是成交笔数 `n_trades`。
A 股同涨同跌：同一天的多笔/多标的共享同一段市场波动，按笔重采样会把它们
当独立样本，CI 会窄得离谱。胜率 CI 用 `daily_clustered_winrate_ci`
（重采样的是**天**，2000 次 bootstrap，seed 固定）。

### D5 · 样本门槛 120 个交易日

`n_days < 120` → **不得据此下注**，无论 `f*` 算出来是多少。
文案必须是「还看不清」，不是「edge 很小」—— 两者是不同的结论。

样本不足时该结论只能标注「样本不足，仅供观察」，**不得**用于选策略、
不得写进优化理由（CLAUDE.md 度量纪律第 3 条）。

### D6 · 两道门分开报，`NO_BET` 是合法结论

- `gates.sample`：`n_days ≥ min_days`？
- `gates.edge`：`p_used > p_be`（`p_be = 1/(1+b_used)`）？

合成 `verdict = "BET" if (sample_ok and edge_ok) else "NO_BET"`，
但 `verdict_reason` 必须能追溯是哪道门没过（`sample_insufficient` /
`edge_not_significant`）。

**任一不过 → `f_final = 0.0`**（一个仓位都不给）。
`NO_BET` 是**结论**不是错误，退出码 0，页面必须原样显示。

### D7 · `f_final` 的裁剪链，每一步都留痕

`f_star → f_fractional = k·f*（k=0.25 默认）→ clip 到 2f* → cap 到 f_cap`

- 超过 `2f*` 时期望对数增长转负 → 硬拒绝到 `2f*` 并记 `overbet_rejected`；
- `f_cap` 默认 0.25（上限），命中记 `f_cap_applied`。

### D8 · 连续近似只作对照

`f* ≈ μ/σ²` **不参与** `f_final`：它给的是杠杆倍数而 A 股现货无杠杆，
且它按「每笔」频率、忽略交易在时间上不重叠。当二元口径与连续口径
给出**相反**信号时，必须显式披露（这类分布下 μ 被 `1/σ²` 放大，
凯利对它极其敏感）。

## 后果

- 本项目在真实数据上的正确答案**就是 `NO_BET`**，且这不是「系统坏了」。
  任何让页面看起来「有仓位」的改动都违反本 ADR。
- `p`/`b` 的口径变更 = 结论变更，必须新开 ADR，不许在实现里悄悄调。
