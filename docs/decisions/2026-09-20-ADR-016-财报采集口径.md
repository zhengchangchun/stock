> **编号说明**：任务书指定 016；`docs/decisions/` 现有最大号为 015（写库入口自动前滚 schema），按「编号顺延不回收」取 **ADR-016**。

## 背景

财报是候选池中期池与长期池因子的唯一来源（ROE、毛利率、毛利率变动、存货周转天数、自由现金流率、DuPont 分解）。要定的是**口径**：怎么采、PIT 语义怎么保证、公告日从哪里来、权益用归母还是合计、行业字段的 PIT 限制——而不是「怎么抓」的实现细节。

要解决的核心问题：

1. **公告日来源**：DMSK 三表的 `NOTICE_DATE` 历史行指向**同类报告的下一次公告日**（实测，见下文），用它做 PIT 锚会让中间窗口的财报全部不可见。
2. **权益口径**：DMSK 的 `TOTAL_EQUITY` 是所有者权益合计（含少数股东），不是归母——用它算 ROE 会系统性低估，且 DuPont 恒等式不成立。
3. **行业字段**：东财 DMSK 的 `INDUSTRY_NAME` 是当时提取的字段，无法还原历史行业分类。
4. **报表名按机构类型选**：银行（B）、保险（I）与一般工商业（G）的 F10 报表名不同，填错会导致整批拿不到财报。

## DMSK `NOTICE_DATE` 实测缺陷（促使 D-01 决策）

实测（2026-09-20，`000333.SZ` 全量 79 期）：

| `report_date` | DMSK `NOTICE_DATE` | F10 `NOTICE_DATE` | 差距 |
|---|---|---|---|
| 2025-12-31 | 2026-08-29 | 2026-03-31 | 151 天 |
| 2024-12-31 | 2026-03-31 | 2025-03-29 | 367 天 |

**结论**：DMSK 历史行的 `NOTICE_DATE` 指向的是「同类报告的下一次公告日」，完全不是该期报告的实际公告日。若照它做 PIT 锚，2025 年报在 2026-04-30 至 2026-08-29 之间根本不可见，中期/长期池候选逻辑会静默地算不出来。

## 备选方案

### 1. PIT 锚点的选择

- **方案 A：用 DMSK `NOTICE_DATE` 直接当 PIT 键** —— 实测不成立（见上表），历史大量报告期会变成不可见。
- **方案 B：用 `report_date`（报告期末日）当 PIT 键** —— 相当于「报告期结束就能看到」，完全忽视披露滞后，是典型未来函数。
- **方案 C：F10 的 `NOTICE_DATE` 为第一优先，合理性校验，失败则法定截止日** —— 最接近真实公告日，保守方向安全。

### 2. 公告日来源与法定回退

- **方案 D：仅用 F10，取不到就 NULL** —— 早期历史 F10 可能缺数据；NULL 的 `notice_date` 使该期对任何 `asof` 均不可见，等于永久丢失。
- **方案 E：三级回退：F10 → 合理性校验 → 法定截止日** —— 法定截止日是保守方向（只会让数据「晚一点可用」），不会让尚未公告的财报提前可见。

### 3. 权益口径

- **方案 F：用 `TOTAL_EQUITY`（合计）算 ROE** —— 分母含少数股东权益，分子是归母净利润，ROE 系统性低估，且 `资产 = 负债 + 权益合计` 成立，但 DuPont 的 `equity_multiplier = 资产/归母权益` 就错了。
- **方案 G：用 `parent_equity`（归母）算 ROE，`total_equity` 只用于会计恒等式校验** —— 分子分母口径一致（均为归母），DuPont 成立。

### 4. 行业非 PIT 问题

- **方案 H：把行业字段当 PIT 字段用，回测里按 `asof` 读行业** —— 行业字段无历史快照，「2018 年用 2026 年的行业分类」会引入少量偏差但无法检测。
- **方案 I：显式声明非 PIT，下游披露义务** —— 诚实，不把偏差藏起来。

### 5. 报表类型按机构选

- **方案 J：全部用通用 G 报表** —— 银行/保险的 G 报表要么根本不存在，要么字段不完整，会静默拿不到财报。
- **方案 K：按 `org_type` 分派：通用→G，银行→B，保险→I** —— 实测可拿到各类机构的财报。

## 决策

**全部取后者：1C / 2E / 3G / 4I / 5K。**

### D-01 PIT 锚点：`notice_date`（三级回退结果），不是 `report_date`

`financial_reports.notice_date` 是 PIT 键。下游读取唯一允许的形式：

```sql
SELECT * FROM financial_reports
WHERE code = :code AND notice_date <= :asof
ORDER BY report_date
```

`asof` 之后 `notice_date` 的行**不可见**（对回测/预测完全不可见）。

**为什么主键含 `notice_date`**：财报可被更正/重述，同一报告期可有多个版本（公告日不同），主键 `(code, report_date, notice_date)` 保留每个版本，读侧取 `notice_date <= asof` 中最晚的那个即得最新已公告版本。

### D-02 公告日三级回退（`stocklab/data/notice_date.py`）

优先级顺序：

1. **F10 的 `NOTICE_DATE`**（`RPT_F10_FINANCE_{G/B/I}BALANCE` 等报表的 `NOTICE_DATE` 字段）——实测与真实公告日吻合
2. **合理性校验**：`0 < (notice_date − report_date).days ≤ 120`，不过则进入第 3 级
3. **法定披露截止日**（`source='statutory'`）：依据《证券法》与交易所定期报告规则
   - 年报：次年 4-30
   - 一季报：4-30
   - 中报：8-31
   - 三季报：10-31

**第 3 级是保守方向**：只会让数据「晚一点可用」，绝不会让尚未公告的财报提前可见。最大滞后约一个月（相对真实公告日），在策略层面可接受。

`notice_date_source` 字段区分：`'f10'`（取自 F10，可信）/ `'statutory'`（法定截止日，保守估计）。

实测（17 只个股，1443 行，来源：`SELECT notice_date_source, COUNT(*) FROM financial_reports GROUP BY 1` on `/tmp/fin-acceptance.db`）：

### D-03 权益口径：归母（`parent_equity`）

**ROE 与 DuPont 一律用 `parent_equity`（归母股东权益）**：

- 分子 `parent_netprofit`（归母净利润）/ 分母 `parent_equity`（归母权益）口径一致
- `equity_multiplier = total_assets / parent_equity` 成立（可解释）
- `total_equity`（含少数股东）只用于**会计恒等式勾稽**校验：`|total_assets − total_liabilities − total_equity| / total_assets < 1e-6`

**注意**：DMSK 的 `TOTAL_EQUITY` 字段注释已标明「所有者权益合计（含少数股东权益）」，落库时字段名为 `total_equity`，与 `parent_equity` 明确区分。

### D-04 行业非 PIT（**必须显式披露**）

`financial_reports.industry_name` 来自东财 DMSK 每次采集时的当前值，**无历史快照**。它不是 PIT 字段。

**风险**：若某标的在历史期间发生行业重分类，当前采集到的行业名不一定是那一期的行业。这是「非 PIT 里最接近 PIT 的选择」，不是「已经 PIT 了」。

**对策**：
1. `industry_name` 字段**不进横截面分位排序**（当前实现是按「所有可见行的行业分布」排，不做行业内排名）
2. 行业排雷（插桩0）用 `instruments.sector`（从行情端采集），两者来源不同
3. 任何引用 `industry_name` 做 PIT 分析的报告**必须**写明「行业字段非 PIT，历史分类可能失真」

### D-05 报表名按机构类型分派

| `org_type` | F10 报表名前缀 | DMSK 报表 |
|---|---|---|
| `通用`（一般工商业） | `RPT_F10_FINANCE_G*` | `RPT_DMSK_FN_*`（3 张） |
| `银行` | `RPT_F10_FINANCE_B*` | `RPT_DMSK_FN_*`（同上） |
| `保险` | `RPT_F10_FINANCE_I*` | `RPT_DMSK_FN_*`（同上） |

DMSK 三表对银行/保险与通用机构使用**相同报表名**，差异只在 F10。`org_type` 填错不会导致 DMSK 失败，但会导致 F10 公告日拿不到（退化到法定截止日）。

实测：招商银行（600036，银行）、中国平安（601318，保险）均可正常取到 102/84 期财报。

### D-06 累计 → 单季 → TTM 的计算口径

财报是**累计值**（每季报都是从 1 月 1 日到报告期末的累加）。因子计算路径：

```
累计值 → 单季(Qn) = 本累计 − 上一累计（同一会计年度内）
      → TTM = 最近 4 个单季之和
```

等价展开（以最新期为 H1 YYYY 为例）：

```
TTM = H1(YYYY) + FY(YYYY-1) - H1(YYYY-1)
```

手工对照（000333 美的集团，asof=2026-09-18，最新期=2026Q2）：
- 2026H1 parent_netprofit = 26,446,037,000
- 2025FY parent_netprofit = 43,945,411,000
- 2025H1 parent_netprofit = 26,013,690,000
- TTM（手工）= 44,377,758,000

系统输出 `roe = 0.20352925...`，对应 TTM netprofit / avg(equity_2026Q2, equity_2025Q4) = 44,377,758,000 / ((212,861,055,000 + 223,221,305,000) / 2) = 0.20353（与系统一致）。

### D-07 行业 NA 分布（金融股结构性缺字段）

| 因子 | 缺失标的 | 原因 |
|---|---|---|
| `gross_margin` | 600036（招商银行）、601318（中国平安）、601398（工商银行） | 银行/保险报表无「营业成本」（`operate_cost`）字段，因此无法算毛利率 |
| `gm_yoy_pp` | 同上 | 依赖 `gross_margin`，源不可算则下游也不可算 |
| `inv_days` | 同上 | 银行/保险报表无「存货」（`inventory`）字段 |

`roe`、`fcf_margin`、`dupont` 对银行/保险可算（有归母净利润、净经营现金流、归母权益）。

`gross_margin` / `inv_days` 缺失**不是采集失败**，是报表结构的固有差异。代码以 `None` 返回，不填 0，下游横截面分位排序时这些标的的对应因子列不参与排序。

### D-08 append-only + 首写保留

与 ADR-011 同款语义：`INSERT OR IGNORE`（幂等），`(code, report_date, notice_date)` 三元组已存在则跳过，不覆盖，计入 `conflicts`。行一旦写入**永不改写**（触发器 `trg_financial_reports_no_update/delete`）。

### D-09 溯源

每行带 `source`（`eastmoney-datacenter`）、`fetched_at`（UTC 时刻）、`raw_refs_json`（DMSK 三表 + F10 三变体的来源 URL / 响应摘要数组）。**能复现、能对拍、能查账。**

### D-10 ETF / 无财报标的的处置

`ingest financials` 遇到 ETF（`org_type` 默认通用但 `asset_type='etf'`）时直接返回 0 期，不报错，不写 `system_events`（合法空，与 ADR-011 D-05 中 ETF 无估值数据同款语义）。

### D-11 采完不直接上策略（与 ADR-011 D-08 保持一致）

本轮只建**采集与因子计算路径**。六个因子（ROE、毛利率、毛利率变动、存货周转、FCF 率、DuPont）目前仅用于横截面分位排序，排序结果在报告中**标注「样本内、未经验证」**。

要走策略必须先过 walk-forward 评测（按日聚类 + 扣成本 + 基准对照 + ≥120 交易日样本），且须先问用户测不测。**数据存在 ≠ 数据可用 ≠ 有 edge。**

## 后果

**好处**

- DMSK `NOTICE_DATE` 缺陷被 F10 + 三级回退封死，历史窗口的财报不再静默消失
- 归母口径一致（ROE 分子/分母均归母），DuPont 恒等式成立
- 行业非 PIT 风险显式披露，不把偏差藏起来
- 银行/保险因缺字段而 NA 的因子不填假值，下游有明确的处理规则

**代价 / 已知限制（显式记账，不掩盖）**

1. **行业字段非 PIT**：`industry_name` 可能与历史行业实际不符，无法自动检测重分类
2. **法定截止日回退**：`statutory` 来源的 175 行公告日可能比实际晚约一个月；对 PIT 保守安全，但会导致财报在那段时间「看不到」
3. **DMSK `TOTAL_EQUITY` 口径探针**：会计恒等式 `|资产 − 负债 − 权益合计| / 资产` 对少数金融股偶有微偏（实测 1e-3 量级），疑因合并层次差异，记为 warn 不拒写
4. **行情深度**：`ingest financials` 只覆盖 SEED_UNIVERSE（21 只），中期/长期池横截面排序的「横截面」就是这 21 只，不是全市场，因此分位结果不代表全市场水平
5. **样本内因子**：当前六个因子的有效性结论需 ≥120 交易日 walk-forward 样本，本轮所有输出均标注「样本内、未经验证」
