# ADR-030 信号有效性度量的口径（rank IC ＋ 分层，只读基建）

- 日期：2026-09-26
- 状态：已接受
- 上游：`docs/tasks/2026-09-26-p78-信号有效性度量闭环.md`（D1–D10）、
  `docs/experiments/2026-09-25-xsec-topn-csi300-500.md` §5、ADR-008、ADR-017、ADR-029

## 背景

`research xsec-topn` 只能回答「**持有集合换一个定义**，组合收益差多少」。2026-09-25 的
扩池实验（`csi300-500`，800 只）Δ = **+0.3132%/期**、95% CI `[−0.4887%, +1.1584%]`
**跨 0** ⇒ 「无可测的选股增量」，该报告 §5 自己写下了下一步：

> 瓶颈不在 N，也不在宇宙大小，而在**选股信号本身** …… 下一步不是调 N / 调宇宙，而是
> **先能量化「打分变量对前向收益的横截面排序能力」（IC / 分层回测）**，再据证据改打分函数。

`xsec-topn` 与「选股准不准」**不同构**，三个结构性理由：

1. 它比较两个**组合**的收益序列 ⇒ 只对「取前 N 相对持全部」有分辨率，而短池 topn 只有
   6 只、`|topn|/|all|` ≈ 1/60 ⇒ 区分度**结构性地小**（该报告 §3 自认的固有上限）；
2. 它**看不到**分数的中间段：第 7 名与第 300 名对 Δ 毫无贡献，对「这个分数有没有信息」
   贡献巨大；
3. 它一次只出**一个数**（Δ），无法回答「打分函数里哪一项有用」。

⇒ 在没有任何「信号有效性」读数之前改打分函数，就是**盲改**（改完只能再跑一次 ≈96 分钟
的组合级实验、而且大概率还是 CI 跨 0）。本 ADR 记录这把**尺子**的口径。

## 备选方案

1. **继续用组合级 Δ 迭代打分函数** —— 优点：零新增代码；缺点：分辨率结构性低（理由 1–3），
   且无法归因到打分的哪一项。**否**。
2. **引入 numpy/scipy 算 IC/分层** —— 优点：省事；缺点：本项目**零 ML 依赖**（既有口径见
   `docs/architecture/`），为一把尺子拉进一整套数值栈不划算；IC 与分层都是初等统计，
   stdlib 足够。**否**。
3. **只读基建：逐调仓日 rank IC ＋ 分 5 层**（选中）—— 用既有 `score_pipeline` 的现算分数，
   不改任何阈值/公式/参数，新增一条只读命令。
4. **在 `signal.py` 里自己重写一遍打分循环**（拿到「全部已打分标的」）—— **否**：那会形成
   第二套打分口径，与通路 A 的 A1 归因冲突；改为给 `PipelineResult` **只增**一个字段暴露
   内部已构造好的 `scored`（只增、不改既有字段，见 D2）。

## 决策

### D1 度量对象

跑 `pool="short"`，主读数 = **`adj_score`**（`select_top` 实际排序用的那个，`risk_adjust`
之后的最终分），次读数 = **`raw_score`**（插桩1 的原始输出）**并列报出**。只跑 `short`：
`mid` 需 32.6 年、`long` 需 97.9 年才够 `MIN_VALID_PERIODS=120` 个验证周期（纯算术，
同 `xsec.ONLY_POOL`），其余池 exit 2。

### D2 交叉截面来源（`PipelineResult.scored`）

每个调仓日跑一次 `score_pipeline(conn, asof=<mark>, universe=<members>)`，取该池
**全部已打分的合格标的**（不是只有 top-N）。为拿到这条信息，给
`candidate/run.py::PipelineResult` **只增**字段 `scored: dict[str, list[dict]]`
（`field(default_factory=dict)`，位置在 `eligible` 之后），内容就是 `score_pipeline`
内部**已经构造好的**那个列表。`score_pipeline` 的打分口径/顺序/公式**一字未动**；
`members` / `rejects` / `params` / `eligible` 的取值与顺序**逐位不变**
（`eligible` 仍由 `scored` 派生）—— 自证方法与结果见任务书 §7（`git stash push --
stocklab/candidate/run.py` 前后 digest 相同）。**不许**在 `signal.py` 里重写打分循环。

### D3 前向收益口径 = PIT 复权价

`fwd(c; d0, d1) = adj_close(c, d1) / adj_close(c, d0) − 1`，复权序列由
`data/adjust.py::load_bars_adjusted(conn, code, as_of=FWD_ASOF)` 提供，`d0`/`d1` 是
`rebalance_marks` 输出的**相邻**调仓日。`FWD_ASOF = marks[-1]`（最后一个**调仓日**，
不是 `end` —— `end` 可能不是交易日）。前向收益**一次/只**载入并缓存（不是一次/(只·日)，
那会把耗时乘上周期数）。**不自己实现复权、不改 `adjust.py`**。

**为什么一个 `as_of` 能覆盖全部周期**：比值 `adj(d1)/adj(d0)` 只取决于 `(d0, d1]` 区间内的
除权事件 —— `d1` 之后的事件因子在分子分母上同时出现、**相消**；且 `d0/d1 ≤ as_of`
⇒ **无未来数据**。

> ⚠️ **实施记录的一处细化（P78 §7.4，照实记）**：这条「相消」是**数学上**成立，
> **IEEE-754 比特级不保证相同**。只读探针（真库、15 个 `(code, 周期)` 样本）实测：
> 5/15 样本末位不等，最大相对差 **2.6e-14**（≈128 ULP，就是「因子乘积的乘法次序不同」
> 累积的舍入）。决定性检查：其中 3 个周期的**横截面名次序完全一致** ⇒ Spearman 的输入
> 秩序不变 ⇒ **IC 逐位相同、结论不可能因此改变**。本站**不**把「逐位相同」写成已验证的
> 比特级事实；只写「数学等价 ＋ 名次序实测一致」。

### D4 复权不可用的处置：fail-open ＋ 可见

- 复权层拒绝服务（`EtfChainUnsupported` / `MissingFactor` / `StaleFactorTable`，
  与 `run.py::_ADJ_UNAVAILABLE` **同一集合**）⇒ 该只回退**未复权价**算前向收益
  （因子恒 1 ⇒ 数值等价），计入 `n_fwd_fallback`；
- 该只**复权链为空**（无 `corp_actions`）⇒ 同样等价回退、同样计数；
- `d0` 或 `d1` 任一取不到价 ⇒ 该 `(日期, code)` 从该日截面剔除，计入 `n_no_fwd_ret`；
- 裸 `AdjustError`（`k>1` / `pre_close<=0`，属**代码/数据缺陷**）**不在此列，原样抛**
  —— 数据脏与代码坏要分档（ERROR_DIARY #81）。

fail-open 的理由与 P77 D3 同：这是**度量路径**不是下单路径，一只标的的因子不可用不该让
整轮死掉；但**必须可见**（报告计数）。**不许**把回退当静默。

### D5 IC 定义

主 = **Spearman 秩相关**（并列取平均名次，与 `candidate/cross_section.py::_pct_of` 那套
排名法**同值**——复制该算法、不 import 私有函数），次 = Pearson（并列报出）。**只用 stdlib**
（`statistics` / `math` / `random`），⛔ **不许 import numpy / scipy / pandas**。
某日截面同时有分数与有效前向收益的标的数 `< MIN_XSEC_N = 30` ⇒ 该日 IC 记为 `None`、
计入 `n_dates_skipped` —— **不许**用 0 顶替（那是把「不知道」伪装成「没相关」）。
同一个门槛对 IC / 分层 / spread **一视同仁**（否则「n=5 的一天」进得了层均值却进不了
IC 序列，两个读数对「哪些天算数」各说各话）。`MIN_XSEC_N = 30` 是**自创取值**：
分 5 层后每层 n≈6，再小则层均值是少数几只的噪声。

### D6 分层

`n_layers = 5`（预注册字段，改要新预注册）。按分数**降序**、等量分桶（rank-based；并列按
`code` 升序定序 ⇒ 确定性），**第 1 层 = 最高分**。非整除时靠前的层更宽
（`numpy.array_split` 同形，但不引入 numpy）。报每层平均前向收益（**先按日算层均值、
再对日平均**）＋ `spread = layer1 − layer5` 的日序列（均值 ＋ bootstrap CI）。
单调性另报 `n_ascending_steps`（相邻层「上一层均值 > 下一层」的个数，满值 4）与其按日平均。

### D7 判据：预注册 ＋ fail-closed，**复用**既有门槛

- 验证段有效日期数 `< sandbox.MIN_VALID_PERIODS`（=120）⇒ verdict = **`INCONCLUSIVE`**
  （「测不出」，不是「没效果」）；
- 否则：验证段 IC 序列的 `sandbox._BOOTSTRAP_N` 次按日期重采样 95% CI **不含 0** ⇒
  **`IC_SIGNIFICANT`**；含 0 ⇒ **`IC_NOT_SIGNIFICANT`**。

**verdict 词汇为什么换**：`WIN` / `LOSE` 是**组合收益**的词，会读成「策略赢了/输了」；
本度量的结论是「IC 的 CI 含不含 0」，**IC 为负也叫 significant**（负 IC 意味着把分数
反过来用可能有信息）。因此另立度量专用词。**这不是第二套阈值**：门槛数字
（`MIN_VALID_PERIODS` / `_BOOTSTRAP_N` / `_BOOTSTRAP_SEED` / `_bootstrap_ci` /
`overfit_flag`）与训练/验证切分（`replay.split_train_validate`，周期序号 70/30）
**全部 import 复用，一个数字都没手抄**——由 `tests/test_research_signal.py`
的源码守卫（`"MIN_VALID_PERIODS = 120" not in src` 等）钉住。

### D8 窗口与宇宙

`--start` **必填**且 `≥ 2015-01-01`（`MIN_START`，窗口即结论）。`--universe <id>`
（默认 `None` ⇒ `seed21` 主干常量），走 `config/universes.py::resolve_universe`
（**fail-closed**，文件缺失即抛，不回退）。**换宇宙必须新预注册**（与 `xsec` 同语义：
预注册缺 `universe` 字段 ⇒ 语义 = `seed21`，命令行不一致即 exit 2、零输出）。
首次全窗跑 = `--universe csi300-500`、窗 `2015-01-01 → 2026-09-24`（与 09-25 扩池实验
同窗，便于并列读），**全窗由 nanobot 事后后台跑**（≈100 min，见 §后果）。

### D9 只读与产物

连库一律走 `stocklab/cli/research.py::open_read_only`（`file:…?mode=ro`，不调
`ensure_schema`、不开 WAL），**不写任何表**、不进 `ops close`、不进红线基线。
产物落 `reports/research/`，文件名**必须带宇宙 id**：
`<end>-rank-ic-<universe_id>.{json,md}`（P77 T7 的教训：不带 id 会静默覆盖历史产物）。

## 已知遗留（**本站不修**，只记录）

`candidate/replay.py::period_returns` 算组合收益用的是 `_close_on` ⇒ 直读
`bars_daily.close`，而 `bars_daily` 全表 `adj_mode='none'` ⇒ **未复权价**（P77 §0.3 列
「所有其它价格路径都走 `load_bars_adjusted`」时**漏了 `replay.py` 这一条**）。除权日的
缺口会被算成组合亏损。

- **本站不改它**：改 `replay.py` 就动了 `xsec-topn` 的臂定义、也动了 `plugin/sandbox.py`
  经注入调用的那条回放路径 = **第二个变量**，会与 P77 的口径切换混在一起。
- **后果（必须写进报告正文）**：本度量与前向收益走 **PIT 复权价**（D3）⇒
  **本报告的 IC 绝对水平与 `xsec-topn` 的组合收益绝对水平不同源、不可直接比**。
- **后续**：另立任务书评估（先在库副本上量化影响，不改口径）。

## 后果

- **好处**：从此「改打分函数」有尺子 —— 先看 IC / 分层，再决定改哪一项；`xsec-topn`
  的 Δ 仍是组合级读数，两者的**用途**分开（IC 判「有没有信息」，Δ 判「取前 N 值不值」）。
- **代价**：零 ML 依赖 ⇒ 自写 Spearman/Pearson/分层（已用「与 `_pct_of` 排名法同值」
  的用例钉住）；全窗 ≈100 min 由 nanobot 后台跑。
- **失败的结论也合法**：CI 跨 0 就写「无可测的横截面排序能力」，不降门槛、不换窗口、
  不换宇宙（`CLAUDE.md` 度量纪律 6）。
- **D4 的回退计数**是可见性读数，不是缺陷数：真库 `n_fwd_fallback` 高只说明复权链覆盖
  不足（与 ADR-029 的 `n_adj_fallback` 同源现象）。
- **`MIN_XSEC_N = 30`** 是自创取值（同 ADR-017 的 `OVERFIT_TRAIN_GAP` 一类）：理由写在
  D5，改它要新预注册。
- **后续可选**：`horizon` 字段目前恒等于 `REBALANCE_DAYS[pool]`；若将来要试「多周期
  前向收益」（如 5/10/20 日），那是**新实验**（新预注册），不是改本站。
