# 设计决策记录（ADR）

命名：`NNNN-<kebab-title>.md`，例如 `0001-use-postgres.md`

## 模板

```markdown
# NNNN. [决策标题]

- 日期：YYYY-MM-DD
- 状态：提议 / 已接受 / 已废弃

## 背景
面临什么问题？

## 备选方案
1. 方案 A — 优点 / 缺点
2. 方案 B — 优点 / 缺点

## 决策
选了哪个，为什么。

## 后果
带来的好处、代价、后续需要注意的地方。
```
