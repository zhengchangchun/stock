## 1. 假设

> 资金流与估值这两类**外部状态**对次日方向有信息量，能改善方向先验：
>
> - **V1（资金流）**：`asof` 当日**主力净额**（`money_flow_daily.main_net`）的符号，
>   对次日个股方向的信息量高于个股自身 60 日对数收益均值（噪声主导）。
>   令 `mu = |mu_sample| · sign(main_net)`，应当让样本外**方向准确率上升**、
>   **Brier 下降**。
> - **V2（估值）**：`PE_TTM` 在**过去 756 个交易日**中的分位 `q` 具备均值回归含义
>   （低分位 → 正漂移）：`q ≤ 0.30 → +1`、`q ≥ 0.70 → −1`、其余 `0`。
>   令 `mu = |mu_sample| · s(q)`，同上判据。

**PIT 约束（提前写死）**：

- 变体**只允许**读 `date <= asof` 的 `valuation_daily` / `money_flow_daily` 行。
  估值分位的窗口 = `asof` 之前（含）最近 756 行，**不含未来行**。
- `asof` 当日缺该行（采集缺口 / 上市前）→ 返回 `None` → `DegenerateInput` **硬拒绝**，
  该 `(日, 标的)` 记入 `skipped` 并在报告里**显式列出「实际用变体的天数」**。
  **绝不许**退化成「取最近一根」或静默回落到基线 —— 退化会让报告显示
  「变体跑了 N 天」而实际只有 M 天用了变体（`index-mom-dir` 的同类坑）。
- 资金流/估值的**当日值只在收盘后可得** → 只能用于预测 `T+1`，不得用于预测 `T` 当日。

**失效条件（判据，提前写死）**：

| 判据 | 阈值 | 结论 |
|---|---|---|
| 方向 | validate 段配对日差 `Δdirection` 的 95% CI **下界 > 0** | 两条同时满足才记 `WIN` |
| 校准 | validate 段 `Δbrier` 的 95% CI **上界 < 0** | 同上 |
| 符号错 | 方向 Δ < 0（CI 上界 < 0） | `LOSE` |
| 符号对但不显著 | CI 跨 0 | `FLAT` |
| 样本量 | 有效交易日 < 120 | `INSUFFICIENT`（结论作废，**不许**据此改策略） |

- `WIN` → 允许打开封存段 `test` **一次**复核；不达 `WIN` → **test 不打开**。
- **V1 与 V2 各自独立判定**，不许合并、不许挑一个好看的说成结论；
  预算不够导致某个变体没跑完 → 记「未跑」，**不许**放宽判据。

**预期方向（也提前写死）**：A 股「主力净额」类指标在公开数据上长期被质疑为
**当日价量的同义反复**（大单净额≈当日涨跌的镜像），且指数动量当方向先验已被否证
（`index-mom-dir`）→ **预期两条都是 `LOSE`/`FLAT`**。若结果真是 `FLAT`，
正确结论是「资金流/估值分位无次日方向信息」，**不是**换窗口、换阈值、换分位数再试。
**这一条是本次实验最可能失败的地方**，写在这里以免事后找补。

**已知局限（提前写死）**：

- 本评测的标的池只有 2 只股票（`{000333, 600690}`）→ 按日聚类后**有效自由度极低**，
  即使 `WIN` 也不等于可交易；`WIN` 的含义仅为「方向先验轴值得再研究」。
- 资金流/估值为**一次性回填**（`source`/`fetched_at`/`resp_sha256` 有留痕，但无逐版本追踪）：
  若源站事后改历史值，本结论基于的是**当时那一刻的快照**，不可追溯只能重采。
- ETF 的 `money_flow_daily` 只有 43 行（< 120）→ 排除，不参与本次任何结论。

**结论（append-only，不改上文）**

1. **两个变体各自独立判定，均 `LOSE`（=falsified）→ test 封存段一次都没打开**，符合预注册纪律。
2. 撤规则生效：`mf_sign` / `val_pe_pct` 两个 `mu_mode` **不采纳**，不得进入预测报告的任何默认路径；
   默认仍是 `mu_mode='sample_mean'`，`MODEL_VERSION` 未变。
3. 方向轴再添两条否证记录（累计：μ 漂移置零 / 指数动量 / σ 状态缩放×3 / 区间残差分位 / 趋势状态当方向信号 / 资金流符号 / PE 分位）。

4. 预注册里写下的「若结果 FLAT/LOSE，换窗口/换阈值没有意义」—— **照此执行，不重启同类实验**。
