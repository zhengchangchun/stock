## 3. 已知注意事项（读这份结论的人必须知道）

1. **「WIN」是框架词，含义只有一个**：判据 (b) 在 validate 与 test **两段都成立**。
   **它绝不等于「方向预测能力提升」**——判据 (a) 两段都是否证的。
   引用时请写「判据 (b) 成立」，不要写「模型赢了」。
2. **延续率不是常数、按段漂移很大**：UP 延续率 validate **53.6%** → test **70.4%**；
   预注册 §4.1 的全样本探索读数是 **71.9%**。这三个数指的是不同区间，**不许混用**；
   配额里写「72% 延续率」当常态是错的，近三年（validate 段）只有 54%。
3. **无条件频率随之漂移**：UP 在 validate 段只占 18.6% 的行（2021–2024 弱势区间），
   test 段占 30.9%。所以「延续率 − 无条件频率」这个差值比延续率本身稳健。
4. **UP = 更高波动，不是更高胜率**：validate 段 UP 状态未来 5 日**上涨**概率 32.4%，
   低于同日全体基线 37.9%。预注册 §4.1 读数 C 的定性判断（趋势状态是**风险**变量）
   在正式版里得到确认。
