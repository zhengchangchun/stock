# 实验台账（append-only）

> 每一次「提出假设 → 改动 → 评估」都必须在这里留一条记录，**失败/被否证的实验同样要留**。
> 目的：让优化可追溯、可复现、不重犯。

## 规则

1. **单变量**：一条记录只改一个变量。同时改多处 → 无法归因 → 无效实验。
2. **样本外**：结果必须来自 walk-forward 验证窗；样本内数字只能作为附注。
3. **样本量门槛**：不足 120 个交易日的结论标注「样本不足，仅供观察」，不得据此改策略。
4. **扣成本**：净值曲线必须含佣金（最低 5 元/笔）、印花税、滑点。
5. **基准对照**：必须与 index_300 / buy_and_hold 对比。
6. **不许改口径救结果**：失败就写失败。
7. **不许删改历史记录**：结论被推翻时，追加新的记录引用旧的，不修改旧的。

## 命名

`YYYY-MM-DD-<short-name>.md`，从 `TEMPLATE.md` 复制。
