# 实验：趋势状态标签（双均线三态）的命中率与延续率

- **日期**：2026-09-15
- **提出人**：user（口径由 nanobot 落成可证伪形式）
- **状态**：预注册（pre-registered）· 未跑正式验证
- **缘起**：用户明确要求「不需要判断是涨是跌，给出上升/下降的趋势，然后再判断准确性」。
  即：放弃「次日涨跌方向」这一被证否的预测轴（P8/P10 已否证三条变体，`pit-rw-v1.0.1`
  方向能力 ≈ 0：行级 38.14%、Brier 0.6581），改为**先给趋势状态标签，再评估该标签的准确率**。

## 1. 假设

> 用**仅用 t 日及之前收盘价**可算出的双均线趋势状态（UP / DOWN / FLAT）给标的打标签，
> 则「未来 5 个交易日收益方向」的条件命中率显著高于无条件基线，且状态自身具有显著延续性。

**失效条件（提前写死，不许事后修改）**：

- **F1**：validate 段中，UP 侧与 DOWN 侧**任一**侧的 `Δ = 条件命中率 − 无条件命中率` 的
  按日聚类 95% CI **下界 ≤ 0** → 判据 (a) 不成立。
- **F2**：validate 段中，状态延续率（`P(state_{t+5} = state_t)`）不高于该状态的无条件频率
  （差值 CI 下界 ≤ 0）→ 判据 (b) 不成立。
- **F3**：按日聚类的**有效样本 < 120 交易日** → 记 `inconclusive`（不算数，也不许当作
  「可以再调参重跑」的理由；调参需另立预注册）。

**达标规则**：判据 (a) 或 (b) **至少一条**成立 → 允许打开 test 段复核；两条皆不成立 →
`falsified`，不打开 test、不进策略库、不进实盘。

## 2. 变量（只改一个）

基线：`pit-rw-v1.0.1`（随机游走 + PIT 因子链的次日方向/区间预测）。

实验：**趋势状态标签**（不是新的收益预测模型，是新的一层可评估输出）。

| 项 | 基线值 | 实验值 |
|---|---|---|
| 输出对象 | 次日方向 + 区间 | 趋势状态 `UP / DOWN / FLAT` |
| 状态定义 | — | `UP`：`close_t > MA20_t` 且 `MA20_t > MA60_t`；<br>`DOWN`：`close_t < MA20_t` 且 `MA20_t < MA60_t`；<br>`FLAT`：其余 |
| 主视界 N | 1 日 | **5 交易日** |
| 判定指标 | 方向准确率 / Brier | M1 条件命中率、M2 状态延续率 |

**设计常量（写死，看结果后不许改）**：`MA20 / MA60`（含当日收盘）、`N=5`、无 FLAT 阈值
（FLAT 由两条均线关系直接定义，不引入额外分位阈值）、无平滑、无迟滞。
二级视界 `N ∈ {1, 10, 20}` 与替代窗口 `MA(10,30) / MA(5,20)` **只作稳健性附表**，
不得据其结果改判据或宣布达标。

## 3. 数据

- 区间：`trading_calendar` 全量（2013-04-16 起），但评估只用各标的 bars 覆盖区间。
- 标的：`000333`、`600690`、`sh000300`（指数作对照；当前标的池只有这三个，**无 ETF**）。
- 价格口径：`bars_daily` 不复权收盘（PIT）；收益率为**不复权价格收益**（趋势状态只用
  价格序列的相对关系，不涉及跨除权日的收益计算；若落到交易则必须换成复权口径）。
- 数据快照：以 `raw_fetch_cache` 当前内容为准，跑正式版时记录哈希。

## 4. 结果（样本外）

- walk-forward 切分：沿用 P8 框架的 validate / test 两段（validate 判定、test 只在校验时打开）。
- 按日聚类：同一天的所有标的/状态命中记为一个簇，bootstrap 重采样**按日期**而非按行。
- 样本量是否 ≥ 120 交易日：待正式版填写。
- **正式版结论：未跑。**

**读数 C（副产物，预注册未列，仅登记）**：状态对**波动/尾部风险**分层明显。000333 未来 5 日收益标准差：
UP `6.44%`、DOWN `4.98%`、FLAT `4.42%`；未来 5 日跌超 5% 的比例：UP `0.111`、DOWN `0.098`、FLAT `0.073`。
即「上升趋势」= 更高的波动与尾部风险，而**不是**更高的上涨概率。

**探索性判断（非结论）**：趋势标签作为**状态描述 + 风险条件化**是站得住的（延续率 68–74% vs 基线 30–35%）；
作为**方向信号**不成立（Δ 不显著且在标的上符号不一致）。正式版若走完流程，预期结论是
「判据 (a) 否证 / 判据 (b) 成立 → 采纳为标签层（风险用途），不采纳为交易信号」。

## 5. 结论

- 采纳 / 不采纳 / 否证：**待跑**（正式版 = validate 段判定 + gate；test 仅在达标后打开）
- 探索性预期（非结论）：采纳为**标签层**（趋势状态 + 风险/波动条件化），
  **不**采纳为方向交易信号 —— 见 4.1 读数 A/B/C。
- 若判据 (a) 否证 —— 学到了什么：**「趋势持续」≠「趋势可预测收益」**。双均线状态
  高度自相关（延续率 ~72%）只是平滑后的价格序列的机械性质；把它当买点，等于把
  「状态持续」误读为「涨」。这条要写进项目 CLAUDE.md 的否证清单，防止重复踩。
- 落地口径（若采纳为标签层）：标签只用于 ① 描述（当前处于什么状态、已持续多久）；
  ② 风险预算（该状态历史波动与尾部风险）；③ 规则化纪律触发（如跌破 MA20 且 MA20<MA60
  记为 DOWN 并提示，这不是预测）。任何用它做买卖的用法，必须另立实验并扣成本与
  `buy_and_hold` 对照。
