> 第 4.2 节起才是跑完之后贴回来的真实输出。

- **日期**：2026-09-15
- **提出人**：claude（P8 上半 Task 40）
- **状态**：**已收尾 · `falsified`**（不晋级，基线 `pit-rw-v1.0.1` 保持不变）
- **口径版本**：`p8-metrics-v1`
- **完整报告**：`reports/2026-09-15-exp-index-mom-dir.{md,json}`
- **冻结项**（本实验**不许**改）：标签带 `FLAT_BAND=0.005`、`WINDOW=60`、
  `LEVEL_WINDOW=20`、标的集合 `{000333, 600690}`、成本模型、本金、样本区间。
  **`sigma` 与 `range_80` / 关键位口径完全不动** —— 本变体只换漂移的**符号来源**。

## 1. 假设

> A 股同涨同跌。沪深300 在 `asof` 当天的涨跌方向，对**次日**个股方向的信息量
> 高于个股自身 60 日对数收益均值（后者是噪声主导的）。
> 把漂移改成 `mu = |mu_sample| * sign(sh000300 当日收益)`（`|·|` 不变，只换符号，
> 当日指数落在 ±0.5% 带内则 `mu = 0`），应当让样本外的
> **方向准确率上升**，并带来 **Brier 下降**。

**PIT 约束（提前写死）**：指数方向**只允许**用 `<= asof` 的指数行。
`asof` 当天指数没有 K 线（采集缺口）→ 返回 `None` → `DegenerateInput` **硬拒绝**，
该 `(日, 标的)` 记进 `skipped`。**绝不许**取「最近一根」或退化成基线 ——
退化成基线会让报告显示「变体跑了 N 天」，实际只有 M 天用了变体。

**失效条件**（提前写死）：

- **方向**：validate 段配对日差 `Δdirection` 的 95% CI **下界 ≤ 0** → 假设不成立。
- **校准**：validate 段 `Δbrier` 的 95% CI **上界 ≥ 0** → 假设不成立。
- 两条同时满足才记 `WIN`；符号错 → `LOSE`；符号对但不显著 → `FLAT`；
  有效交易日 < 120 → `INSUFFICIENT`。
- validate 不达 `WIN` → 封存段 test **不打开**。

**预期方向**（也提前写死）：方向准确率 **上升**，Brier **下降但幅度小于**
方向准确率的提升（因为 `|mu|` 没变，概率分布的**形状**几乎没动，
动的只是它朝哪边偏 —— Brier 对这种「整体搬家」不如对 argmax 翻转敏感）。
**这一条是本次实验最可能失败的地方**，写在这里以免事后找补。

**已知风险 / 反方预期**：A 股的隔夜动量在 2015 年后被反复证伪；
指数当日方向对次日个股方向很可能**就是噪声**。若如此，
正确的结论是「否证：指数当日方向无次日信息」，而不是换窗口/换指数再试。

## 2. 变量（只改一个）

| 项 | 基线值 | 实验值 |
|---|---|---|
| `mu_mode` | `sample_mean`（`mu = fmean(60 日对数收益)`） | `index_sign`（`mu = \|mu_sample\| * index_dir`） |

`index_dir ∈ {-1, 0, +1}` 是**数据**（`asof` 当天指数相对前一交易日的方向），
不是配置项：`ForecastSpec` 里仍然只有 `mu_mode` 一个字段，
`changed_fields() == ("mu_mode",)`。相对基线改掉的字段 = `["mu_mode"]`。

## 5. 结论

<!-- VERDICT -->
**`falsified`（不晋级；基线 `pit-rw-v1.0.1` 保持不变）**

- **一句话理由**：把漂移的**符号来源**换成沪深300 当日方向后，validate 段方向准确率
  从 **0.3687 掉到 0.3372**（Δ=-0.0315，95% CI [-0.0708, +0.0078]，下界 ≤ 0），
  **方向是变差的**；Brier 名义上降 0.0014，但 CI 上界 +0.0037 ≥ 0，
  **改善落在噪声内**。两条预注册失效条件都触发，gate 记 `LOSE`，
  因此**不打开 test 封存段**。
- **学到什么**：
  1. 我在 §1 写的预期失效点**被自己命中了**：当时写下「Brier 对此不如 argmax 翻转敏感，
     这是本次实验最可能失败的地方」。事实是**方向本身就没变好**，
     比预判的更彻底 —— 指数当日方向对次日个股方向**就是噪声**，
     这正是 §1「已知风险」里预留的那个否证结论，现在由数据给出，**不再换窗口/换指数重试**。
  2. **`index_300` 基准那 54.38% 不是「指数方向能预测个股」——它是同期共振，别被它骗。**
     基准表里 `index_300` 在 validate 段按日聚类 **0.5438**，远高于模型（0.3687）
     甚至高于 `always_down`（0.4301），看上去像「指数方向是个强预测器」。
     核对口径（`stocklab/verify/service.py:100 index_pct_for`）：它算的是
     `index[target]/index[asof] - 1`，即**与个股被预测的那段窗口完全相同的同期涨跌**，
     再拿它的分类去比个股的**同一窗口**分类。
     所以它度量的是「A 股同涨同跌」的**同期**共动，是一个**同期对照/上界参考**，
     **不是领先信号**，也不是任何可交易的东西。
     而本变体用的是 `asof-1 → asof` 的指数方向（`experiments/variants.py:140-152`，
     `cur.date == asof` 硬校验）去猜**次日**——是货真价实的领先用法。
     **这两个数字不矛盾，恰恰是本次最该记住的一课**：
     看到「指数方向 54%」就以为指数方向对次日有信息量，
     是把**同期共动**误读成**领先预测**。数据说：同期共动很强，领先信息 ≈ 0。
     基准表里这一行必须永远和它的「同期」口径一起读 —— 建议后续把
     `note` 从「当日方向」改成更不容易误读的「**同期**（asof→target）指数涨跌」。
  3. `index-mom-dir` 与 `rw-mu0` 同日独立提出、方向 Δ 同为负 —— 两条独立路径都指向
     「漂移项（`mu`）的改造不是当前方向准确率的瓶颈」。后续提「换 `mu`」类假设，
     必须先解释这两次否证。
  4. 工程侧的正向确认：那个「指数缺 K 线 → 硬拒绝并计入 `skipped`，绝不退化成基线」
     的设计在真实数据上**确实触发了 1 次**（否则两侧可评分数会相等）。
     若当时图省事让它退化，报告会显示「变体跑了 3596 天」，实际有 1 天是基线 —— 
     这是「绝不静默退化」这条规矩第一次在真实数据上被证明必要。
- **不做什么**：不换窗口、不换指数、不试「指数前 N 日累积方向」把否证「救」回来；
  不改口径、不改切分、不翻看 test。
