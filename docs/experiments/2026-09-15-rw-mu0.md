## 1. 假设

> 当前基线把「最近 60 个交易日的对数收益均值」当作漂移 `mu`。
> 这个估计量的噪声远大于它对次日方向的真实信息量，而三分类的标签带只有 ±0.5% ——
> 于是 `mu` 的主要作用是**把概率质量从一个尾部搬到另一个尾部**，
> 让 argmax 偏离标签带真正偏好的那一类。
> 把 `mu` 置 0（`Normal(0, sigma)`，sigma 与关键位口径完全不动），
> 应当让样本外的**方向准确率上升、Brier 下降**。

**失效条件**（提前写死，事后不许改）：

- **方向**：validate 段配对日差 `Δdirection`（变体 − 基线，按日聚类）的 95% CI
  **下界 ≤ 0** → 假设不成立。
- **校准**：validate 段 `Δbrier` 的 95% CI **上界 ≥ 0** → 假设不成立。
- 两条**同时**满足（下界 > 0 且上界 < 0）才记 `WIN`；符号错记 `LOSE`，
  符号对但不显著记 `FLAT`；有效交易日 < 120 记 `INSUFFICIENT`（不算数）。
- **样本外才算数**：选择只看 validate；validate 不达 `WIN` → **封存段 test 不打开**，
  结论直接 `inconclusive`/`falsified`，不许「翻一眼 test 看看」。

**预期方向**（也提前写死）：方向准确率 **上升**（`Δdirection > 0`），
Brier **下降**（`Δbrier < 0`）。理由：`mu=0` 在 ±0.5% 带下把 argmax 推向 `flat`，
而实测 `flat` 是真实频率最高的一类（方向几乎无信息，Brier ≈ 0.658 ≈ 随机 0.667）。

**已知风险 / 反方预期**：`mu := 0` 抹掉的也可能是真实的一点动量信息。
若 A 股个股次日方向确有短期动量，则本变体会**变差** ——
那么正确的结论是「否证」，不是去找个更小的 mu 再试（那是全样本调参）。

## 5. 结论

<!-- VERDICT -->
**`falsified`（不晋级；基线 `pit-rw-v1.0.1` 保持不变）**

- **一句话理由**：`mu` 置 0 后 validate 段方向准确率从 **0.3687 掉到 0.3310**
  （Δ=-0.0376，95% CI [-0.0806, +0.0053]，下界 ≤ 0），**方向是变差的**；
  Brier 名义上降了 0.0040，但 CI 上界 +0.0004 ≥ 0，**改善落在噪声内**。
  两条预注册失效条件都触发，gate 记 `LOSE`，因此**不打开 test 封存段**。
- **学到什么**：
  1. 预注册里我写的理由（「`mu` 是噪声主导，置 0 会把 argmax 推向 `flat`，
     而 `flat` 是真实频率最高的一类」）**站不住**：在 ±0.5% 带下，
     把质量推向 `flat` 并没有换来准确率 —— 因为 `always_flat` 按日聚类只有
     0.2234，真实频率最高的那一类恰恰是**最难猜对**的那一类；
     「猜多数类」在三分类带里不是有效策略。这条推演我在跑之前写死了，
     现在被数据正面否掉，属于**有价值的否证**。
  2. 样本内（train，1943 交易日）这个变体记 `FLAT`：
     方向 Δ=+0.0080 [-0.0124, +0.0283]（不显著），**Brier Δ=-0.0060 [-0.0096, -0.0024] 显著变好**。
     到样本外，方向 Δ **翻负**（-0.0376，仍不显著），而样本内那个**显著的 Brier 改善直接消失**
     （Δ=-0.0040，CI 上界 +0.0004 ≥ 0，不显著）。
     「样本内显著改善 → 样本外无影、且方向翻负」是本次最值钱的观察，
     也正是「样本内数字只能用来调试，不能上报」这条纪律的实证。
     （注意措辞纪律：样本外方向只是**符号错**，不是「显著变差」——
     它的 CI 同样跨 0。不许把「不显著」说成「显著」。）
  3. `rw-mu0` 与 `index-mom-dir` **同一天、同一区间、各自独立提出**，两者方向 Δ
     都是负的，且都指向同一个结论：**漂移项的改造不是当前的方向准确率瓶颈**。
     后续再提「换 `mu`」类的假设，必须先解释这两次否证。
- **不做什么**：不去试 `mu = 0.5 * sample_mean` 之类的中间值（那是拿全样本调参
  把否证「救」回来），不改口径、不改切分、不翻看 test。
