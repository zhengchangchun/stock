## 1. 假设

`pe_pct_756`（P95 §5.2 **VAL-B**）＝ 当前 PE 落在**自身最近 756 个交易日（≈3 年）历史**里的百分位：

```
W756 = trading_calendar 里 is_open=1 且 date <= asof 的最近 756 个交易日
d0   = W756 里最靠 asof 的那个交易日
x    = pe_ttm[code, date == d0]
S    = { pe_ttm[code, d] : d ∈ W756 且该值非空且 > 0 }        # 参照集，含 x 自身
pe_pct_756 = #{ s ∈ S : s <= x } / |S|                        # ECDF、右闭、含自身 ⇒ 值域 (0, 1]
```

- **只读 `valuation_daily.pe_ttm` 一列**（`pb` / `ps_ttm` / `total_mv` / `total_shares` /
  `close_price` / `change_rate` 一律不读）；PIT 锚 = `valuation_daily.date <= asof`，
  `d0` 用「`<= asof` 的最后一个交易日」（`asof` 本身可以不是交易日）。
- **窗口序**：`_recent_trading_dates` 返回 `ORDER BY date DESC`（最近的在前）⇒ 取值器内部翻成升序后取
  `[-1]`（P104 §0.5 L2 ＋ 它的 §10 独立复核已实测 `d_hi == asof`）。
- **缺失三条**（P104 L4，缺一不可）：① `x` 为 `NULL` 或 `<= 0` ⇒ `None`；② `|S| < 252` ⇒ `None`；
  ③ 窗内 `NULL` / `<= 0` 的样本**只从 `S` 剔除**（不补 0、不取绝对值、不当 0 进分子分母）。
- **不做 winsorize**（rank IC 对单调变换不变）；`756` / `252` 是照抄 P95 的**常量**，本档不许试别的值。

**假设**：**时序自比**（当前 PE 处于自身 3 年区间的百分位）比**横截面绝对值**（候选 #3 `ep_ttm`）
更能剥离行业/规模差异，因而对下一个调仓周期（5 交易日）的前向收益**有可测的横截面排序能力**。

**方向不预设**（CLAUDE.md 度量纪律 6）：`pe_pct_756` 高 = 相对自身历史偏贵、低 = 偏便宜。
两种相反叙事都存在（低估值 ⇒ 均值回复向上；或 ⇒ 便宜有便宜的理由、继续跑输），本实验
**不据此预设符号**（负 IC 同样算 `IC_SIGNIFICANT`）。

**头号风险（本节提前写死）**：

1. **样本量不足 ⇒ 大概率 `INCONCLUSIVE`**。`valuation_daily` 首行 **2018-01-02**，再要 756 个交易日
   ⇒ 实际可用起点 **≈2021-02-08**（P104 §9 只读实测：`asof=2015-01-05` 覆盖 **0** 只、`2021-06-01`
   覆盖 **624** 只、`2026-09-24` 覆盖 **716** 只）。`factor-ic` 的 70/30 切分是对**有值 IC 序列**
   （`replay.split_train_validate`）切，不是对全 570 个周期切 —— 候选 #3 `ep_ttm` 已实测到这一点
   （丢 147 个早期有效日后验证段从 171 变 **127**）。本档丢的早期周期更多（≈2015-01→2021-02，
   约 **297** 个调仓周期）⇒ 有值序列只剩 **≈274** 个周期 ⇒ 验证段 **≈82 < `MIN_VALID_PERIODS = 120`**
   ⇒ **预期 `INCONCLUSIVE`**（P95 §8 第 471 行已预判）。**这是允许的结果，不是失败**；出现时
   **禁止**改窗、改门槛、补前向填充、加长样本（P104 §0.5 L10 已禁）—— 只照实写「测不出」。
2. **`|S| >= 252` 让覆盖**在**最早期几年**进一步偏窄（长期亏损 / 停牌标的被剔除）⇒ 本档必须并排报
   `value_coverage_p50` / `xsec_size_p50` / `n_dates_skipped`，与 IC 一起读；**不许**为了让 n 好看而
   降低门槛。
3. **与候选 #3 `ep_ttm` 同列不同构**（同一个 `pe_ttm` 的两种变换：绝对值横截面 vs 时序百分位）

## 4. 判据（跑完照此写结论）

1. **主读数**：`pe_pct_756` 的全窗 / 训练段 / 验证段 IC 均值、95% CI、IR、t、分层（5 层）spread、
   单调步数、`n_dates_skipped`、`n_fwd_fallback`、覆盖度（`value_coverage_p50`、`xsec_size_p50`）；
   **并排报** `zero_ratio_p50` / `tie_ratio_p50`（只报不判）；`mom20` / `vr15` 同表并排（同样出 verdict）。
2. **冗余门（预注册，跑完只许照此判）**：`ρ̄` = 验证段逐调仓日的**截面 Spearman**均值 ——
   分别对 `pe_pct_756` 与 `mom20`、`pe_pct_756` 与 `vr15`，在「当日两个因子都有效」的**共同代码集合**上计算。
   - `max(|ρ̄_mom20|, |ρ̄_vr15|) > 0.5` ⇒ **冗余淘汰**（即使 IC_SIGNIFICANT 也不采纳）；
   - `0.3 < max ≤ 0.5` ⇒ 需另立「残差 IC」单变量实验后才谈采纳；
   - `≤ 0.3` ⇒ 视为独立候选（仍要过下面的 IC 与折扣）。
   **额外必报（本档独有，只报不判）**：`ρ̄(pe_pct_756, ep_ttm)` —— 同列不同构的旁证（§1 头号风险 3）。
   **度量路径与已知缺口**：harness **不出**这些读数（`research factor-ic` 无此输出，候选 #2/#3/#4/#5
   §7 已披露）；P98 的只读探针 `/tmp/p98b/rho_probe.py` 存在，**本档无论 verdict 都必须先跑它补齐
   `ρ̄(pe_pct_756, ep_ttm)` 并把探针 sha256 与输出 json 回填 §7**（这条比候选 #2–#5 更硬：本档与
   `ep_ttm` 同列，冗余是**先验已知**的高风险项）；若探针不可用，则如实写「缺口未执行」并把
   `ep_ttm` 的 `IC_NOT_SIGNIFICANT` 读数并排引用，**不得**据此说「已排除冗余」。
3. **折扣（只用于解读，不改代码门槛）**：
   - **有效样本折扣（本档最重，必须写）**：窗宽 756 交易日、调仓步长 5 交易日 ⇒ **相邻调仓日的因子
     窗重叠 `(756−5)/756 ≈ 99.3%`** ⇒ IC 序列存在强正自相关，`570`（本档实际只剩 ≈274）个观测
     **不是**独立样本。两条口径并排报，**只作解读**：(a) 温和 —— 只披露「窗口重叠 99.3%」这一事实；
     (b) 保守上界 —— 按最粗的 `窗口重叠倍数 = 756/5 ≈ 151.2` 折算，有效独立样本 ≈ `274 / 151.2 ≈ 1.8`（上界）。
     若结论要采纳，须另立「按日聚类 / 换窗（如 252 日）/ 打散步长」的稳健性实验。
   - **族大小折扣**：本实验的假设来源是 P95 §5 的候选池（`gm_yoy_pp`、`mf_ratio_5d`、`ep_ttm`、
     `ann_count_5d`、`mf_net_surprise_20d` 已测／在测，本档是**第 6 个**）⇒ 报出 `1 − 0.95^6 = 26.5%`
     供解读，**不作判据**。
   - **方向先验前科（必须并排写）**：P29 `val-pe-pct-mu`（`docs/experiments/2026-09-17-valuation-moneyflow-oos.md`
     §4.2.1）测的是「`PE_TTM` 近 756 行分位」当**次日方向先验**（时序扩散，非横截面排序），
     判定 **`LOSE`**（方向 0.3389 vs 基线 0.3472，Δ CI 下界 < 0、符号错；Brier Δ 跨 0）。
     **两者不是同一件事**（不同预测对象、不同度量），但 **P95 §5.2 明写 `pe_pct_756` 与「近期估值」
     有**方向先验的前科**，本档是「换度量重测」** —— 结论若为 `IC_SIGNIFICANT`，必须与这条前科并排写，
     **不许**隐去。
4. **结论词汇只许四个**（`IC_SIGNIFICANT` / `IC_NOT_SIGNIFICANT` / `INCONCLUSIVE` / `LOW_COVERAGE`）；
   **不得**写因果推断，**不得**据此直接改打分函数或权重。
